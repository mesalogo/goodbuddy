# Factory Droid Runtime 界面设计

遵循 [UI-DESIGN.md](../../../../UI-DESIGN.md)。本文定义 [FR-1、FR-3 至 FR-6](./prd.md)
的展示与操作，状态来源以[状态设计](./logic-design.md)为准。

## 会话顶部

在现有 `ConversationHistorySlot` 的 `conversation-context-strips` 中增加后台任务条，
复用待办条的紧凑摘要、折叠操作和已有任务详情样式。三个条目按需出现，不显示空条：

```text
待办       2/5 · 正在检查测试
后台任务   2 个运行中 · 1 个待回答                 展开
定时任务   每日检查 · 明天 09:00
```

示意数字不代表真实任务。Runtime 选择与可用性继续放在输入区，不在顶栏重复展示。
后台任务绑定当前会话；远程会话同样显示，并在详情注明所属 Host。

展开列表优先显示待回答、运行中、停止中、失败任务，已完成项可折叠查看。每行包含名称、
类型（子代理/后台命令）、状态文字、运行时间及可用动作。没有可测量进度时只显示状态，
不制造百分比。任务执行结束后才停止计时。

| 动作 | 交互 |
| --- | --- |
| 查看输出 | 打开现有风格的任务详情，展示预览、加载更多和最终结果；有新输出时提供跟随末尾 |
| 回答问题 | 定位并展开同一个 `AgentQuestionCard`；顶部只提供待回答入口，不再创建第二份表单 |
| 停止 | 单任务进入“正在停止”；收到终态后显示实际结果，只有确认取消才显示“已取消”。错误使用共享通知，详情保留原因 |
| 定位来源 | 定位到创建该任务的消息/工具调用，不改动当前输入草稿 |

运行任务的停止入口只在底层已完成独立停止验收后开放。产品交付不能通过永久隐藏控制来
宣称 FR-4 已完成。暂时失联时保留列表，停止按钮说明当前无法连接，不把任务标为失败。

原生 TodoWrite 的完整输入和成功结果已经验证，可映射现有待办条。普通后台子代理的状态、
输出和独立停止已通过 daemon 验证，可支撑后台条；后台命令独立停止仍待验证。
这些是接口验证结果，本轮没有修改或挂载 Renderer 组件。

## 问答与阅读

问答复用现有单选、多选、自定义输入、提交错误与跳过 UI。后台来源显示任务名称；从顶部
打开的问题与时间线中的问题共享 questionId、提交状态和草稿。切换会话保留草稿，问题失效
后显示原因，不再允许提交。

后台完成不抢焦点、不强制滚动聊天；用户正在查看输出时维持其阅读位置。只有已开启跟随
末尾时自动跟随。需要立即处理的失败或提问通过已有通知机制提示，点击返回对应任务。

## 布局与可访问性

沿用 `ChatHistoryPane` 对顶部条实测高度的处理及现有 `45vh` 容器限制，不额外叠加固定高度。
展开列表内部滚动，窄窗口动作换行，日志换行或内部横向滚动，不撑宽聊天正文。

沿用语义主题令牌、已有 Portal、可见焦点、展开状态及键盘操作。关闭详情后焦点返回触发按钮。
状态同时有文字，不能只靠颜色。输出更新按任务局部订阅，文本块不触发全部任务/会话重载。

验收覆盖浅深主题、短窗口、远程标识、键盘、切换会话、历史定位、顶部展开后的消息留白和
滚动锚点，对应 [US-5、US-7、US-10](./user-stories.md)。
