# Factory Droid Runtime 用户场景

需求定义见[产品需求](./prd.md)，以下场景用于产品路径验收。

| ID | 关联需求 | Given / When / Then |
| --- | --- | --- |
| US-1 | FR-1、FR-7 | 已配置模型和 Droid 路径；选择 Droid 并发送请求；实际使用选中模型，错误时保留原选择并说明原因 |
| US-2 | FR-2 | 当前回复包含文本和工具；接收增量并结束；文字只出现一次，工具与用量正确归属，下一轮能继续 |
| US-3 | FR-3、FR-4 | Droid 创建后台任务；主回复完成并发送下一轮；顶部仍显示原任务，原任务事件不覆盖新回复 |
| US-4 | FR-4、FR-6 | 两个后台任务运行中；停止其中一个；目标任务达到终态，另一个及当前回复继续 |
| US-5 | FR-5 | 前台或后台任务提出问题；切换会话后返回并提交答案；草稿保留，答案回到原提问者并继续工作 |
| US-6 | FR-5、FR-6 | 问答待提交时任务已结束或会话释放；用户点击提交；显示已失效，答案不发送给新任务 |
| US-7 | FR-4、FR-8 | 后台任务有较长输出；用户展开、分页、切换任务；读取对应任务输出，状态更新不触发全量历史重载 |
| US-8 | FR-6、FR-8 | 本地有后台任务；切换 Runtime 配置或正常退出；旧任务按原归属结算，退出后不留孤儿进程；重启不重放任务 |
| US-9 | FR-8、FR-9 | 远程任务运行中；桌面断线再连接；恢复所属 Host 的实际状态及输出，不重复启动任务 |
| US-10 | FR-3、FR-4 | 窄窗口、浅色或深色主题；展开顶部后台任务并定位输出；消息不被遮挡，键盘能操作并返回触发位置 |
| US-11 | FR-10 | Host 已有 Droid 或用户导入离线文件；多个项目选择同一已验证版本；复用同一二进制，配置隔离，无在线下载 |
| US-12 | FR-10 | Host 未安装 Droid；用户选择按需安装；显示下载与占用信息，验证精确版本后使用，失败保留原可用版本 |

US-4 必须使用普通后台 Task 验证，不能用 Mission worker 的停止结果替代。
US-5 还需分别覆盖单选、多选、自定义答案、跳过和同一会话多个待回答问题。
