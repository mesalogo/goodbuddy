# GoodBuddy 更新：故事图谱、Telegram 与 Obsidian 接入

> **让工作有迹可循，让对话走出桌面，让已有笔记直接参与。**

这一版 GoodBuddy 把三件事做完整了：

| | 解决的问题 | 一句话 |
| --- | --- | --- |
| **故事图谱** | 做过的决定、依据和后续变化散落在各次对话里 | 把工作整理成可回看、可追溯的故事 |
| **Telegram** | 人不在电脑前，也想继续处理任务 | 在手机上通过私聊使用同一个项目 |
| **Obsidian** | 多年积累的笔记仓库和 AI 对话彼此割裂 | 助手直接搜索、读取、写回你的仓库 |

## 故事图谱：看清一件事是怎么走到今天的

做了一段时间的项目，最难回答的往往是：当初为什么这样定？后来改了什么？依据在哪次讨论里？

故事图谱把对话中的事件、实体和关系整理成持续发展的故事，每条结论都能点回原始来源。

![故事图谱：事件、实体与关系，右侧可查看详情和关联来源](storygraph.png)

*故事图谱：按时间浏览事件，选择任一节点即可查看详情、关联对象和来源正文。*

**工作回顾，每条结论都有出处。** 按全局或项目范围，回顾最近一天、数天或任意指定日期的工作，得到总结、变化和未决事项。结论可以一路追溯到事件、实体、关系和来源原文，再决定是否确认、改名或调整关系。

**故事与经验，随工作自然沉淀。** 事件归入按项目、功能和子线索组织的故事，支持重命名、合并、移动和撤销。故事里提炼出的经验，会记录适用条件、形成依据和后续应用，也可以手动编辑、合并或删除。

**时间螺旋，换一个角度看进展。** 除了平铺的关系视图，还可以用时间螺旋观察多条线索如何交错、停顿和延续。

**助手接着上次的决定继续。** 追问“当初为什么选这个方案”时，助手会按需查阅已保存的故事、经验和来源，不必从头解释背景。每个会话都可以单独决定是否允许访问图谱。

**智能心跳，持续跟进。** 设置每日或每周计划后，心跳只处理新增和变化的记录，提出未决事项、分歧、修订、候选约定，以及长期没有进展的故事和可能适用的经验。没有新内容时不调用模型。

## Telegram：离开电脑，工作不中断

在 Telegram 上给自己的 Bot 发一条消息，就能把问题或任务交给 GoodBuddy。

```text
手机 Telegram  →  你的 Bot  →  GoodBuddy 项目  →  文字回复回到 Telegram
```

- **沿用项目设置**：使用通道项目的 Runtime、模型和工作目录，不需要另外配置一套。
- **只响应你自己**：通过数字用户 ID 白名单限定可对话的人。
- **桌面同步保留**：每次对话都在桌面端留下完整记录，回到电脑前可以直接接着看。
- **连接更稳**：支持断线自动恢复，停用通道时会取消进行中的请求。
- **配置顺畅**：首次可先留空白名单，连接后发送 `/whoami` 获取自己的用户 ID，再填入保存。

当前通道面向单个 Bot 的私聊文字请求；使用期间桌面应用需保持运行。

## Obsidian：直接使用你已经写好的笔记

如果你的笔记早已在 Obsidian 里，不必搬家，也不必装插件。

![设置中心中的 Obsidian 接入：选择仓库范围、分配给 Runtime](obsidian.png)

*在“设置 → 能力与工具 → MCP”中选择仓库范围，分配给需要的 Runtime。*

- **搜索与读取**：让助手在笔记里找资料，并结合当前对话回答。
- **写回仓库**：把讨论结论追加或局部修改到笔记中。
- **目录、标签和属性**：浏览目录，管理标签与属性。
- **范围可控**：可以使用本机全部已注册仓库，也可以只开放某个文件夹；默认关闭，启用后仅在所选范围内读写。
- **笔记留在原处**：内容不会复制进 GoodBuddy 知识库。
- **无需启动 Obsidian**：不依赖插件，也无需配置 REST 服务。

支持直连模型，以及 GoodBuddy 管理的本机 OpenCode 与 Continue 对话。

## 更多改进

| 方向 | 亮点 |
| --- | --- |
| **输入区与 Runtime** | 上下文来源、专家角色、模型和 Runtime 控制整合进输入区工具栏，窄窗口下依然清晰；Runtime 与模型可按会话、项目、全局分别配置，也能在当前会话临时切换 |
| **项目与会话** | 项目和会话合并到同一个菜单，支持分类搜索和悬停预览；长对话渲染更流畅，阅读位置和展开状态得到保留 |
| **魔法笔记** | 支持表格编辑、标签筛选与管理、列表和正文双栏浏览；聊天回答可一键存入笔记并回到原会话 |
| **文件与图表** | 批量导入本地文件到本地或远程项目；Mermaid 图表可导出完整 PNG |
| **原生终端** | 在输入区直接打开 Continue 或 OpenCode 终端 |
| **日常体验** | 桌面通知、磨砂外观和任务用量可分别设置；直连模型支持手动压缩上下文，工具失败后可继续对话 |
| **稳定与性能** | 存储与请求路径优化，减少界面等待；长请求的工具授权、取消与失败处理更可靠；监督回顾支持暂停、继续和失败重试 |

---

**版本**：Desktop `0.15.13`，远程项目配套 Agent `0.15.6`。升级前请备份用户数据；新版数据库格式不能被旧版客户端打开。
