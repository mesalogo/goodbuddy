# GoodBuddy 更新：飞书、企业微信与 Office 文档编辑

GoodBuddy 这轮更新接入了飞书和企业微信的办公工具，也支持在工作栏中编辑 Office 文件。在聊天里查资料、整理内容后，可以写回平台文档，或选中 Word 中的一段文字，请助手修改。魔法笔记增加了按页和框选提问，远程项目也可以使用直连模型处理 Host 上的文件。

## 新增功能

### 飞书：文档、知识库和多维表格参与对话

飞书接入后，助手可以读取和创建文档，追加或修改正文，浏览知识库与云空间，也能查询和更新多维表格记录。讨论完的内容可以直接写入飞书，后续仍在原来的文档中查看和协作。

右侧的飞书面板提供知识空间、页面和文件夹浏览，支持搜索、类型筛选、新建文档或知识库页面，以及上传本地文件。找到资料后，可以打开原文，或将它用于当前对话。聊天中的工具结果卡片会显示可识别的文档标题、操作和原文入口，便于核对助手刚才处理了什么。

飞书消息通道也已接入，支持飞书和 Lark。配置应用凭据、允许的发送者及群聊响应策略后，可以从飞书向 GoodBuddy 发起文字请求并接收文字回复，使用期间桌面端需要保持运行。

文档工具使用飞书应用身份，访问范围由应用权限和资源授权决定。接入前需要把相应文档或知识空间开放给应用；消息通道目前处理文字，不收发图片和附件。

### 企业微信：从查资料到处理办公事项

企业微信接入扩展到了办公操作。完成工具授权后，助手可以按开启的类别处理在线文档、表格、智能表格、智能页面和微盘资料，也可以使用日程、会议、待办、通讯录等工具。在线 PPT、邮件和消息操作有各自的类别开关，按需要启用。

右侧面板可以搜索文档，查看近 30 天最近浏览或自己创建的资料，浏览微盘，并新建在线文档、上传文件。文档仍保留在企业微信中，工具按授权人的身份访问和修改，沿用该身份已有的权限。

飞书和企业微信工具可用于直连模型、OpenCode 和 Continue 对话。消息会话是否可以使用这些办公工具，需要在应用设置中单独开启。企业微信工具支持 Windows x64、macOS x64／arm64 和 Linux x64／arm64。

### 用 `@` 指定这次讨论的文档

在输入框里键入 `@` 和关键词，可以搜索已接入的飞书或企业微信文档。选中后，文档以引用标签留在输入区，和问题一起发送；一次可以选择最多五份资料。

例如，选中一份项目方案，再写“整理其中还没有确定的事项”，助手就会根据引用调用相应平台工具读取资料。引用保留标题、链接和资源标识，实际能读取的内容取决于文档类型、平台权限和当前 Runtime 支持的工具。

菜单跟随输入位置展开，支持键盘选择。应用已经开启、但凭据或工具类别尚未就绪时，入口会显示原因和设置位置。

### Office 文档可以直接编辑，也可以交给当前对话改写

工作区文件、会话文件预览和附件菜单增加了 Office 编辑入口，也可以直接选择本地文件。配置具备 Office 能力的内网 ShareServer 与 ONLYOFFICE 后，Word、Excel 和 PPT 会在工作栏的文档页签中打开，支持同时打开多份文件。已有设备共享连接可以复用，不必每打开一份文档就重新填写地址。

编辑 DOCX、XLSX、PPTX 后，按 `Ctrl/Cmd+S` 将修改保存回源文件，按 `Ctrl/Cmd+Shift+S` 另存为。DOC、XLS、PPT 会由服务端转换，首次保存为现代格式的新文件，保留原件。源文件在编辑期间被其他程序改过时，会提示冲突并拒绝覆盖，可以另存一份。

Word 中需要润色的段落，可以选中后附上修改要求，发送给当前对话，沿用该会话的 Runtime。回答回来后，先查看或调整结果，再应用到原选区。这个操作目前用于 Word 文字，Excel 和 PPT 仍通过编辑器手动修改。

Office 编辑会把文件交给配置的 ShareServer 和编辑服务处理。本地文件和远程工作区文件均可接入，远程文件操作需要配套更新的 Agent；附件和旧格式转换后的内容首次保存时会选择新文件。

### 魔法笔记支持按页提问和框选提问

阅读一份多页资料时，可以在笔记的 AI 面板中直接提问，选择当前页、指定页码范围或整份笔记作为上下文。只想讨论某张图或某一段内容时，可以在画布上框选区域，确认截图缩略图后发送问题，例如请助手解释图中的关系，或检查选中段落的表述。

回答保留在当前提问面板中，可以接着追问。框选提问需要支持图像输入的模型；使用纯文本模型时，页面提问依据可提取的文字，不会分析笔迹和图形。笔记的长文本、图片、附件和多页画布也已取消此前固定的导入与保存配额，提问仍按模型上下文和单次请求范围处理。

### 远程项目可以使用直连模型

SSH 项目和会话现在可以选择直连模型，请助手读取、搜索、修改 Host 工作区中的文件，或在远程执行命令。项目与会话沿用原有的模型配置继承方式，也支持子任务、长输出续读和手动压缩上下文。

模型请求仍由桌面端驱动，文件和命令工具在 Host 上执行，使用期间桌面端需要保持运行。这项能力需要 Desktop 0.16.11 与 Agent 0.15.10 配套版本。

### 聊天中的 HTML 可以交互

助手生成的 HTML 回复可以在内嵌或全屏预览中运行脚本、加载外部资源、发送网络请求和使用表单。生成一张可筛选的图表或一个计算页面后，可以直接在对话里操作。预览与 GoodBuddy 的应用接口隔离，网络访问遵循浏览器跨域规则。

## 功能改进

### 连接设置和文件查看更集中

应用中心改为卡片布局，内置应用与平台应用分组展示。飞书、企业微信、钉钉、微信 ClawBot 和 Telegram 的连接状态、启用开关、固定入口及设置集中在各自卡片中；应用中心、启动菜单和侧栏使用一致的固定顺序。飞书与企业微信的工具可用性跟随同一个应用总开关，具体类别仍可分别选择。

飞书、企业微信和钉钉的私聊发送者不在白名单中时，会收到包含自身 ID 的提示；桌面端显示最近被忽略的发送者，可以一键加入允许名单。未获允许的请求不会执行，群聊也不会发送这类提示。

聊天里的项目文件链接可以直接打开右侧工作区预览，图片也能从文件列表或聊天链接中查看。文档附件名称变成了可点击入口，用系统应用打开保存的原文件。远程项目的图片预览需要配套支持该能力的 Agent。

文档识别模型和远程 OCR 服务统一放到模型连接中管理，文档解析页保留解析流程和诊断。本地工具环境有独立设置入口，可以自动检测系统工具，也可以选择内置工具或指定路径。

### 聊天导航与故事图谱更便于查阅

非当天的聊天消息显示完整日期和时间，缩略导航增加日期标记，并将消息行均匀排布。会话标题下方显示所属项目，任务条直接显示状态文字，任务与执行清单的背景跟随磨砂外观设置。

会话改名直接在原标题位置编辑，按回车或点击外部保存，按 Esc 取消，列表不会再被额外的输入行挤动。

故事图谱的时间螺旋按实际有事件的时间范围显示，保留事件之间的空白时段；同一时段的不同故事分段呈现，减少重叠。助手读取故事图谱时，会先看到故事、经验和事件的内容，再按需要读取最新决定和原始来源。

### 设备共享与日常操作

设备共享增加独立的设备凭据，重启后沿用注册身份，并显示待审批、批准、拒绝或停用状态。需要连接兼容的 ShareServer，当前共享范围仍是设备目录、能力与知识说明。

导入 Skill 不必先把来源文件夹改成与技能 ID 相同的名字。模型、Runtime 和工作区分类统一使用页签，文档识别的本地与远程来源用单选项选择，保存后生效。

远程任务的记录保存合并了重复写入，减少桌面端的数据库写入量；远程 Continue 再次启动时复用已准备的运行缓存，减少 Host 上反复创建和删除相同文件的操作。任务输出与恢复记录仍会保存。

## 问题修复

- 监督回顾中某个会话批次失败时，其他可处理会话仍会继续，已完成批次保留。恢复后继续未完成部分，存在失败时不会把结果当作完整回顾发布。实体引用出错时，也会说明重复、越界或对象已失效等具体原因。
- 远程会话的连接耗尽、断线接管和历史同步问题合并修复。远程直连模型在准备请求时短暂断线，会自动重试；请求已提交但启动响应丢失时，接管原请求，避免重复执行。历史同步完成后及时结束恢复提示，迟到的断线事件不会再影响已恢复会话。Agent 更新等待在途直连工具及保留输出，临时清理失败时保留已知命令结果。
- 取消 Continue 和 DeepSeek Harness 请求时，修复命令子进程仍继续运行的问题；OpenCode 已取消的子任务显示为取消，不影响同级任务。本地工具启动也修复了环境变量缺失的问题。
- 模型请求遇到 HTTP 413 时，提示尝试压缩上下文后重试，便于处理请求过大的问题；这项提示同时覆盖直连模型和远程模型桥接路径。
- 附件选择或粘贴失败时，通知显示可读的错误并保留输入草稿。平台设置恢复了默认工作目录的保存入口，保存失败时保留修改；企业微信修复了授权人身份读取失败的问题。远程项目隐藏仅支持本地的 Runtime 原生客户端入口。魔法笔记长内容滚动、平台侧栏关闭和控件样式问题也一并修正。
