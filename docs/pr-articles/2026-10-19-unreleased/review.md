需要保留的事实边界：

- 飞书以应用身份访问，非个人 OAuth；扫码创建应用不自动获得扫码人能看到的所有文档。普通电子表格的单元格读写不能由多维表格能力推导。飞书面板上传上限 20 MiB，文档读取最多返回 100,000 字符。
- 企业微信有 14 类工具；旧进度段落的“13 类”已过时。邮件和消息类别默认关闭。官方 CLI 覆盖 Windows x64、macOS x64／arm64、Linux x64／arm64；缺少对应二进制的架构不提供企业微信工具。内置依赖不等于平台离线可用，技能脚本仍需 Python 3.13。
- 直连模型、OpenCode、Continue 接入平台工具；DeepSeek Harness 不接收这两组工具。消息会话工具开关默认关闭。旧进度中“调用前逐次审批”的表述与实际执行路径不符，本稿不采用。
