## 范围与兼容性

- 统一项目与会话菜单、当前/全部范围、活动及十个最近会话、悬停预览。
- 监督者独立文本模型选择及默认开启的会话 Story Graph 开关。
- 活动差量保存、索引分页与完整汇总，schema 57 保留历史并迁移排序；
  schema 58 增加启动恢复候选消息索引。升级前关闭应用并备份完整数据库
  和相邻 notes 目录，旧客户端回退须恢复升级前备份。
- 文档解析 Worker、依赖延迟加载、本地工具环境后台准备、Composer 和
  路由等渲染边界、笔记/文件树/知识文档窗口化、滚动和焦点保留。
- 终端 Main 合并与 xterm 帧批次，远程事件 16ms 定时 flush；
  checkpoint 前落库、事务顺序和回放去重保留。
- 旧 Runtime 缓存按明确版本和布局命名清理，跳过符号链接；
  保留当前布局、运行记录、会话和配置。工作栏间距及操作修复。
- 高频本地写入临时切换 NORMAL 并恢复原 PRAGMA；嵌套事务由外层决定。
  保留应用崩溃原子性，但断电/系统崩溃可能丢失最近部分本地写入。
  远程确认、通道投递和任务生命周期继续 FULL，后台 PASSIVE checkpoint
  不代表已经验证破坏性断电恢复。
- Agent 守护进程只有测试变更，Continue host-v7 仅提取常量，协议和部署
  行为未变，因此不发布新 Agent。Electron/Node/OpenCode/Continue 锁不变。

不承诺通用提速比例。窗口化未挂载行不支持页内查找，快速滚动可显示占位；
只读 Worker 失效可同步回退。开发报告中的 stable controller generation resume
及 Runtime 未到终态错误仍是调查项，本轮不声称修复。

## 本轮真实 Host 验证

中断前已针对 `e89db96` 源码使用固定 Host 身份与既有凭据存储，
在隔离测试目录经生产 Agent、模型桥、远程 ACP、RemoteEventBatcher
和 SQLite 持久化入口执行。后续 `74efbcd` 仅修改工作栏 CSS 间距，
不改变已验证的远程实现。OpenCode 探针显式使用已有 Continue 模型配置，
不是产品静默回退；未构建生产安装包。

**4 次真实模型请求，4 次 HTTP 200**：

| Runtime / 模式 | 批次 | 事件 | checkpoint |

| OpenCode Ask | 3 | 4 | 2 |
| OpenCode Execute | 22 | 42 | 21 |

checkpoint 前落库、完整已保存流再次写入返回已存在、Runtime 重建后历史恢复，
本轮拥有进程清零。生产 SSH 连接池与终端会话另输出 1000 行 Unicode，
13 个输出事件；CRLF 归一化后内容完全一致、序号递增、输出先于退出。

这些证据不是完整 Renderer、已安装 Agent 升级或全部断线恢复矩阵，
也没有验证所有消息投影恢复分支。开发阶段其他模型调用不计入本轮四次。

## 发布门槛

按用户持续授权，直接提交、推送并跟进 CI 和发布，不逐步询问。
不运行本地测试套件、类型检查、lint 或生产构建；完整验证和构建由精确候选
main CI 执行，通过后才创建新的不可变 Desktop 标签。双语说明与 FEATURES
同时更新；Agent 不打新标签。开发文档记载的未通过测试不能视为已解决，
由此次精确候选 CI 决定，失败须定位修复。

最终需核验六平台打包、macOS 签名与公证、GitHub Latest 和 20 项资产、
北京 OSS 索引一致性与网站 12 种下载选择。不下载或启动安装包，
不将候选或推送成功称为发布完成。
