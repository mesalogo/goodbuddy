# Desktop 0.15.14 发布准备

日期：2026-10-09。基线 `v0.15.13`，候选源码 `8f1b6007986f31fb5e2a80e80021602a13fa20a2`。
本候选只更新 Desktop；Agent 保持 `0.15.6`，不创建新的 Agent 标签。标准六平台 Desktop，
不含 LoongArch。

## 范围与兼容性

- 恢复旧版因监督来源变化或移除而失败的历史回顾的继续操作。
- 来源在回顾期间变化时，在有限次数内重新冻结处理；持续变化的来源之后省略，
  已删除、归档或不可用来源沿用既有省略规则，其他来源继续保留进度。
- 保留暂停、失败、取消和已保存批次的监督活动状态及项目范围、来源处理规则。
- 设置分类显示对应图标，帮助用户更快找到各类设置。
- 不新增数据库 schema，继续使用 schema 62；Agent、runtime/acp、wire 和运行时锁版本不变。

## 验证边界

本候选包含监督存储、Worker、服务和 Renderer 回归测试，以及历史失败回顾继续操作的
界面覆盖。完整并发验收矩阵、跨平台存储进程安装和其他未完成验收不在本候选中宣称通过。

## 发布门槛

完成发布说明校验、测试、三套 typecheck 和 lint 后，推送候选到 `origin` 与 `github`，
要求精确候选的主分支 CI 和生产构建通过，再由用户确认后创建不可变的 `v0.15.14` 标签。
本轮不构建或发布 LoongArch，也不创建新的 Agent 标签。
