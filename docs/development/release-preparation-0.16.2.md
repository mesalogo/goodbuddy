# Desktop 0.16.2 发布准备

日期：2026-10-10。基线 `v0.16.1`，候选源码包含 `12a02912`、`ba308520`
和 `f2f4c127` 三个提交。本候选只更新 Desktop；Agent 保持 `0.15.6`，
不创建新的 Agent 标签。标准六平台 Desktop，不含 LoongArch。

## 范围与兼容性

- 监督回顾增加从最早记录到当前时间的全部时间范围。
- 监督回顾只读取已完成消息和任务，实时生成中的内容等待完成后再进入回顾。
- Magic Notes 操作入口增加文字标签，次要更多操作按需显示。
- 终端输入法组合区域保持在终端边界内。
- 数据库 schema 从 62 升到 63；Agent、runtime/acp、wire 和运行时锁版本不变。

## 升级须知

首次启动会执行 schema 63 数据库升级。升级前关闭应用并备份完整数据目录、
相邻 `notes/` 和设置文件。旧客户端回退需要恢复升级前备份。

## 发布门槛

完成发布说明校验、测试、三套 typecheck 和 lint 后，推送候选到 `origin` 与 `github`，
要求精确候选的主分支 CI 和生产构建通过，再创建不可变的 `v0.16.2` 标签。
本轮不构建或发布 LoongArch，也不创建新的 Agent 标签。
