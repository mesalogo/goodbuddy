标准六平台 Desktop、三平台 Agent，不含 LoongArch。

## 范围与升级边界

- 无模式执行：删除 Ask/Execute、安全设置分类及通用 toolApproval，
  普通请求使用启用能力和执行账号权限，内部文本任务保持无工具。
  旧 Ask 会话不再有产品只读隔离，必须在发布说明中明确。
- schema 59 增加状态计时和会话汇总索引，不扫描旧历史补算时长；
  schema 60 按已知 JSON 路径分批清理工作模式，并删除三列。
  保留正文、图片、稳定引用、远程去重身份；损坏元数据可见失败并保留已提交批次。
  Runtime 设置 22 清理顶层 toolApproval，保持加密凭据字节，不递归删除同名用户字段。
- 升级前关闭应用，备份完整数据目录（数据库、相邻 notes 与设置），
  大库可能耗时，回退须恢复升级前备份。0.15.10 的 NORMAL/FULL 边界不变。
- 远程 runtime/acp 能力从 5 升到 6，新增工作区 importFile 动作及时间字段；
  Continue helper 采用原生 agent。Agent 必须升级 0.15.4，最低 Desktop 0.15.11；
  wire major/minor 保持 2.0，Node/OpenCode/Continue 锁不变。
  更新前处理活动任务，不声称覆盖旧操作跨版本恢复。
- 工作区分块导入二进制与空文件，同名不覆盖，失败项独立反馈；按名称和时间排序。
  每目录最多读取 500 条，排序只覆盖已读条目，无传输中取消和百分比。
  移除成果页不删除数据库成果，不自动把会话附件或图片复制到项目目录。
- 图片仅消息引用也可发现，生成关闭时仍可保存；远程专家保持父请求执行空间。
- 项目菜单默认全部项目、归档恢复和明确进入，新本地项目必选目录、
  远程目录符号链接、OCR 提供方与 PPTX 图片位置诊断、完整输入缓存率。
- 回顾来源初始化和续跑移到 Worker；不宣称最后发布大事务已移出 Main。
  历史选择与布局统一，真实区间按主故事着色，空档中性、无归属事件保留；
  消息密度来自当前消息/小时桶，非历史快照，不补造故事归属。
