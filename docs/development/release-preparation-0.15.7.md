# Desktop 0.15.7 发布准备

日期：2026-10-01。基线为 `v0.15.6`，源码候选 `c8f327f`。
检查时工作区干净，用户要求纳入的先前改动已由该提交包含，共 75 文件。
本轮 Desktop 升至 0.15.7，Agent 保持 0.15.1，仅标准六平台，不含 LoongArch。

## 范围

- 流式 Markdown 分段复用、会话行与派生值缓存。默认 16ms 节奏不变。
- 运行记录进入时读取、可见时 15 秒刷新及页头手动刷新，不是逐事件实时视图。
- 本地自定义 MCP 发现与动态目录故障按服务隔离，取消和撤销仍生效。
- 模型连接中的受管模型下载源弹窗，确认保存、取消不变及相关入口统一。
- 设备共享默认关闭的测试入口，显式启用，关闭不撤销服务端记录。

网关修改只涉及本地自定义 MCP 发现方法；远程 Agent 的独立 MCP 实现与
Story Graph 绑定不经过这些方法，Agent 源码、锁及包未变。边界与开发验证见
[工作栏进度](../features/assistant-workbar/progress.md)。
数据库仍为 schema 52，无新增迁移。

## 证据与发布门槛

本轮遵照用户要求，不运行本地测试、类型检查、lint 或生产构建，由新候选 CI 验证。
已有开发会话记录不等于本候选全仓通过；网关会话的历史全仓失败也不掩盖。
流式输入测量见 [组件测量记录](../../tests/support/streaming-input-results.md)，
不据此声称完整 App 或所有机器的相同比例提速。本轮外部模型调用为 0。

中英文 FEATURES 已核对设备共享默认值、下载源位置及实现边界，并补充本轮性能和活动行为。
发布说明保留 schema 52 备份提醒，不修改历史已发布条目。
双远端推送精确候选后，必须通过主分支全量验证与生产构建，并确认候选及双语说明后，
才能创建不可变 `v0.15.7` 标签。
