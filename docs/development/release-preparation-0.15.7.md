## 范围

- 流式 Markdown 分段复用、会话行与派生值缓存。默认 16ms 节奏不变。
- 运行记录进入时读取、可见时 15 秒刷新及页头手动刷新，不是逐事件实时视图。
- 本地自定义 MCP 发现与动态目录故障按服务隔离，取消和撤销仍生效。
- 模型连接中的受管模型下载源弹窗，确认保存、取消不变及相关入口统一。
- 设备共享默认关闭的测试入口，显式启用，关闭不撤销服务端记录。

网关修改只涉及本地自定义 MCP 发现方法；远程 Agent 的独立 MCP 实现与
Story Graph 绑定不经过这些方法，Agent 源码、锁及包未变。边界与开发验证见
[工作栏进度](../features/assistant-workbar/progress.md)。
数据库仍为 schema 52，无新增迁移。

本轮遵照用户要求，不运行本地测试、类型检查、lint 或生产构建，由新候选 CI 验证。
