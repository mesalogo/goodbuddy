# Desktop 0.16.1 发布准备

日期：2026-10-10。基线 `v0.16.0`，候选源码包含 `d9dcb65d` 和 `c7f09e1e`
两个 Composer 视觉修复提交。本候选只更新 Desktop；Agent 保持 `0.15.6`，
不创建新的 Agent 标签。标准六平台 Desktop，不含 LoongArch。

## 范围与兼容性

- 消息内容延伸到 Composer 输入框轮廓前再淡出，不再被输入区上方的实色区域提前截断。
- 浅色和深色主题使用匹配的消息到输入框渐变，输入框焦点边界不再形成粗边。
- 滚动到底部按钮保持与新的输入区过渡相配的可见位置。
- 不新增数据库 schema，Agent、runtime/acp、wire 和运行时锁版本不变。

## 发布门槛

完成发布说明校验、测试、三套 typecheck 和 lint 后，推送候选到 `origin` 与 `github`，
要求精确候选的主分支 CI 和生产构建通过，再创建不可变的 `v0.16.1` 标签。
本轮不构建或发布 LoongArch，也不创建新的 Agent 标签。
