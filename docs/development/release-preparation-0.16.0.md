# Desktop 0.16.0 发布准备

日期：2026-10-09。基线 `v0.15.14`，候选源码为本次发布准备提交。
本候选只更新 Desktop；Agent 保持 `0.15.6`，不创建新的 Agent 标签。标准六平台 Desktop，
不含 LoongArch。

## 范围与兼容性

- 专家和团队角色选择移动到 Composer 输入框顶部，发送前更容易发现。
- 角色选择按会话保存，切换会话不会带入其他会话的选择。
- 历史消息保留请求发送时使用的角色，即使角色后来重命名或删除，历史上下文仍可识别。
- 不新增数据库 schema，Agent、runtime/acp、wire 和运行时锁版本不变。

## 验证边界

本候选包含 Composer、会话选择状态、历史消息元数据和角色选择的回归测试。
完整跨平台安装、远程 Host 和未覆盖的整包验收仍以 CI 与发布工作流结果为准。

## 发布门槛

完成发布说明校验、测试、三套 typecheck 和 lint 后，推送候选到 `origin` 与 `github`，
要求精确候选的主分支 CI 和生产构建通过，再由用户确认后创建不可变的 `v0.16.0` 标签。
本轮不构建或发布 LoongArch，也不创建新的 Agent 标签。
