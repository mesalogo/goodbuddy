# 用户故事

本期角色为使用本机笔记的桌面用户，以及替用户调用工具的会话助手。需求定义见[PRD](./prd.md)。下表描述验收条件，不表示场景已经通过。

| ID | 场景与需求 | Given（前提） | When（动作） | Then（预期结果） |
| --- | --- | --- | --- | --- |
| US-1 | 首次检查，FR-1、FR-2、FR-7 | 本机有已注册仓库，功能尚未启用 | 用户进入 MCP 设置并测试默认范围 | 开关保持关闭；返回注册仓库列表和工具数；未保存配置，也未改动笔记 |
| US-2 | 指定草稿范围，FR-2、FR-6、FR-7 | 用户选择一个未注册文件夹，尚未保存 | 用户测试该草稿 | 仅探测此文件夹；已保存范围及启用状态不变 |
| US-3 | 保存与恢复默认，FR-1、FR-2 | 用户已测试指定文件夹 | 保存后重新进入设置，再切换为全部仓库并保存 | 保存结果可重新加载；恢复默认时保存空 `vaultPath`；两次保存均不自动启用 |
| US-4 | 单仓库日常操作，FR-4、FR-9 | 功能已启用并分配给当前会话，范围只有一个仓库 | 助手读取、修改并再次读取笔记 | 写回当前唯一仓库，结果可从文件核验；无需额外 Obsidian 审批 |
| US-5 | 多仓库同名文件，FR-3 | 有两个仓库，都包含 `daily.md` | 助手先取得仓库 ID，再指定其中一个修改；另行尝试省略 ID 或传入无效 ID | 明确 ID 的请求仅作用于对应仓库；另两次调用返回错误，两个仓库均不因失败请求改变 |
| US-6 | 离线与关闭 Obsidian，FR-5、FR-6 | 安装包已有依赖，Obsidian 未运行，系统未安装 Node，网络断开 | 使用内置服务测试、读取和写入测试仓库 | 本地操作通过现有托管 Node 完成，不请求 npm，也不要求插件；模型联网另行验证 |
| US-7 | 范围失败恢复，FR-8 | 注册文件缺失或含失效路径，或者草稿路径不可访问 | 用户测试后改为有效文件夹并重试 | 显示具体原因，保留输入；重试使用新草稿，不偷偷跳过坏仓库或切换目标 |
| US-8 | 取消与失败保留，FR-8 | 用户正在编辑草稿或执行会话工具 | 取消文件夹选择、遇到保存失败，或取消会话工具 | 选择取消和保存失败均保留草稿；工具取消关闭对应进程，不报告成功，也不宣称回滚已发生的写入 |
| US-9 | 既有能力规则，FR-4、FR-9 | 功能启用且已分配 | 助手请求写入，再关闭能力后请求写入 | 启用时正常执行，关闭后不能绕过设置；不增加 Obsidian 专用开关、过滤或审批 |
| US-10 | 旧配置与分配，FR-1、FR-9 | 旧配置没有 Obsidian 字段，已有其他 MCP 配置 | 加载设置并修改 Obsidian 分配 | Obsidian 默认关闭，其他配置保留；修改分配不改写仓库范围；未分配的会话不可调用 |
| US-11 | 上游能力完整，FR-4 | 启用接入并分配给受支持 Runtime | 获取工具集合并对照 MCPVault 0.16.0 | 18 个上游工具均有可调用映射，参数能力保留；仓库发现辅助工具不计入这 18 个 |
| US-12 | 设置变更与旧调用，FR-10 | 有含 Obsidian 的旧请求授权和正在执行的工具 | 提交保存范围、切换开关或修改分配，随后关闭网关 | 旧授权失效，在途调用收到取消；网关等待工具关闭。保存失败也不恢复旧授权；后续请求按实际保存状态重新取得授权 |

跨平台注册路径和安装包测试分别取证。通过模拟平台字符串测试注册路径，不等于在对应操作系统上完成安装包验收。
