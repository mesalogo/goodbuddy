# 功能逻辑

## 状态维度

启用状态、Runtime 分配、已保存范围和页面草稿分别管理。启用状态不表示服务已连接，测试成功也不表示会话可调用。会话使用已保存范围；测试使用本次提交的草稿。

测试状态为未测试、测试中、成功或失败。修改草稿使先前测试结果失效；测试结果只描述该次请求，不持久化为服务健康状态。

## 规则与追溯

| ID | 规则 | 需求 / 故事 |
| --- | --- | --- |
| LR-1 | 仅启用操作改变启用状态；仅保存操作改变持久化范围；测试不改变二者。 | FR-1、FR-7；US-1～US-3 |
| LR-2 | 非空指定路径优先，完全绕过注册信息；空路径读取全部注册条目，忽略条目的打开状态。 | FR-2、FR-6；US-1、US-2、US-6 |
| LR-3 | 先解析当前范围，再校验 `vaultId`，成功后才启动目标仓库的工具进程。 | FR-3；US-5 |
| LR-4 | 上游能力完整保留；启用、分配和资源范围由既有会话入口执行，不另加 Obsidian 权限层。 | FR-4、FR-9；US-4、US-9～US-11 |
| LR-5 | 范围解析失败使本次请求失败，不跳过失效注册条目，不选择替代仓库。 | FR-8；US-7 |
| LR-6 | 测试仅发现仓库并列举工具，逐仓库连接；工具数按上游名称去重，不按仓库数相乘。 | FR-7；US-1、US-2 |
| LR-7 | 操作结束或取消后关闭本次 MCP 连接和子进程；取消不承诺撤销已落盘写入。 | FR-8；US-8 |
| LR-8 | 保存范围、切换开关和修改分配在输入校验后、持久化前撤销含 Obsidian 的旧请求授权并取消在途调用；网关销毁等待活动调用清理。 | FR-10；US-12 |

## 仓库决策

| 条件 | 结果 |
| --- | --- |
| 指定路径非空 | 验证为可访问的绝对目录，得到单仓库范围 |
| 默认范围且注册信息有效 | 使用全部注册条目，保留各自注册 ID |
| 注册文件不可读、无条目、条目无路径或任一目录不可访问 | 返回对应错误；用户可修复注册信息或选择文件夹 |
| 范围只有一个仓库且请求省略 ID | 使用唯一仓库 |
| 范围超过一个仓库且请求省略 ID | 拒绝调用，要求明确 ID |
| 请求提供 ID 且属于当前范围 | 使用该 ID 对应仓库 |
| 请求 ID 不属于当前范围 | 拒绝调用，不回退到唯一仓库或首个仓库 |

工具清单描述与实际文件操作分开。服务可用首个仓库读取固定版本的工具 schema，这不赋予首个仓库任何默认写入地位。跨仓库搜索或修改由调用方对明确的仓库 ID 分别发起请求，不把一次请求广播到全部仓库。

## 设置转换

| 动作 | 草稿与结果 | 持久化影响 |
| --- | --- | --- |
| 选择文件夹 | 更新草稿，切换为指定文件夹，清除旧测试结果 | 无 |
| 取消文件夹选择 | 保留原草稿 | 无 |
| 切换范围或编辑路径 | 清除旧结果和关联错误；指定文件夹模式空路径时报错 | 无 |
| 测试 | 使用提交时的草稿；忙碌期间禁止重复提交，结束后显示结果或错误 | 无 |
| 保存成功 | 使用返回快照显示已保存范围，结束当前草稿编辑状态 | 仅范围 |
| 保存失败 | 保留草稿并显示错误，可修改后重试 | 已保存范围不变 |
| 启用、关闭或调整分配 | 更新对应状态，草稿不自动保存 | 仅对应状态 |

上表仅列持久化影响；涉及授权的副作用按 LR-8 执行。连接测试不提供独立取消按钮，其临时连接不持有会话授权。

## 授权撤销与清理

Main 对范围保存、开关和分配请求先验证来源及输入，再撤销现存的含 Obsidian 授权，随后保存设置。提交相同值也触发撤销。输入无效时在撤销前返回错误；持久化失败时原设置保留，但旧授权已经失效。草稿编辑、文件夹选择和连接测试均不触发此撤销。

撤销按整个请求授权执行。若同一个授权同时含 Obsidian 和知识库等能力，该授权整体失效；独立的不含 Obsidian 授权保留。后续请求按当前保存的范围、开关和分配重新取得授权；关闭后不再签发 Obsidian 能力。

撤销会立即移除旧授权并发出取消信号，设置响应不等待子进程完全退出。工具调用负责在结束路径关闭 transport 和 client；网关销毁则等待活动调用完成清理，包含先前已撤销但仍在关闭的调用。取消过程中已落盘的内容保留。
