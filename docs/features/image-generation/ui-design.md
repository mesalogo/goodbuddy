# 图片上下文提示

遵循根目录 [UI-DESIGN.md](../../../UI-DESIGN.md)。

- 仅在某次成功生成确实缺少部分上下文时，在对应助手回复底部显示低强调文字。
  正常使用上下文不显示警告，也不声称上游“不支持上下文”。
- `reference-unavailable`：部分历史图片无法读取，本次仅使用可用的图片与文字上下文。
- `editing-unavailable`：上游不支持图片编辑，本次按文字要求生成，未使用参考图片。
- 使用共享 `--text-muted`、`--font-caption` 和间距令牌。不加警告卡片、闪烁、
  `alert`、`aria-live`、弹窗或应用通知。文本保留在消息中并随会话恢复。
- 发送和生成继续可用；真实请求失败仍采用原来的错误及重试交互，不生成成功提示。
- 文案具备简体中文、英文两套翻译。本轮显式附图和新对话继续使用现有入口，
  不增加模式开关或第二次确认。
