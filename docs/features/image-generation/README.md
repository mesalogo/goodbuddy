# 图片生成与连续修改

本目录维护直连图片模型的生成、参考图编辑和会话续接行为。这是已有生图流程的修复，
不增加独立模型、工具审批或服务端会话管理。

## 产品行为

- 首次无附图时生成新图片。同一桌面对话继续请求时，自动引用最近一次成功回复的图片，
  同时发送此前的文字要求；本轮修改要求优先。
- 本轮显式附图优先，不自动混入上一轮生成图。要独立生成不相关图片，使用新对话。
- 已保存会话重新打开后仍可继续改图，引用已有成果，不依赖 Runtime 内存缓存。
- 上游明确不支持编辑时，继续按文字生成，并在该回复底部说明未使用参考图片。
  缺失历史成果时使用剩余可用上下文并提示，不禁用发送。
- 网络、鉴权、限流、参数错误和真正的生成失败仍正常报错，不伪装成能力缺失。
- 模型 ID、地址和质量服从用户的模型连接配置，不对特定服务商或模型别名做硬编码。
  验证以用户指定的 `sub-gpt-image-2` 实际服务能力为准，不由其他模型的失败推断其能力。
