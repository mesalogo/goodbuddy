# 界面设计

遵守 [统一界面设计系统](../../../UI-DESIGN.md)，落实 FR-1 至 FR-6。

用户消息的编辑按钮右侧提供复制按钮，复制该消息正文。与助手消息共用图标、样式及反馈：成功后显示绿色对号，3 秒后恢复复制图标。

用户消息提供“编辑”动作。点击后打开共享表单 Modal，展示原正文和附件，操作为“取消”“保存并重新回复”。Modal 复用 `custom-task-dialog` 的布局、焦点循环和背景隔离，避免长消息的编辑器改变历史列表的窗口化范围。编辑内容独立于底部输入草稿，状态位于消息窗口化列表之外。

就近提示：“将从此处创建新分支并重新回复，原对话会保留。已执行的文件和外部操作不会撤销。”源会话忙碌、空输入、附件处理和提交中的状态须有文字说明。

进入编辑时焦点进入正文；普通 Enter 换行，Ctrl/Cmd+Enter 提交，输入法组合输入不提交。取消后焦点返回原入口。失败在编辑区显示并允许恢复；同一错误不重复发通知。

新分支沿用分叉徽标和来源标题，提供返回原会话的入口。来源已删除时保留标题并说明不可打开。窄窗口按钮可换行，浅深主题使用现有令牌。
