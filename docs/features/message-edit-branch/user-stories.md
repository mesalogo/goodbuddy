# 用户故事

| 编号 | 场景 | 验收 |
| --- | --- | --- |
| US-1 | 修改第一条或中间用户消息 | 提交后新会话只包含正确前缀和新请求；原会话逐条保持不变；新回复不含旧后缀上下文。 |
| US-2 | 编辑附件消息 | 默认带回原附件；移除或添加后只发送最终选择；资源缺失时保留草稿并显示错误。 |
| US-3 | 取消或编辑长消息 | 创建分支前取消不写入；Modal 内滚动不丢输入；原底部草稿保持，背景视图在编辑期间隔离。 |
| US-4 | 保存或发送失败 | 保存失败仍可修改并重试；已创建分支的发送失败可在该分支恢复，避免无意义重复分支。 |
| US-5 | 正在生成或排队 | 编辑可准备，提交有明确不可用原因；结束后恢复；重复点击不重复提交。 |
| US-6 | 压缩后编辑及跨 Runtime | 新请求没有旧摘要和旧原生会话；前缀顺序正确；本机与 SSH 路径使用新会话身份。 |
| US-7 | 重启、删除原会话 | 新分支仍可打开，保留附件和工具全文；来源被删除时保留来源标题并明确无法返回。 |
| US-8 | 监督回顾 | 复制前缀保留来源标识，不重复计作新证据；编辑后的请求和新回复正常参与回顾。 |
| US-9 | 历史较长或外部通道 | 较早消息的分叉基于存储中的完整前缀；只读通道没有编辑动作。 |
