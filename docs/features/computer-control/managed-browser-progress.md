# 浏览器自动化升级实施记录

## 最终方向

按用户的后续修正，保留原生网页显示及原有普通浏览器界面，自动化改用 Playwright 1.64.1。已删除独立浏览器画面传输、Canvas、人工输入转发、接管／交还状态和上传下载工具栏。早期画面传输实验的通过结果不作为当前方案验收依据。

## 已验证

- 原生 WebContentsView 经公开 CDP 接口接入 Playwright，同一页面完成 AI 快照、中文填写、iframe 和自动滚动点击。
- `npm run test:browser`：真实 Electron、正式 Preload 和原生视口通过。100% 与 150% 系统缩放下，原生页面 CSS 尺寸、设备像素比和截图尺寸匹配，网页 zoomFactor 均为 1。
- 原生中文组合输入及粘贴无需切换模式，AI 后续能读到并修改同一字段；Renderer 中没有 Canvas、键盘代理或新增控制按钮。
- 取消等待中的按钮点击后再启用按钮，没有迟到点击；模型文件字段上传、原生下载保存、新窗口绑定及关闭同级隔离通过。
- 同一测试的 Linux Host 经 SSH 转发调用当前桌面 MCP 网关通过：发现 9 个工具，读取快照、填写原生页面并列出标签。外部模型调用数为 0。该证据不是完整远端 Agent／ACP 运行时部署验证。
- 浏览器、模型工具、MCP 网关、工作栏、共享契约与 Preload 定向回归：11 个文件、310 项通过。
- TypeScript 检查、lint、生产构建和原生 App 浮层复验已通过。

测试窗口关闭后台节流，并显式取得焦点，避免桌面其他窗口导致 requestAnimationFrame 被暂停。生产窗口策略保持原样。
