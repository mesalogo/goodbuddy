# 聊天历史导航

聊天历史导航负责长会话的连续滚动、窗口化渲染和对话 minimap。当前实现已经取消向上滚动时每次增加 80 条消息的产品限制，保留已有的消息窗口化机制，并用轻量 canvas 提供消息分布和快速定位。

## 术语

- **历史窗口**：允许滚动访问的消息范围。第一阶段扩大为当前已加载会话的全部消息。
- **DOM 窗口**：实际挂载消息组件的范围。继续由消息高度估算和最多约 60 条挂载消息控制。
- **minimap**：替代消息区原生滚动条的 canvas 全局概览，高度与滚动区一致，悬停时展开为较宽的缩略长图；不等于完整渲染所有消息。
