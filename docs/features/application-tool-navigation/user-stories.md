## 1. 角色

### 1.1 普通用户

使用对话、笔记和知识功能，希望常用入口稳定，不需要理解工作栏实例模型。

### 1.2 本地工作用户

经常查看项目文件、打开终端、使用受控浏览器或检查电脑负载，希望从任意一级页面快速进入
这些工具。

## 2. Epic A：固定系统入口

### US-A1 始终访问运行记录

作为用户，我希望运行记录保持在固定位置，以便应用入口变化后仍能检查 Agent 和工具活动。

验收：

- Given 用户隐藏任意内置应用
- When 用户查看主导航
- Then “运行记录”仍显示在应用区之后
- And 设置中没有隐藏、卸载或固定运行记录的选项

### US-A2 从固定入口进入设置

作为用户，我希望设置入口始终位于侧栏底部，以便快捷工具状态变化时仍能进入配置。

验收：

- Given 任意主页面和任意侧栏宽度
- When 用户查看侧栏底部
- Then 设置按钮保持可见且点击区域不与工具按钮重叠
- And 点击后继续遵守未保存内容的离开确认

## 3. Epic B：管理应用入口

### US-B1 识别完整应用

作为用户，我希望魔法笔记、知识库和智能心跳显示在主导航，以便知道它们会打开完整页面。

验收：

- Given 对应功能已启用且应用设置为显示
- When 用户打开主侧栏
- Then 应用位于“当前对话”和“运行记录”之间
- And 点击应用在主内容区打开对应一级页面
- And 原有待办或建议徽标继续显示

### US-B2 隐藏低频应用

作为用户，我希望隐藏不常用的内置应用，以便缩短主导航，但保留已有数据。

验收：

- Given 应用已有内容
- When 用户关闭该应用的“显示在侧边栏”Switch
- Then 主导航不再显示该应用
- And 应用数据、计划和业务启停状态不变
- And 用户可从同一设置位置恢复显示

### US-B4 保留功能启停语义

作为魔法笔记用户，我希望导航显隐与功能启停相互独立，以免整理导航时关闭功能。

验收：

- Given 魔法笔记功能已启用
- When 用户只隐藏其侧栏入口
- Then 笔记及待办处理能力继续按原设置工作
- And 再次显示时恢复原页面和数据

### US-B5 恢复显隐保存失败

作为用户，我希望入口设置保存失败时继续使用原导航，以免界面状态与实际设置不一致。

验收：

- Given 应用显隐更新尚未完成
- When 用户切换“显示在侧边栏”Switch
- Then 三个应用显隐 Switch 在请求期间暂时不可操作
- And 更新成功后主导航立即变化
- And 更新失败时 Switch 和主导航恢复原状态并显示可重试错误

## 4. Epic C：使用系统工具

### US-C1 一键查看文件

作为本地工作用户，我希望点击左下角文件按钮后直接查看当前工作区文件。

验收：

- Given 当前项目有有效根目录
- When 用户点击文件按钮
- Then 助手工作栏展开
- And 聚焦默认存在且不可关闭的工作区单实例
- And 文件按钮通过选中状态表明该面板正在显示

### US-C2 处理无效工作区

作为用户，我希望目录不可用时看到修复方法，并收到明确反馈。

验收：

- Given 工作区面板处于跟随模式
- And 当前项目和默认工作区均不可用
- When 用户点击文件按钮
- Then 工作区面板仍打开
- And 面板说明目录不可用并提供选择或修复目录的入口
- And 应用不静默改用其他目录

### US-C3 快速进入终端

作为本地工作用户，我希望点击终端按钮后进入当前执行空间的终端。

验收：

- Given 当前执行空间已有正在启动或运行中的终端
- When 用户点击终端按钮
- Then 工作栏聚焦最近使用的匹配终端，不创建重复实例
- Given 当前执行空间没有终端
- When 用户点击终端按钮
- Then 创建一个绑定该执行空间的新终端
- Given 当前没有项目
- When 用户点击终端按钮
- Then 创建或聚焦使用本机 Home 的终端
- Given 当前执行空间只有已退出、已中断或失败的终端
- When 用户点击终端按钮
- Then 创建新终端并保留原终端的历史状态

### US-C4 使用远程项目终端

作为远程项目用户，我希望同一个终端按钮进入远程项目目录，以免误在本机执行命令。

验收：

- Given 当前项目绑定托管 SSH 执行空间
- When 用户点击终端按钮
- Then 创建或聚焦绑定该远程项目及其权威目录的终端
- And 面板持续显示远程主机和工作目录
- And 连接失败时保留重连与诊断信息

### US-C5 打开受控浏览器

作为用户，我希望浏览器按钮打开 GoodBuddy 受控浏览器，以便查看与 Agent 相同的会话。

验收：

- Given 浏览器面板跟随当前上下文且当前会话已有浏览器会话
- When 用户点击浏览器按钮
- Then 工作栏聚焦绑定当前 Conversation 的最近使用浏览器实例
- And 不打开系统默认浏览器或无意创建重复实例
- Given 现有浏览器实例都绑定到其他 Conversation
- When 用户点击浏览器按钮
- Then 工作栏创建并聚焦绑定当前 Conversation 的新浏览器实例
- Given 当前没有活动 Conversation
- And 已存在浏览器实例
- When 用户点击浏览器按钮
- Then 工作栏聚焦最近使用的浏览器实例并保持其目标
- Given 当前没有活动 Conversation
- And 不存在浏览器实例
- When 用户点击浏览器按钮
- Then 创建待选择目标的空实例
- Given 用户需要同一 Conversation 的另一个独立页面
- When 用户从工作栏“+”选择浏览器
- Then 每次创建拥有独立页面和导航状态的新实例
- And 同一 Conversation 内共享隔离登录上下文

### US-C6 查看本机资源

作为本地工作用户，我希望快速查看 CPU、内存和磁盘 IO，以便判断任务变慢是否与本机负载
有关。

验收：

- Given 资源监控面板尚未打开
- When 用户点击左下角资源监控按钮
- Then 助手工作栏创建并激活单实例资源监控面板
- And 页面显示整机 CPU、内存、磁盘读写及 GoodBuddy 桌面进程摘要
- And 页面每 2 秒更新一次，并用图表保留最近 5 分钟
- When 用户切换到其他工作栏 Tab、收起工作栏、隐藏窗口或最小化窗口
- Then 资源监控停止请求新样本
- When 用户再次显示窗口并返回资源监控
- Then 首次采样建立区间指标基线，下一次采样开始显示 CPU 和磁盘 IO 速率
- Given 某项指标在当前平台不可用
- When 页面收到部分结果
- Then 该指标显示“不可用”及原因，其他指标继续更新

### US-C7 从任意应用打开工具

作为用户，我希望在魔法笔记、知识库、智能心跳和运行记录页面也能打开系统工具。

验收：

- Given 用户位于任意一级页面
- When 用户点击文件、终端、浏览器或资源监控
- Then 主页面保持不变
- And 右侧工作栏打开对应面板
- And 工具不会覆盖主内容或伪装成一级页面

## 5. Epic D：可访问性和布局

### US-D1 使用键盘打开系统工具

作为键盘用户，我希望按顺序聚焦并打开左下角工具，以便不依赖鼠标。

验收：

- 每个系统工具和设置都是独立按钮
- Tab 顺序与视觉顺序一致
- Enter 和 Space 均可激活按钮
- 每个纯图标按钮都有可访问名称和工具提示
- 焦点样式不被侧栏边界裁切

### US-D2 在窄窗口使用快捷栏

作为小屏用户，我希望侧栏抽屉中的工具按钮保持可操作。

验收：

- 工具按钮保持单行且不重叠
- 不因宽度不足隐藏文件、终端、浏览器、资源监控或设置
- 触控点击区域符合统一界面规范
- 关闭侧栏抽屉后焦点返回原触发按钮

## 6. Epic E：项目活动级联

### US-E1 从摘要进入确切会话

对应 [FR-14](./prd.md#fr-14-项目活动汇总)。用户在当前项目工作时，可从项目选择器下方
查看跨项目活动，先定位项目，再进入需要处理的会话。

- Given 多个项目存在运行中和待处理会话，当前搜索仅匹配当前项目
- When 打开全项目活动并悬停或点击另一个项目
- Then 项目顺序保持稳定，该项目会话按待处理优先展示，当前页面和会话保持原选择
- When 点击会话
- Then 进入该确切 Conversation ID，清除搜索、任务选择和会话菜单，窄窗口关闭侧栏
- Given 设置页有未保存修改
- Then 会话跳转仍需通过既有离开检查，取消离开保留设置草稿和原项目

### US-E2 键盘、窄窗口与实时结束

- Given 菜单已打开
- Then 上下方向键与 Home、End 选择当前层，右方向键或 Enter 进入会话层，左方向键或
  Escape 返回；再次 Escape 关闭活动菜单并恢复摘要焦点，窄侧栏保持打开
- Given 窗口小于 `620px`
- Then 点击项目后仅显示会话层，可通过返回按钮回到项目列表；长列表可滚动到最后一项
- Given 鼠标从项目行移向相接的会话面板
- Then 子菜单保持打开，点击会话正常导航
- Given 当前项目已无待处理、运行中或已完成未查看会话
- Then 返回项目层并恢复可用焦点；全局无活动时整行隐藏摘要并关闭菜单，新活动到来时只恢复摘要
- When 点击外部、焦点离开、按 Tab 或隐藏侧栏
- Then 菜单关闭，后台新活动不自动重新展开

### US-E3 完成后保留至查看

对应 [FR-14](./prd.md#fr-14-项目活动汇总)，具体状态规则见[活动逻辑](./logic-design.md#9-项目活动汇总)。

- Given 用户正在其他会话或应用中工作
- When 本次应用会话内的运行成功完成，或已观察到的后台任务转为完成
- Then 活动会话保留为“已完成”，全局与项目的已完成计数同步更新
- When 从活动菜单或普通侧栏实际进入该会话的可见聊天
- Then 清除其完成通知；没有其他活动行时隐藏摘要并关闭菜单
- Given 聊天被设置覆盖或文档隐藏
- When 对应运行完成
- Then 完成通知保留，直到设置关闭且目标聊天在可见文档中显示；取消设置离开不清除通知
- Given 目标聊天已可见且未被设置覆盖
- When 运行成功完成
- Then 不保留该会话的完成通知
- Given 初始加载已完成任务历史，或任务失败、取消
- Then 不产生新的完成通知；重载或重启也不恢复上一应用会话的通知
- Given 同一会话仍有待处理或运行中工作
- Then 按实时状态优先展示，只计入一个类别

## 7. 后续需求场景

本节对应新增计划，不计入应用中心首期完成条件。

### US-F1 连接组织应用市场

对应 [FR-15](./prd.md#fr-15-私有化市场与-yaml-交换后续)。

- Given 组织已部署提供应用市场的 ShareServer
- When 用户配置市场 URL，并在来源要求时完成登录
- Then 可以浏览该来源的应用目录、详情及可获取版本
- Given 市场暂时不可达
- Then 显示失败原因与重试入口，已安装和内置应用仍可打开，不切换公共市场

### US-F2 导入导出应用定义

对应 FR-15。

- Given 用户需要在私有部署间迁移应用
- When 导出应用为 `.yml` 并在另一台设备导入
- Then 预览应用身份、版本、可迁移配置和依赖，凭据与业务数据不包含在导出文件中
- Given 同标识应用已存在
- Then 用户可选择更新或取消，取消后原应用与配置保持不变
- Given 文件格式无效、版本不支持或离线环境缺失程序包或模型资源
- Then 显示具体问题与补充要求，不将应用误报为可运行，也不自动启动模型或任务

### US-F3 管理本机模型服务

对应 [FR-16](./prd.md#fr-16-本机模型管理入口新增计划项)。

- Given 用户使用依赖本机模型的应用
- When 从应用中心或常驻菜单打开“本机模型”
- Then 可查看已接入模型的状态、管理方式及使用方，两处入口访问同一页面
- Given 多个应用共用一个 GoodBuddy 受管模型服务
- Then 展示同一服务及使用方，启动操作不重复创建进程
- When 用户停止或重启仍有任务使用的受管服务
- Then 先展示任务影响供用户决定，取消后服务保持运行；操作失败显示原因与实际状态
- Given 模型服务由外部程序启动，且未接入其管理接口
- Then 展示“外部管理”与连接配置，不提供停止或重启
- When 用户关闭管理页或取消常驻
- Then 模型运行状态不变
