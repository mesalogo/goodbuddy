# 应用导航与系统工具入口

本功能整理 GoodBuddy 主侧栏的入口层级：系统入口保持固定，五个内置应用共用可调整的保存顺序，知识库始终启用并常驻；
智能心跳、魔法笔记和本机推理监控可通过应用管理控制启用和常驻。底部“应用”向上展开轻量锚定菜单，列出已启用应用；底部“管理应用”打开既有“应用中心”管理 Modal。系统工具由右侧工作栏 Tab 承载。应用商店是后续功能，首期不提供
商店入口、推荐位或安装流程。

设备共享作为第五项追加到原有应用顺序，测试阶段默认关闭，启用后可从菜单和管理 Modal 打开，不提供常驻
开关；服务地址与设备名称在其页面保存。首期仅支持本地服务的设备注册与元数据目录，详见
[设备共享](../device-sharing/README.md)。

当前分期见 [PRD 第 8 节](./prd.md#8-分期)，实施步骤见[技术设计第 11 节](./technical-design.md#11-实施顺序)。
本轮 A–D 已接入生产源码：应用菜单、应用管理 Modal、共享应用设置、持久化偏好及本机推理监控。菜单不按打开历史或常驻状态筛选，无模态遮罩；点击应用行关闭菜单，知识库、智能心跳和魔法笔记打开主内容区页面。本机推理监控从菜单、常驻入口或管理 Modal 打开时均使用独立 Modal，保留底层工作区。管理列表、菜单和侧栏按同一保存顺序排列，侧栏按启用和常驻过滤。知识库在管理 Modal 中提供“打开”和排序，不提供启用、常驻开关或通用空设置；原工作区配置及心跳单条计划 enabled 保持原义。验证范围及集成缺口见[实施进度](./progress.md)。

新增计划包括 [私有化市场与 YAML 交换](./prd.md#fr-15-私有化市场与-yaml-交换后续)：
通过市场 URL 获取应用，支持 `.yml` 导入导出，未来由 ShareServer 提供私有目录与分发。
[本机模型管理入口](./prd.md#fr-16-本机模型管理入口新增计划项)已独立于商店接入，作为
可常驻左侧的“本机推理监控”（英文 Local Inference Monitor）内置应用，直接查看语音、OCR、向量等本机服务状态与可用资源指标，不显示任务历史。向量服务显示独立进程的 CPU 和工作集内存；ASR、OCR 与宿主共享进程，逐行说明无法独立统计的原因。
本轮已接入 `local-inference` 管理 Modal、类型化 IPC、真实请求登记及引擎管理；实际支持清单见
[技术设计](./technical-design.md#111-本机推理任务与执行服务)，市场仍为后续需求。
相关验收见 [User Stories](./user-stories.md#7-后续需求场景)。

项目活动汇总独立于上述应用中心计划，范围见 [FR-14](./prd.md#fr-14-项目活动汇总)。
生产项目入口是一个固定双行按钮：第一行显示项目名，第二行显示全局活动或“暂无活动”，点击任一行都打开统一工作空间菜单并默认预览当前项目。项目分类依次为“全部项目、本地、远程、消息通道”，点击“全部项目”切换全局范围，悬停预览会话，点击项目直接进入。生产最近会话上限为 10 条，验证状态见实施进度。
计数规则由[活动逻辑](./logic-design.md#9-项目活动汇总)定义，统一菜单见
[活动界面](./ui-design.md#10-项目活动汇总)，数据加载与会话跳转见
[技术设计](./technical-design.md#12-项目活动汇总)。此处“活动”包括当前运行、待处理及本次客户端
会话内已完成但未查看的会话；完成提示在实际进入聊天后清除，不累计历史完成总数。

工作空间 Demo 可直接打开，展示项目工作空间、会话窗口、全局活动、状态筛选、待办处理与完成待查看。
左上角项目和活动摘要打开同一个锚定下拉菜单，没有独立总览页面或全屏遮罩。左栏筛选项目，右栏按状态分组显示紧凑会话列表，列表在菜单内滚动。
菜单桌面宽度扩至 920px、高度至 640px，并受视口约束；左栏按本地项目、远程项目、消息通道分组。远程项目按主机归属展示，主机连接状态与会话活动计数分开；分组、主机和通道均使用演示数据。
左侧通过本地、远程、消息通道 Tab 点击切换分类，项目悬停预览；演示包含 20 个本地项目、20 个远程项目和 3 个消息通道。搜索跨分类匹配项目名、主机及类型，远程主机分组支持折叠。“全部项目”、搜索和分类固定，项目列表独立滚动。
项目行最小高度 52px，无活动时显示名称、工作目录两行；有活动时显示名称、活动状态、工作目录三行，高度随内容增长。当前项目以勾选区分于悬停预览。设置按钮独立，悬停或聚焦显示，触屏常显。设置弹窗可修改演示名称、说明、目录、默认模式及 Runtime；通道名称只读，执行空间不可修改。所有目录均为示例路径，不访问文件系统；原型未模拟真实目录选择、归档删除或远程恢复流程。
点击项目入口默认筛选当前项目，点击活动摘要查看全部项目；悬停左侧项目只预览右侧会话。点击项目直接进入并恢复上次打开的会话，尚无会话则创建新会话；点击右侧会话直接进入指定会话。设置按钮独立，不触发项目切换，会话草稿保留。
支持浅深主题、窄屏、点击外部关闭、Escape 关闭及 `Ctrl/Command+Shift+K` 切换菜单。
菜单底部“新建项目”展开名称表单，创建后进入新项目的首个会话；“新建会话”与状态筛选同排，在所选项目创建会话，全部项目视图下使用当前项目。窄屏状态筛选横向滚动，创建按钮保持可见。均只修改演示数据，重置后清除。
页面顶部可模拟后台完成，进入会话后清除该会话的完成提醒；已查看会话仍保留在最近会话中，不额外标记状态。
状态沿用正式活动入口：待处理、运行中、已完成；待处理会话区分“等待你的回答”和“等待审批”。不提供“可继续”状态或筛选。“已完成”仍表示完成未查看提醒，不是全部历史完成会话。
默认列表将待处理、运行中置顶，其余会话归入“最近会话”，按最近进入、发送或状态更新排序，最多显示 5 条；完成未查看在会话行标注。待处理和运行中不受此上限限制，也不重复列入最近会话。“已完成”筛选展示全部未查看结果，不受最近 5 条限制。没有活动时仍显示最近会话。
所有执行、审批和消息均为内存中的模拟，不访问真实项目、不调用 AI；该候选方案尚未接入正式产品。

知识库关闭时同步隐藏侧栏入口、会话选项中的知识范围和检索方式、已选知识标签；重新开启

通用应用设置统一从应用中心卡片进入，应用页面和全局设置不提供重复入口，分别控制
启用与常驻。魔法笔记面板另含显示未完成待办数量、AI 评论方式
（即时／保存后自动／保存后手动）、AI 评论形式（长评 + 要点／长评／要点）。现有“显示
魔法笔记入口”不在原型中重复提供。正式迁移保留其业务启用值，常驻使用独立配置。启用、常驻、待办数量显示默认开启；
评论方式默认即时，评论形式默认长评 + 要点。侧栏待办数为固定的 3 项演示数据。
修改即时生效于原型，不调用 AI 或写入真实应用设置。

引擎和管理方式收进详情；受管进程模拟启动、停止、重启，进程内模型模拟加载与释放。
服务停止或重启后任务标为中断，重新启动不自动恢复任务；任务级取消仍待实际引擎接入。
影响使用方的操作先显示就地确认，取消保留原状态；隐藏或关闭管理应用不改变服务状态。

预览，明确标为 mock schema，仅识别示例中的七个扁平字段，尚非通用 YAML 解析器。

## 术语

| 术语 | 定义 |
| --- | --- |
| 系统入口 | GoodBuddy 工作流程或审计所必需的固定入口，用户不能卸载、隐藏或改变类型 |
| 应用 | 可显示在主导航区的功能；知识库、智能心跳和魔法笔记打开一级页面，本机推理监控打开保留底层工作区的 Modal |
| 系统工具 | GoodBuddy 自带且不可卸载的辅助能力，包括文件、终端、浏览器和资源监控，由右侧助手工作栏 Tab 承载 |
| 插件应用 | 未来由插件提供的一级页面入口 |
| 插件工具 | 未来由插件提供的辅助面板或命令入口 |
| 快捷入口 | 只负责打开或聚焦能力，不复制该能力的界面和业务状态 |
