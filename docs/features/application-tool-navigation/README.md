# 应用导航与系统工具入口

本功能整理 GoodBuddy 主侧栏的入口层级：系统入口保持固定，应用占用主导航，系统工具从
侧栏底部快捷打开助手工作栏。该功能同时为后续插件应用和插件工具预留统一的入口类型，但
不包含插件市场的安装与运行机制。

## 术语

| 术语 | 定义 |
| --- | --- |
| 系统入口 | GoodBuddy 工作流程或审计所必需的固定入口，用户不能卸载、隐藏或改变类型 |
| 应用 | 在主内容区打开完整一级页面的功能，可显示在“当前对话”所在的主导航区 |
| 系统工具 | GoodBuddy 自带且不可卸载的辅助能力，从侧栏底部打开助手工作栏中的对应面板 |
| 插件应用 | 未来由插件提供的一级页面入口 |
| 插件工具 | 未来由插件提供的辅助面板或命令入口 |
| 快捷入口 | 只负责打开或聚焦能力，不复制该能力的界面和业务状态 |
