# 应用导航与系统工具入口

本功能整理 GoodBuddy 主侧栏的入口层级：系统入口保持固定，应用占用主导航，系统工具从
侧栏底部快捷打开助手工作栏。该功能同时为后续插件应用和插件工具预留统一的入口类型，但
不包含插件市场的安装与运行机制。

Demo 可直接在浏览器中打开，支持方案切换、浅深主题、添加、移除、排序和商店模拟。
六个方案共用本次页面会话内的应用配置，刷新后恢复默认。商店、资源指标和工具内容均为
演示数据，不执行真实安装或本机操作。窄屏上下排列侧栏与输入区，桌面展示完整应用布局。
底部输入区共用一个简化候选布局：附件、语音、Runtime、模式和发送位于主操作行，专家、
知识范围及 Runtime 专属选项通过“选项”展开，非默认选择显示为可移除标签。可体验文件名
附件、模拟语音、模板填入、原生命令选择、8 秒模拟回复、发送排队、立即插入、删除、停止，
以及上下文详情和模拟压缩。文件只读取名称，语音使用固定示例文本，不录音、不上传、不调用 AI。
这是输入区设计讨论用的原型，尚未改变正式产品或替代现有 UI 规范。

六个方案共用“我的应用”区：通过 ＋ 或“全部应用”选择常驻应用，编辑时可拖动或使用
上下箭头排序、移除入口。未常驻的已安装应用仍可从“全部应用”打开。商店包含“项目管理”
和“阅读空间”应用示例，支持仅安装或安装并常驻左侧菜单，常驻不表示后台运行。
常驻应用在本次页面会话内跨方案保持一致；“恢复默认应用”重置安装与常驻配置。
移除入口不会卸载应用或关闭当前页面，刷新后恢复默认。

魔法笔记提供应用中心“设置”、笔记页面“笔记设置”和全局设置演示入口，均打开同一设置
面板，共用本次页面会话内的配置。面板沿用现有选项：显示未完成待办数量、AI 评论方式
（即时／保存后自动／保存后手动）、AI 评论形式（长评 + 要点／长评／要点）。现有“显示
魔法笔记入口”在原型中与“常驻左侧菜单”统一，不额外增加功能启停开关。侧栏待办数为
固定的 3 项演示数据。修改即时生效于原型，不调用 AI 或写入真实应用设置。

| 方案 | 讨论重点 |
| --- | --- |
| A：紧凑入口 | 从底部向上展开应用列表 |
| B：应用宫格 | 在展开面板中展示应用图标、名称和常驻操作 |
| C：应用预览 | 用卡片说明应用用途 |
| D：搜索启动台 | 搜索打开能力，支持 Ctrl / Command K、方向键与 Enter |
| E：常驻管理 | 已常驻应用优先排列，可取消常驻或打开 |
| F：商店发现（未来） | 默认展开模拟商店，不纳入首期 |

D 参考 [Raycast](https://www.raycast.com/) 的搜索启动与扩展发现方式。早期方案参考过
Notion 收藏和 VS Code Profiles，当前版本已移除场景工具包与快捷区。
原型支持 URL 的 `#launcher`、`#favorites`、
`#scenes` 等片段直接打开指定方案。

## 术语

| 术语 | 定义 |
| --- | --- |
| 系统入口 | GoodBuddy 工作流程或审计所必需的固定入口，用户不能卸载、隐藏或改变类型 |
| 应用 | 在主内容区打开完整一级页面的功能，可显示在“当前对话”所在的主导航区 |
| 系统工具 | GoodBuddy 自带且不可卸载的辅助能力，包括文件、终端、浏览器和资源监控，从侧栏底部打开助手工作栏中的对应面板 |
| 插件应用 | 未来由插件提供的一级页面入口 |
| 插件工具 | 未来由插件提供的辅助面板或命令入口 |
| 快捷入口 | 只负责打开或聚焦能力，不复制该能力的界面和业务状态 |
