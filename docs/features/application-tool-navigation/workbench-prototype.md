# 工作台内容与视觉原型

本轮评审入口为[工作台 Demo](./workbench-demo/index.html)。它以早期四栏和多页面原型的视觉方向为基线，将聊天、笔记和知识库放入同一外壳，复用已脱敏快照检查对象数量与状态。原有真实数据结构版保留为数据核对样本，不再作为视觉评审主入口。

## 内容安排

聊天默认与设计文档并列。消息中的文档入口打开右侧阅读区，“记入笔记”把讨论要点放进笔记草稿，用户确认后追加记录。对象列表按应用切换：聊天显示项目与会话，笔记显示笔记索引，知识库显示库列表。进入笔记总览或知识库时先收起工作区，选中笔记或预览文档后再展开。

笔记总览保留轻边框卡片，详情采用连续记录。知识库采用表格，来源状态和历史任务分开。右侧显示文档、评论、清单或任务详情；数据统计与原型解释集中到“关于此预览”。导入、检索等未接服务的操作在点击后说明边界，不显示虚构的成功结果。

## 数据与示例文案

数据来源和导出白名单继续由[真实数据原型说明](./real-data-prototype.md)维护。本轮直接引用其 `snapshot.js`，没有重新读取或修改便携版数据。

| 内容 | 采用方式 |
| --- | --- |
| 项目、会话、笔记、库、文档、任务 | 使用快照对象及其关联，初始数量保持一致 |
| 时间、置顶、来源状态、任务状态、笔记记录数 | 使用快照字段 |
| 标题、消息、记录、评论、设计文档、终端 | 使用公开设计讨论编写的示例，不是导出的私人原文 |
| 消息长度、富文本结构 | 没有逐项还原；本版不能用于原始长消息与富文本验收 |
| 新增消息、笔记和记录 | 当前页面内存中的演示数据，刷新恢复 |

标题与正文不再机械填充到原始字数。笔记记录采用有限的编辑样例，长笔记仍会重复部分样例，适合检查连续记录结构，尚不能评价真实长篇内容的阅读质量。知识库文档预览使用同一篇设计稿，展示阅读排版，不据此推断原始文档内容。文件类型由 MIME 转成 PDF 等可读名称。

## 视觉与交互

沿用生产基础字体及语义令牌；候选表面色和蓝色强调色集中在原型样式顶部。亮色使用浅灰蓝外壳和白色正文，暗色用蓝灰表面与柔白正文。业务模板只引用语义样式，后续配色调整不需要逐页改色值。

列表默认 246px，窗口变窄时收紧到 216px。聊天和工作区按剩余空间分配，拖动分隔线或使用方向键调整；主内容份额限制为 35%～70%。1000px 以下对象列表改为抽屉，700px 以下主内容与工作区单独显示，通过顶栏按钮切换。宽度变化不清除草稿。

页签使用 `tablist`、`tab` 和 `tabpanel`，支持方向键、Home、End；筛选使用原生选择器；持续状态使用 Switch；清单使用 Checkbox；状态文字不做成按钮。Modal 使用原生 dialog，保留 Escape 关闭与浏览器焦点恢复。组件入口展示这些区别，尚不构成生产组件库。

外观提供亮色、暗色、跟随系统，主题选择保存在当前浏览器。栏宽、面板收放和业务草稿仅保留在本次页面内；经典布局比较链接到已有布局原型。本版没有重新实现经典布局。

## 维护位置

| 文件 | 职责 |
| --- | --- |
| `workbench-demo/index.html` | 稳定外壳与资源引用 |
| `workbench-demo/style.css` | 候选令牌、控件、页面结构与响应式规则 |
| `workbench-demo/content.js` | 图标和经过编辑的示例文案 |
| `workbench-demo/app.js` | 快照适配、语义控件辅助函数、页面渲染和交互状态 |
| `workbench-demo/validate.cjs` | 独立 Electron 原型检查与截图 |
| `real-data-demo/snapshot.js` | 共用脱敏快照；不在新目录复制一份 |

继续维护时，先核对操作含义与快照字段，再调整页面。新增主题值留在令牌层；通知、弹窗、按钮、页签和状态标记使用已有辅助函数。正式接入时按[页面内容检查中的维护计划](./page-content-review.md#组件规范与维护计划)迁入生产共享组件，不直接将原型模板塞进 `App.tsx`。

本轮没有新增 `AGENTS.md`，也没有改生产设计系统。完整设置、监督者、主机与设备共享仍由早期多页面原型提供视觉参考；工作台版本目前集中验证上述三个主页面。

## 复现与检查

可以直接打开 HTML，或使用以仓库根目录为根的静态服务。不要仅以 `workbench-demo/` 为服务根目录，否则共享字体、基础 CSS 和快照不可达。

```powershell
node --check docs/features/application-tool-navigation/workbench-demo/app.js
node --check docs/features/application-tool-navigation/workbench-demo/content.js
node docs/features/application-tool-navigation/workbench-demo/validate.cjs --clean
node docs/features/application-tool-navigation/workbench-demo/validate.cjs
```

检查覆盖草稿、分页、搜索空态、记录追加、任务状态、页签键盘及 1500、1100、640、420px 视口。截图和隔离用户目录位于 `temp/workbench-demo-check`，审阅后用 `--clean` 清理；复跑前也先清理，避免复用 Electron 用户目录导致启动失败。实际执行结果见[实施进度](./progress.md)。原型检查不能证明生产服务、终端、编辑器生命周期或真实用户任务已经验收。
