# 主机管理与云环境管理产品需求

状态：2026-09-28 确认产品方向，待实现。本次仅更新文档；现有 SSH 实现与验证范围见[技术设计](./technical-design.md)。

## 目标与范围

主机管理从设置中心迁入应用中心，在主内容区提供独立工作页面。云环境管理作为同级应用，管理公有云及私有化平台中的虚拟机，接入远程执行时复用主机管理。

首版围绕已有虚拟机完成“连接平台 → 发现实例 → 接入主机 → 验证 SSH → 安装远程环境 → 创建项目 → 执行任务”。先交付主机管理入口迁移与页面调整，再分批接入平台适配器。

| 平台范围 | 接入目标 |
| --- | --- |
| AWS | 已有 EC2 实例 |
| Azure | 已有 Virtual Machines |
| 阿里云 | 已有 ECS 实例 |
| 腾讯云 | 已有 CVM 实例 |
| VMware | 先聚焦 vCenter / vSphere 管理的虚拟机 |
| ZStack | 已有云主机 |

六个平台纳入首版适配计划，逐批实现和验收，不把手工 SSH 接入计为平台 API 已适配。候选顺序为阿里云、腾讯云加一个私有化平台，再补其余平台；私有化平台优先级按真实客户与测试环境确定，该顺序尚未锁定。各平台支持版本、认证方式和可验收环境须在对应适配器开发前确认。

首版不包含自动创建、销毁虚拟机、网络编排、镜像管理和计费管理；已有实例启停作为后续增量。现有云服务器仍可手工通过 SSH 接入，受网络、认证和远端操作系统支持范围限制。

## 功能要求

### FR-RH-1 应用入口

应用中心分别提供“主机管理”和“云环境管理”，打开独立主内容区页面，支持排序与常驻。应用中心只负责访问和通用应用设置，主机和云资源操作位于业务页面。迁移后移除设置中心内的重复主机管理表单；旧入口可提供跳转。

### FR-RH-2 主机工作页面

主机作为全局资源，提供可搜索、按来源及状态筛选的列表与所选主机详情。保留现有新增、编辑、验证、Host Key、凭据管理、安装、更新、重装及删除能力。详情包含概览、连接配置、执行环境和关联项目。来源为手工添加或关联平台，不要求手工主机填写云字段。

### FR-RH-3 云平台连接与已有实例接入

一个平台连接管理多台实例。用户可先浏览云资源，再选择实例创建主机或关联已有主机。实例接入须选定可达地址和认证方式，经 SSH 验证后才成为可用主机；仅查询到实例不代表接入成功。认证或连接失败保留平台及实例上下文，允许修正后重试。

### FR-RH-4 依赖与状态

云环境浏览不要求存在主机；安装环境、创建远程项目和远程执行复用主机能力。云实例运行状态、SSH 连通性、执行环境就绪状态独立呈现，并显示检查时间或未检查状态。启用、常驻及共享远程能力的规则由[功能逻辑](./logic-design.md)定义。

### FR-RH-5 资源关联与删除

已接入实例可跳转至对应主机，主机可回到平台实例。移除本机主机记录、移除平台连接与销毁云实例是独立动作，不能相互隐式触发。主机删除沿用现有引用项目影响确认及本地数据清理语义，明确不会删除远端内容。

### FR-RH-6 迁移与接入条件

升级保留已有 Host ID、凭据、Host Key、项目引用、功能启用状态及原有应用导航偏好。私钥认证和私网连接路径属于云接入前的补齐项；在对应能力实际交付前，页面必须说明可用认证与网络条件，不能将平台 API 可达等同于 SSH 可达。具体私钥保存方式和跳板连接方案另行技术设计，不因本文而宣称已经支持。

## 产品验收

| 场景 | 操作与预期结果 |
| --- | --- |
| AC-RH-1 已有用户升级 | 打开主机管理，原有主机及项目引用可用；导航排序和原启用偏好保留，不自动连接远端 |
| AC-RH-2 主机维护 | 从应用中心新增主机，完成验证、显式安装环境并创建远程项目；取消或失败可重试，页面跳转不重复安装 |
| AC-RH-3 云实例导入 | 已配置平台连接时发现并选择实例，验证后创建或关联主机，进入同一主机详情；重复导入定位已有记录 |
| AC-RH-4 网络或认证失败 | 实例运行中但 SSH 不通或认证失败时，分别显示实例状态和连接错误；不显示执行就绪，不安装环境 |
| AC-RH-5 导航与依赖 | 取消主机常驻不影响云环境或执行能力；云环境接入流程可就地启用所需远程能力，无须寻找设置开关 |
| AC-RH-6 移除关联资源 | 删除主机前列出受影响的本地项目；完成后云实例仍存在，云列表显示未接入。移除平台连接不删除主机和远端资源 |
| AC-RH-7 页面与权限 | 窄窗口和键盘可完成列表、详情和返回；平台账号仅有查询权限时仍可发现和导入实例，不要求实例生命周期权限 |

每个平台必须通过真实 API 发现已有实例，并完成 SSH、环境安装、项目创建和真实任务执行的生产路径验收，才可标记该适配器已交付。UI、模拟响应和单独 SSH 测试不能替代平台验收。
