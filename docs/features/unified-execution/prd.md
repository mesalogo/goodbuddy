# 产品需求

状态：主要源码改造已落地，完整验收待完成，见[进度](./progress.md)。需求依据：用户确认完全移除 Ask / Execute、安全分类及 `toolApproval`，并清理历史字段。

## 用户问题

旧实现中，用户已启用工具，调用仍可能被工作模式拒绝。图片生成同时检查请求绑定的模式和调用时的模式；多个 Runtime 又分别控制工具注册与执行，导致界面、工具目录和执行结果不一致。模式还增加了项目、通道、任务和子代理中的配置与解释成本。

目标是让用户直接提出问题或要求执行任务，由所选 Runtime 和已配置能力完成请求，不需要先切换工作模式。

## 范围

覆盖 Model、OpenCode、Continue、DeepSeek Harness 的已实现产品入口，本地和远程执行、原生客户端、原生工具、MCP、图片、子代理、队列、定时任务、消息通道和内部文本任务。历史数据和中英文文案同步处理。

远程通用 MCP、远程 DSH、远程原生客户端等尚未实现的路径，不因移除模式自动获得支持。其现状由[源码调研](./source-audit.md)记录。

## 功能要求

| 编号 | 要求 | 产品验收 |
| --- | --- | --- |
| FR-1 | 移除工作模式选择和展示 | 输入区、项目、通道、任务、历史子代理和原生工具页均无 Ask / Execute 选择、徽标或默认值 |
| FR-2 | 移除运行时模式判断 | 已支持入口不再根据旧模式筛选、拒绝或要求重新授权工具；原生文件和命令工具一并覆盖 |
| FR-3 | 沿用设置控制能力 | 已启用且已分配的 MCP 服务提供其工具；关闭或未分配的服务不可调用；只读标记只描述行为 |
| FR-4 | 删除历史模式字段 | 新写入无模式字段；升级清理旧 SQL 列和已确认的应用元数据路径；Ask、Execute、Plan 与缺省数据适用同一执行规则 |
| FR-5 | 覆盖全部请求来源 | 对话、队列、定时任务、通道、外部委派和子代理不再附带或继承模式 |
| FR-6 | 覆盖远程与原生客户端 | 配套 Agent、桥接程序、启动参数和生成配置均不保留产品模式；版本不匹配时明确提示升级 |
| FR-7 | 保留任务性质与业务条件 | 摘要和内部分析仍无工具；资源范围、输入校验、取消、超时和进程清理保持有效 |
| FR-8 | 清理提示词与命令语义 | 不再注入工作模式说明或“切换 Execute”建议；旧通道模式前缀不再改变权限 |
| FR-9 | 保留用户数据与任务身份 | 模式迁移不修改正文、工具输入输出、附件、成果、任务顺序、调度时间或远程去重身份 |
| FR-10 | 同步产品说明 | 中英文界面、当前功能文档及发布升级说明准确反映新行为；历史版本证据保持原状 |

## 设置粒度

MCP 当前按服务启用和分配，展开的工具列表用于说明。启用服务意味着使用该服务实际提供的工具；不再按工作模式维护第二份读写名单。

Runtime 原生工具沿用其现有注册与配置机制，没有开关的工具按 Runtime 正常能力提供。本次不承诺新增文件、命令或插件的通用逐工具开关。图片继续使用图片模型的会话调用设置，浏览器继续使用已有能力开关，知识库继续使用用户选定范围。

用户进一步确认删除“安全”设置分类和 `toolApproval` 自动授权/禁止工具策略，并迁移清理其历史配置。“清除本地数据”移到通用设置，保留二次确认。覆盖文件选项、上传许可和原生结构化提问保留，具体处理见[执行规则](./logic-design.md)。

## 非目标

- 不新增权限档位、模式别名、固定安全工具列表或额外确认流程。
- 不因删除模式实现尚不支持的 Runtime、远程工具或 MCP 传输。
- 不删除 OS 账户权限、Electron 隔离、凭据保护、协议校验或资源归属校验。
- 不删除用户保存的文字，也不承诺擦除备份、已导出的日志或数据库空闲页中的字节。
- 不将第三方协议的 `ask` 权限值、原生计划代理或 `chat/agent` 名称当作产品模式批量替换。

## 完成条件

FR-1 至 FR-10 的实现与[用户故事](./user-stories.md)验收均有证据后才可标记完成。仅隐藏选择器、统一传入 `execute`、修改工具说明或通过隔离单元测试，不满足完整交付要求。
