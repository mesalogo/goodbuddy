## 验收执行要求

工具调用至少覆盖生产入口到结果保存的链路。原生客户端必须检查实际生成文件与启动行为；远程场景须使用开发中的源码或包，不以已发布 Agent 的成功替代当前实现验证。

数据库验收使用一致性备份后的副本，并对原始内容、稳定 ID、顺序、时间及远程来源字段做比较。真实图片生成另行记录提供商调用次数；配置检查不能替代生成验收。

设置变更的生效时点沿用各能力已有生命周期，至少验证下一轮请求和重新启动客户端。当前已接受的任务不得因本次改造被重复提交。
