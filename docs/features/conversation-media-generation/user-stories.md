# 用户场景

状态：设计草案。Given、When、Then 分别为前提、操作和预期结果。范围以[产品需求](./prd.md)为准，行为以[行为规则](./logic-design.md)为准。

## 场景验收

适用的自动调用场景须在直连文本 Model Runtime、本地 OpenCode、Continue、DeepSeek Harness 和 GoodBuddy Agent 远程适用 Runtime 分别验证，前提为 Execute 且聊天模型支持工具调用。切换验收同时检查原操作归属和目标 Runtime 的新生成、编辑能力。

| 编号 | 需求 | Given | When | Then |
| --- | --- | --- | --- | --- |
| US-01 | FR-1、FR-3、FR-9 | 已添加图片模型、开启会话调用并设为默认 | 在文字会话中要求画海报 | 自动调用并显示活动，原会话出现图片及实际模型；无需创建 Skill、MCP server 或重复凭据 |
| US-02 | FR-2 | 有两个可调用图片模型，未选默认 | 请求生成图片 | 提示本次指定模型或到设置选择默认后重新发送；名称歧义先澄清，不按列表顺序提交 |
| US-03 | FR-4、FR-5 | 聊天模型 A 已调用图片模型生成图片 | 切换聊天模型 B，要求修改该图 | B 获得成果引用和可用工具，编辑模型按规则选择 |
| US-04 | FR-4、FR-6、FR-9 | 生成操作已提交 | 切换 Runtime 并打开其他会话，再请求生成或编辑 | 原操作继续且只写回原会话；目标 Runtime 可提交新操作，不重放旧调用 |
| US-05 | FR-2、FR-4 | 当前操作使用图片模型 X | 将全局默认改为 Y，再请求新建图片 | 旧操作仍用 X，新操作用 Y；本次明确指定可覆盖默认 |
| US-06 | FR-1、FR-2、FR-4 | 默认或本次指定模型为 X | X 被关闭或删除后请求生成 | 显示 X 不可用并提示改选，历史图仍可打开，不静默换模型 |
| US-07 | FR-5、FR-8 | 已保存图片并重新打开会话或切换 Runtime | 引用原图，指定另一个支持编辑的模型 | 新模型接收原图；素材缺失时要求重新选择，不能假装已编辑 |
| US-08 | FR-7 | 当前聊天模型不支持工具调用，或处于 Ask | 请求生成或编辑 | 无工具能力时说明可使用已有直连图片工作流；Ask 下不提交并提示需要 Execute，不自动切换模式 |
| US-09 | FR-6 | 操作正在生成或保存，或已经失败 | 取消，或明确要求重新生成 | 如实显示取消结果；人工重新生成创建新操作，不自动重复收费请求，不提供独立保存重试入口 |
| US-11 | FR-4、FR-9 | 使用 GoodBuddy Agent 远程适用 Runtime | 生成及编辑图片，切换本地后继续编辑，再切回远程生成 | 工具往返可用，成果可继续引用；活动归原会话，凭据留在 Main；远程断连不取消 Main 已接收的操作 |
| US-12 | FR-5、FR-7、FR-8 | 聊天模型无视觉能力但支持工具 | 请求分析图片或根据文字修改图片 | 说明无法直接查看图片；可传原图给编辑工具，不编造视觉观察 |
| US-13 | FR-6 | 图片操作尚未取得可保存结果 | 退出并重开应用 | 未完成记录显示结果未确认，不承诺后台继续，不自动查询恢复或重新提交 |
| US-14 | FR-5 | 会话有多张图片 | 要求“修改第二张”或“新画一张无关图片” | 前者引用指定成果，后者不附带旧图；指代不清先澄清 |
| US-15 | FR-3、FR-5、FR-9 | 上传图片并选择支持编辑的图片模型 | 要求修改背景，再切换 Runtime 继续修改成果 | 上传原图及后续成果被正确引用，编辑结果保存在各自发起会话；不降为纯文生图 |
| US-16 | FR-1、FR-9 | 尚无开启会话调用的图片模型 | 查看内置 MCP 列表，再开启一个图片模型并保存 | 图片生成与编辑行一直可见且标记“内置 · 自动管理”；全部支持 Runtime 从未勾选变为勾选，目录包含该模型；重开设置或应用仍按模型配置显示 |
| US-17 | FR-1、FR-9 | 至少两个图片模型开启会话调用 | 关闭或删除其中一个并保存 | 全部支持 Runtime 保持勾选，允许目录移除该模型、保留其他开启模型；新操作不能调用已关闭或删除模型 |
| US-18 | FR-1、FR-9 | 仅剩一个开启会话调用的图片模型 | 关闭或删除该模型，再重新开启或添加并开启一个模型 | 目录为空时全部取消勾选，整行和说明、模型设置导航仍可见；再次开启后自动恢复全部勾选，无需另行分配 |
| US-19 | FR-1、FR-7、FR-9 | 至少一个图片模型开启会话调用 | 尝试用鼠标或键盘切换分配，或切换到无工具聊天模型、Ask、离线 Runtime，或遇到配置或执行错误 | 分配不可手动修改，运行限制与错误不取消勾选；无独立启用、分配保存、移除或凭据编辑操作；自动管理说明持续可读，辅助技术可识别勾选和禁用状态，键盘可通过“前往图片模型设置”导航修改源配置 |

## 编号变更

US-10（图生视频）移出本图片设计范围，编号保留，不安排实施。US-02、US-05、US-06 的会话选择预期由全局默认和本次指定替代；US-08 使用已有直连图片工作流；US-09 取消独立保存重试要求；US-13 的视频查询恢复由图片中断状态说明替代。其余编号保持，US-15 补充上传图片编辑的显式验收。

US-16 至 US-19 补充自动管理分配验收，设置展示不依赖 Execute 或当前聊天模型支持工具；自动生成与编辑仍遵循本节的调用前提。
