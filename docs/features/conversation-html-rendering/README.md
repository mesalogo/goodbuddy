# 会话 HTML 渲染

会话 HTML 渲染让用户直接查看 Agent 回复中的网页结果，而不必先复制代码到外部文件。
该能力默认开启，也可以在“设置 > 平台功能 > 通用设置”中关闭。

## 功能边界

- 只渲染已完成的 Agent 正文和已完成的子 Agent 输出。
- 支持完整 HTML 文档、单一 HTML 根元素，以及 Markdown 中的 `html` / `htm` 代码块。
- 使用无脚本、无网络、无表单提交和无窗口操作权限的静态隔离预览。
- 每个预览提供源码切换和全屏预览两个图标操作；全屏预览沿用同一清理和隔离边界。
- 用户消息、推理过程和流式中的回复不执行 HTML；关闭功能后继续显示 HTML 源码。
- 本功能不把普通聊天回复复制为成果，也不替代助手工作栏中独立成果的预览流程。

## 术语

- **HTML 源码**：Agent 回复中原始、可复制的 HTML 文本。
- **静态预览**：在隔离 `iframe` 中显示的 HTML；脚本、联网和外部操作均被禁用。
- **全屏预览**：在应用级 Modal 中显示同一份静态预览文档，用于查看完整页面布局。

全局聊天和设置界面规则由根目录的
[统一界面设计系统](../../../UI-DESIGN.md)定义。独立成果预览仍由
[助手工作栏](../assistant-workbar/README.md)负责。
