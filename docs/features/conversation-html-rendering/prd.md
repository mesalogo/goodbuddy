# 会话 HTML 渲染产品需求

## 用户问题

Agent 可以生成网页、报告和交互原型的 HTML，但此前会话只能显示源码或忽略原始标签。
用户必须把内容复制到外部文件后才能查看结果，打断了会话内的阅读和迭代流程。

## 目标

- 让 Agent 生成的 HTML 在回复完成后直接显示为网页预览。
- 保留一键查看原始 HTML 的能力。
- 允许用户通过平台功能开关恢复为只看源码。
- 预览支持脚本和网络访问，并与 GoodBuddy 应用接口隔离。

## 非目标

- 不向预览开放 Electron 或 GoodBuddy 应用接口。
- 不在流式输出中反复加载不完整页面。
- 不自动把普通会话回复保存为成果。

## 功能需求

### FR-1 默认设置

“会话 HTML 渲染”是应用级持久设置，默认开启。用户可在“设置 > 平台功能 >
通用设置”中立即关闭或重新开启；保存失败时保留最后确认的状态并显示错误。

### FR-2 可识别输出

开启后，已完成 Agent 回复中的以下内容显示为网页预览：

1. 完整 HTML 文档。
2. 由单一 HTML 根元素构成的完整回复。
3. Markdown 中标记为 `html` 或 `htm` 的代码块。

普通 Markdown 继续按原有规则显示。一个回复中的多个 HTML 代码块各自保持原有位置。

### FR-3 回复状态和角色

- 已完成的主 Agent 正文和已完成的子 Agent 输出可以预览 HTML。
- 用户消息和 Agent 推理只显示文本或源码。
- 流式 Agent 正文在完成前显示源码，完成后原位切换为预览。

### FR-4 源码、全屏与关闭行为

每个预览显示“支持脚本交互与网络访问”，并在标题右侧提供两个图标操作：

1. 源码按钮，就地展开或收起原始 HTML。
2. 全屏按钮，在应用级 Modal 中查看同一份预览文档。

嵌入预览使用固定高度并在框内滚动，需要更大画面时使用全屏预览。全屏预览可通过关闭
按钮、Escape 或点击遮罩退出，退出后焦点回到全屏按钮。关闭平台功能后，完整 HTML 回复
和 HTML 代码块继续显示源码，不能变成空白。

### FR-5 交互与隔离

预览支持 JavaScript、事件属性、外部脚本、样式、字体、图片和网络请求，以及表单交互。
网络请求遵循浏览器的跨域规则。预览与主应用保持不同源，不能读取主界面或调用应用接口；
不授予顶层导航和弹窗权限。内嵌与全屏预览使用相同权限。

## 产品验收

- 新安装和从旧设置升级后，开关均为开启。
- 完整 HTML 和 fenced HTML 在已完成的 Agent 回复中显示预览。
- 关闭开关后，当前会话立即恢复显示源码，重启后选择仍保留。
- 流式回复、推理和用户消息从不执行 HTML。
- 预览可通过键盘访问源码和全屏按钮，并具有明确的 iframe 标题。
- 全屏预览隔离背景、初始聚焦关闭按钮，Escape 退出后焦点回到全屏按钮。
- 脚本交互和外部资源正常工作，预览无法访问主界面 DOM、Node 或 GoodBuddy 接口。
