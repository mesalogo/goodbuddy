# 文件打开与内容预览

本功能统一工作区文件、会话文件链接和附件的打开规则，并规定消息内容何时在会话内渲染。
文件类型决定首选阅读方式，入口、用户动作和运行环境决定实际打开目标。

本目录目前建立产品规范，尚未实施统一分发或新增阅读器。支持情况见实施进度。

## 术语与职责

内容对象先分为消息正文、会话中的文件引用和实际文件内容。会话是展示入口；附件和
文件链接保持其文件身份，不能仅因显示在消息中就套用消息正文渲染规则。

- 文件打开：用户主动打开已有文件，按类型进入阅读器、浏览器或源码视图。
- 会话内渲染：消息中的内容或明确展示的预览卡片在聊天区域呈现，不自动创建项目文件。
- 原件阅读：查看文件原始版式、分页、工作表或幻灯片。
- 解析正文：由解析器或 OCR 提取的内容，显示时标注为解析结果。
- 能力可用：当前环境的生产链路可以完成操作；仅有类型声明或独立 Demo 不算可用。

[助手工作栏](../assistant-workbar/README.md)负责布局、目录操作和返回状态；
[会话 HTML 渲染](../conversation-html-rendering/README.md)负责 HTML 识别、设置、权限和生命周期；
[文档处理](../document-processing/README.md)负责解析与 OCR；
[Office 协同编辑](../office-document-editing/README.md)负责编辑、保存及冲突处理。
这些功能引用本目录的打开规则，不另建一份文件类型分发表。

## 维护方式

新增格式或修改默认行为时，先更新打开规则及对应验收场景，再调整实现。
能力状态和实测证据只写入进度；扩展名表中的目标行为不能作为已支持的依据。
专属阅读器的内部规则由所属功能维护，本目录通过链接引用。
