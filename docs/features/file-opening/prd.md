# 文件打开与内容预览产品需求

## 范围

用户从工作区、聊天文件链接或附件打开内容时，应能预期显示位置和阅读方式。
文件打开、会话内渲染、文档解析和编辑分别承担不同操作，界面应明确当前模式。
具体格式和路由的权威定义见[打开规则](./logic-design.md)。

本轮交付规范。HTML 文件浏览器打开、文档阅读器接入和统一分发的代码改动在后续任务中实施。

## 功能需求

### FR-FO1 按类型打开

单击文件名执行该类型的默认打开操作。更多菜单提供当前能力支持的替代方式，
例如“查看源码”“在浏览器中打开”“使用系统应用打开”。同一文件从工作区或聊天
文件链接打开时使用同一规则。Git 变更和提交历史文件默认打开相应 Diff。

### FR-FO2 会话展示

区分消息正文、会话文件引用及读取后的文件内容。消息正文依据消息语法和状态渲染；
附件或文件链接依据文件身份读取后选择阅读器。消息 HTML 的设置不自动扩展到 HTML 文件
内容的内嵌预览；后者的触发和设置归属待定，见打开规则。

普通 Markdown 消息继续按消息排版规则显示。HTML 沿用所属功能的识别规则和设置。
文件链接本身不触发全文读取或自动展开；明确展示的文件预览使用有界高度，提供适用的
展开和右侧打开操作。HTML 会话开关不改变用户主动打开 HTML 文件的默认目标。

### FR-FO3 文档阅读与编辑

PDF、Word、Excel 和 PowerPoint 分别使用适合其分页、版式、工作表和幻灯片的阅读方式。
“原件”和“解析正文”明确区分。阅读文件不自动运行 OCR、不默认进入编辑模式或改写原件。
编辑及转换入口按所属功能的可用能力提供。

### FR-FO4 来源和返回

文件继续在右侧打开。由文件列表进入浏览器或阅读器后，可返回来源列表，恢复项目、目录、
展开状态、选择、滚动位置和已有筛选。项目切换后，过期读取结果不能覆盖当前视图。
附件沿用会话资源身份，不因打开而复制进项目；远程文件由对应 Host 读取。

### FR-FO5 失败与能力反馈

尚未支持、文件损坏、无权限、远程断连、读取失败分别显示原因和可用操作。
本机系统打开与远程文件操作按实际能力展示。刷新失败时保留已有可读内容并提示内容未更新。
部分内容标明加载状态，继续读取或按需分页；不得把截断内容标为完整文档。

## 用户场景与验收

| 场景 | 前提与操作 | 预期结果 | 需求 |
| --- | --- | --- | --- |
| US-FO1 HTML 文件 | 浏览器文件通路可用，单击 HTML/HTM | 右侧浏览器打开；可看源码，返回原目录位置 | FR-FO1、4 |
| US-FO2 会话开关 | 关闭 HTML 渲染后查看已完成回复 | HTML 保留源码；主动打开 HTML 文件仍按文件规则处理 | FR-FO2 |
| US-FO3 HTML 输出 | 开关开启，Agent 的 HTML 代码块由流式变为完成 | 按会话 HTML 规范转换为预览，用户消息和推理不触发 HTML 执行 | FR-FO2 |
| US-FO4 文件链接 | 消息仅包含项目文件链接，随后点击 | 展示时不读取全文；点击后与文件列表使用同一路由 | FR-FO1、2 |
| US-FO5 文档阅读 | 对应阅读器可用，打开 PDF/DOCX/XLSX/PPTX | 显示原件对应阅读方式；解析正文独立标识，原件不被修改 | FR-FO3 |
| US-FO6 能力缺失 | 打开旧 Office 或未支持格式 | 文件信息、原因和实际可用操作可见，不伪装成已成功阅读 | FR-FO5 |
| US-FO7 远程与取消 | 远程读取中返回或切项目，随后旧请求完成 | 停止无关读取，迟到结果不替换当前内容；断连可重试 | FR-FO4、5 |
| US-FO8 Git | 从当前变更或某次提交打开文件 | 查看该上下文的 Diff；主动查看当前文件才进入默认打开流程 | FR-FO1 |
| US-FO9 原件异常 | 文件损坏、格式不符或内容不可解码 | 显示具体失败，不仅通过更换扩展名就认定为可渲染内容 | FR-FO5 |
| US-FO10 既有行为 | 升级后打开 Markdown、图片及既有会话 HTML | 保留已有阅读与设置行为；新增路由由进度和真实验收确认 | FR-FO1、2 |
| US-FO11 同格式不同对象 | 回复中同时有 HTML 代码块与 HTML 文件链接 | 代码块按消息 HTML 规则处理；链接保持文件引用，点击后读取文件，不自动展开为消息 HTML | FR-FO1、2 |
