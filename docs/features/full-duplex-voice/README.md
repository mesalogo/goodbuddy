# 全双工语音

全双工语音定义持续听说、打断、语音活动检测、本地与远端推理以及多平台音频边界。

现有麦克风听写支持本地模型和远程 OpenAI 兼容转写。远程服务的“流式返回识别结果”
指完整录音上传后逐步返回文字，不等同于实时听写或全双工语音。
