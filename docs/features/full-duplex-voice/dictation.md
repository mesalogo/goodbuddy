# 录音转写

## 产品行为与验收

| 要求 | 用户场景与结果 |
| --- | --- |
| ASR-1 | 在“设置 → 模型 → 语音”选择本地模型或远程服务。旧安装默认继续使用本地模型。 |
| ASR-2 | 远程服务配置 API 基础地址、模型、可选 API Key 和语言；语言留空时由服务检测。地址支持内网 HTTP 与 HTTPS。 |
| ASR-3 | “流式返回识别结果”默认关闭。关闭时一次返回文字；开启时上传完整录音后显示增量预览，完成后一次追加到发起录音的会话草稿。 |
| ASR-4 | 切换会话不会把结果写入新会话；识别期间的手动草稿输入保留。取消、超时或错误时不追加部分结果，用户可重试。 |
| ASR-5 | 设置页可保存并录音测试，结束录音后显示结果及请求耗时；测试使用当前保存的设置，语音发送到所配置的服务。 |

该功能沿用现有最长 20 秒、16 kHz 单声道录音。它不提供持续音频上传、实时听写、
TTS 或自动发送聊天消息。不能通过打开流式结果开关获得“边说边出字”的行为。

## 界面与状态

本地模式显示现有模型下载、导入和选择控件；远程模式显示服务字段及共享 Switch。
密钥输入框只显示是否已配置，留空保留原密钥，可明确选择保存时清除。
设置草稿纳入离开页面提醒，也可由页面内“保存识别设置”单独保存。

“保存并录音测试”先验证、保存当前字段，再申请麦克风。录音期间可结束录音；
等待转写时可取消。字段错误就地显示，保存结果与异步失败走应用通知。
流式预览显示在测试结果或聊天输入区附近；完成后移除预览，仅使用最终文本。

## 技术合同

- `SpeechSettingsStore` 是语音服务配置的唯一持久化 owner，使用 `speech-settings.json`，
  复用原子设置写入与系统加密凭据；公共快照没有密钥。现有本地模型选择文件不变。
- `SpeechTranscriptionService` 冻结每次请求的配置，按来源选择本地 Sherpa 或 HTTP。
  远程请求不登记为本机推理任务。桌面直接连接 ASR 服务，不经过 GoodBuddy Agent；
  桌面到 Agent 的 Runtime 协议与部署没有改变。
- 音频在内存中转换为 PCM16 WAV，以 `multipart/form-data` 上传至基础地址后的
  `/audio/transcriptions`；表单携带 `model`、`stream`、非空 `language` 和 `file`。
  `Content-Type` boundary 由 FormData 生成，Bearer 凭据只在 Main 构造请求时使用。
- 普通返回读取 `text`。SSE 解析跨网络块的 UTF-8 与 CRLF，支持已实测的
  `choices[0].delta.content` / `[DONE]`，以及 `transcript.text.delta` / `transcript.text.done`。
  后一种格式有自动测试，尚无外部提供商实测。未收到结束事件的断流按失败处理。
- 进度携带请求 ID，Preload 暴露显式订阅。Renderer store 验证归属，预览局部订阅，
  首个结果立即显示，后续通知按动画帧合并；结束或取消清理订阅与待绘制帧。
- 沿用单次录音与最终文字的现有长度限制，远程请求 120 秒超时；取消使用 AbortSignal
  中止 HTTP 与响应读取，请求结算后释放活动项。音频不落盘，不静默切换服务或重试。

验证状态见[进度](./progress.md)。持续双向音频的设计另见[全双工技术设计](./technical-design.md)。
