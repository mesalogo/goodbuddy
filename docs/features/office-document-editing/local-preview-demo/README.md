# Office 本地预览 Demo

这是 Office 集成方案的独立网页实验。左侧选择文件，右侧以文件名打开多个阅读页签。
每种格式都有可下载的真实二进制样例，也可以选择或拖入自己的文件。

## 启动

在本目录运行（Windows PowerShell 使用 `npm.cmd`）：

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 <http://127.0.0.1:5188>。首次安装依赖需要网络，依赖安装后，预览无需连接 Office
服务。网页通过 Vite 提供，不能直接双击 `index.html` 运行。默认只监听本机。

点击“下载源文件”可将当前文件保存到浏览器下载目录，再使用 Office 对照版式。
“展开阅读”隐藏左侧文件列表；支持深浅主题、页签关闭和方向键切换页签。

## 本次可比较的能力

| 格式 | 实际组件 | 本次支持 | 边界 |
| --- | --- | --- | --- |
| DOCX | docx-preview 0.3.6 | 段落、表格、分页阅读 | 复杂浮动排版、字体与分页可能不同；禁用 altChunk HTML 渲染 |
| XLSX | SheetJS 0.18.5 + HTML 表格 | 工作表切换、单元格值、公式查看，每段 100 行 | 展示缓存公式结果，不计算公式；不复刻样式、合并单元格、图片与图表 |
| PPTX | pptx-preview 1.0.7 | 按顺序滚动阅读幻灯片 | 实验性；不播放动画，复杂母版、形状和图表需用业务样本验证 |
| PDF | PDF.js 4.10.38 | 单页渲染、翻页、75%–200% 缩放 | 当前 Demo 未接文字选择、搜索、目录和密码输入 |

旧版 DOC / XLS / PPT 未接入。加密、损坏或不兼容文件显示失败及重试入口。
预览代码不上传文件内容；字体和版式取决于本机环境。正式离线验收仍需覆盖文档内外链资源。

PPTX 组件的上游说明允许使用发布的 npm 包，但源码有单独限制；此 Demo 只使用原包。
正式打包前应确认分发条款，不能将它当作已确定的产品依赖。

## 与产品集成计划的关系

候选路径为：本地或远程文件读取 → 客户端只读预览 → 用户选择编辑 → ShareServer / ONLYOFFICE。
预览不创建编辑会话。远程项目仍需要现有文件通道将内容传至客户端。

本目录只包含网页实验。ONLYOFFICE 按钮标为未接入；未实现 Desktop IPC、远程文件读取、
文件变化监听、保存回写或 LibreOffice 转 PDF。正式 UI 需使用应用共享页签和控件。
大文件解析线程、宽表列虚拟化、页签资源缓存和跨平台字体尚未完成产品级验证。

ShareServer 已单独验证 Community 10.0 的 DOCX 保存与普通插件选区操作，证据及 Desktop 剩余
工作见[Office 实施进度](../progress.md)。该结果没有接通本 Demo 的编辑按钮，也不扩展本表的预览能力。

依赖按类型动态加载。样例由 `samples.js` 生成，再通过与导入文件相同的解析路径展示。
PptxGenJS 4.0.1 生成的清单会声明不存在的额外母版，样例生成阶段删除这些悬空声明；
导入的用户文件不做此修正。PPTX 解析返回零页时显示失败，避免把空画布报告为成功。

## 验证记录

2026-10-24，在 Windows 本机 Microsoft Edge 无头浏览器中验证：

- DOCX 段落和表格；XLSX 工作表切换、单元格缓存值和公式；PPTX 幻灯片正文；PDF 翻页与缩放。
- 四种真实二进制文件经文件选择输入导入，均成功渲染。
- 损坏 DOCX 的失败反馈与重试入口、关闭页签后恢复阅读、主题切换、展开阅读及 600px 窄屏布局。
- 检查过程中没有未捕获的浏览器错误。

运行复核（先启动网页；此脚本使用本机已安装的 Microsoft Edge）：

```powershell
node verify.mjs
npm.cmd run build
```

独立 Vite 构建通过。PPTX 解析包存在超过 500 KB 的 chunk 提示，当前按需加载；
这不是生产性能验收。没有运行 Desktop 全量测试，因为本次仅添加独立网页及文档入口。
