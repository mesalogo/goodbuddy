# Office 协同编辑用户故事

## US-A1 打开本地文档

**Given** 用户已连接支持 Office 编辑的 ShareServer，并在工作区选择一个受支持文件

**When** 用户选择“在文档页签中打开”

**Then** GoodBuddy 显示目标服务和数据去向，验证并上传工作副本，然后以文件名创建新文档
页签；失败不会修改源文件或留下可重用文件授权。

## US-A2 同时打开多个文档

**Given** 工作栏已经存在一个文档页签

**When** 用户打开另一个文档或再次打开同一文档

**Then** 工作栏创建独立页签，不替换现有实例；同名页签可辨认，文件、选区和保存状态不串联。

## US-B1 人工编辑并保存

**Given** 文档编辑器已进入可编辑状态

**When** 用户修改内容并保存

**Then** ShareServer 先形成稳定检查点，Desktop 确认源文件未被外部修改后原子回写，并明确
显示“已写回源文件”。

## US-B2 源文件发生冲突

**Given** 用户编辑期间源文件被其他程序修改

**When** 新检查点准备回写

**Then** GoodBuddy 禁止静默覆盖，并允许用户查看外部版本、另存编辑版本、放弃编辑版本或经
二次确认替换。

## US-B3 关闭未保存文档

**Given** 页签存在未形成检查点或尚未回写源文件的修改

**When** 用户关闭页签或退出应用

**Then** GoodBuddy 根据真实可恢复状态提供保存、放弃或取消，不把未知结果显示为已保存。

## US-C1 使用 AI 修改选区

**Given** 当前 Conversation 使用 Execute，用户在编辑器中选择受支持内容

**When** 用户提交 AI 修改要求

**Then** Agent 只接收有界选区和必要上下文，编辑器将完整结果作为一个事务应用并允许单次撤销。

## US-C2 Ask 模式请求修改

**Given** 当前 Conversation 使用 Ask

**When** 用户请求 AI 修改当前选区

**Then** GoodBuddy 可以生成修改建议，但不会调用编辑器写入；界面提供切换 Execute 后重新应用
的明确入口。

## US-D1 网络中断后恢复

**Given** 编辑会话已经建立

**When** Desktop、ShareServer 或 ONLYOFFICE 之间的连接中断后恢复

**Then** 页签保留并显示失败阶段；只有 ShareServer 确认存在稳定检查点时才提供恢复和回写。

## US-D2 服务未配置或不健康

**Given** 用户没有连接支持 Office 编辑的 ShareServer，或服务健康检查失败

**When** 用户打开文档能力

**Then** 入口仍可发现并解释不可用原因，同时保留使用系统默认应用打开本地文件的独立操作。

## US-E1 权限撤销和保留到期

**Given** 管理员撤销编辑权限，或编辑会话达到保留期限

**When** 用户继续访问旧页签

**Then** 新读取、保存和 AI 操作被拒绝，旧令牌不能重用，本地源文件不受服务端清理影响。
