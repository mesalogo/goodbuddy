# 故事线图谱（Story Graph）

这是[监督者应用](../conversation-supervision/supervisor-prd.md)的核心视图。目标对象与交互由[产品设计](./prd.md)定义，用户验收见[User Stories](../conversation-supervision/user-stories.md)。时间事件、知识实体与阶段总结在目标设计中分别建模；下述演示仍使用阶段节点。

[打开交互演示](./demo.html)。这是监督者故事图谱的独立设计原型，使用模拟数据，尚未接入产品或笔记存储。

`demo.html`、`demo.css`、`demo.js` 共同负责可交互的界面草案：时间线选择、阶段回放、跨时间线关联、节点总结和来源展开。直接在浏览器中打开 HTML 即可使用，无需安装依赖。

当前设计假设：每个圆代表一条时间线，实心节点代表阶段总结，实线表示同一时间线的先后关系，虚线表示不同时间线间的知识关联。节点位置为示意布局，尚未定义集中度算法，不代表效率或产出。聚合知识以预置示例演示，不调用模型。

新增平铺视图（默认）：时间轴沿画布外围逆时针环绕，从顶部 09.01 经左侧 09.07、底部到右侧 09.14，以箭头表示继续推进。知识节点平铺在环内，外圈时间点与对应阶段节点直接连接，选择节点时高亮其时间连线。工具栏可切回圆形视图，保留所选阶段、时间线与节点。当前仍使用阶段节点示例，同一知识实体在多个时间点发生修订的合并展示尚未实现。
