# 下一版 3D 故事线图谱概念

状态：时间螺旋、分层故事与经验连接已接入生产视图；本文同时保留尚未实现的概念方向。当前数据合同与实施记录见[故事线模型设计](../conversation-supervision/storyline-model-design.md)及其进度文档。

## 时间、事件与故事

内部只有一条共同的时间螺旋。时间均匀推进，同一圈中交错发生不同事情；同一件事也可以在多个圈中间隔出现。

每圈时长从 3、6、12、24、168、720、2160、8760 小时中选择，在不超过 14 圈的候选中取最接近 8 圈的一档。生产界面自动选择粒度；手动指定仍是 Demo 能力。不足一圈时保留实际圈数，时间区间不因显示需要而扩大。

同一故事中屏幕上过于接近的事件合并为一段，显示事件数量。点击聚合段，查看范围缩小到这段时间，事件随之拆开；小于约 6 小时仍无法拆开的事件（同一时刻多次提取），改为在右侧列出。

[3D 网页 Demo](3d-demo.html) 已按上述几何规则和时间尺度实现，数据为本机故事线图谱的只读导出。

生产螺旋只有一条连续曲线，高度按所选回顾的起止时间均匀推进。每圈中间 70% 保持同一半径，相邻圈在边界两侧各 15% 内用余弦插值过渡。

半径使用回顾范围和时间区间内的用户、助手消息数，按小时汇总，再按每圈覆盖时长折算每小时消息数。末尾不足一圈也按实际时长计算。每圈密度除以本次窗口的最大密度后开平方，映射到 78～152 的场景半径；相同密度得到相同半径，无记录时为 78。仅边界过渡做平滑，不向安静时段传播高密度，也不加入随机起伏。

小时桶跨圈时按重叠时长分配，小时内的精确分布不可恢复。统计读取当前消息及当前会话项目归属，消息删除、迁移或修改后可能改变历史回顾的半径；这不是当时注意力的冻结快照。知识、任务等非消息来源不计入密度。该指标只比较本次回顾内的消息频率，不表示投入时长、效率、价值或成果，也不能跨窗口直接比较绝对半径。

外层以木桶木片般的曲面连接同一故事的事件。木片起止时间、长度各不相同，可以顺着事件位置弯曲；不能为保持规则桶形而强行等长、等径。多年持续的故事可能只有少数活跃阶段，事件之间保留空白，连接只表达同一故事的延续。未结束的故事使用开放末端，不虚构未来事件。

数据来源与层级（全局 › 项目 › 功能 › 子线索、跨项目故事、经验）由[故事线模型改造设计](../conversation-supervision/storyline-model-design.md)定义。

Demo 底部的“跨项目故事”开关默认关闭。打开后，根层在项目木片旁增加跨项目故事木片（示例：果蝇神经仿真、Agent 运行环境、国内服务器部署），由多个项目中的功能组成；事件仍归属原项目，跨项目木片只做关联。关闭时只显示同一项目内的经验连接。示例中的跨项目分组按功能名称手工对应，产品中应由故事归属阶段提出，并允许用户调整。

## DIKW 与阅读路径

| 层次 | 表达 |
| --- | --- |
| D | 可追溯的原始记录 |
| I | 时间螺旋上的事件片段 |
| K | 木片串联的故事及其形成的认识 |
| W | 从早期故事形成经验及适用条件，关联到后来其他故事中的应用 |

沿螺旋查看某阶段发生的事情；沿木片查看一件事如何跨阶段发展；跨木片查看经验如何被使用、验证或修正。普通相关性不能直接标为智慧。
