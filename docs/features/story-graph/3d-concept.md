# 下一版 3D 故事线图谱概念

状态：已讨论的视觉方向，尚未实现。本文记录空间表达及概念图引用，不替代当前产品需求或技术设计。

## 时间、事件与故事

内部只有一条共同的时间螺旋。时间均匀推进，同一圈中交错发生不同事情；同一件事也可以在多个圈中间隔出现。

每圈的时长随查看范围变化，使螺旋保持约 8 圈、最多 14 圈：一天约 3 小时一圈，一周 1 天一圈，一个季度 1 个月一圈，几年 1 季度或 1 年一圈。用户可以手动指定，指定值会超过 14 圈时改用更粗的粒度。注意力密度按当前粒度重新统计，每圈 8 个时段。

同一故事中屏幕上过于接近的事件合并为一段，显示事件数量。点击聚合段，查看范围缩小到这段时间，事件随之拆开；小于约 6 小时仍无法拆开的事件（同一时刻多次提取），改为在右侧列出。

[3D 网页 Demo](3d-demo.html) 已按上述几何规则和时间尺度实现，数据为本机故事线图谱的只读导出。

螺旋半径可以随时间、随事件片段变化，表达注意力处理密度。时间轴不能随半径拉伸。密度的统计口径、归一化和缺失数据表现尚待定义，半径不代表效率、价值或成果。

外层以木桶木片般的曲面连接同一故事的事件。木片起止时间、长度各不相同，可以顺着事件位置弯曲；不能为保持规则桶形而强行等长、等径。多年持续的故事可能只有少数活跃阶段，事件之间保留空白，连接只表达同一故事的延续。未结束的故事使用开放末端，不虚构未来事件。

数据来源与层级（全局 › 项目 › 功能 › 子线索、跨项目故事、经验）由[故事线模型改造设计](../conversation-supervision/storyline-model-design.md)定义。

Demo 底部的“跨项目故事”开关默认关闭。打开后，根层在项目木片旁增加跨项目故事木片（示例：果蝇神经仿真、Agent 运行环境、国内服务器部署），由多个项目中的功能组成；事件仍归属原项目，跨项目木片只做关联。关闭时只显示同一项目内的经验连接。示例中的跨项目分组按功能名称手工对应，产品中应由故事归属阶段提出，并允许用户调整。

## DIKW 与阅读路径

| 层次 | 表达 |
| --- | --- |
| D | 可追溯的原始记录 |
| I | 时间螺旋上的事件片段 |
| K | 木片串联的故事及其形成的认识 |
| W | 从早期故事形成经验及适用条件，关联到后来其他故事中的应用 |

沿螺旋查看某阶段发生的事情；沿木片查看一件事如何跨阶段发展；跨木片查看经验如何被使用、验证或修正。普通相关性不能直接标为智慧。
