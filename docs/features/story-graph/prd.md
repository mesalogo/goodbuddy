# 故事线图谱产品与交互设计

日期：2026-09-16。状态：目标设计；当前 Demo 仅验证部分布局与交互。

图谱属于[监督者应用](../conversation-supervision/supervisor-prd.md)，负责展示工作过程与知识演变。应用入口、心跳和知识库写入边界由该产品设计定义。

## 对象

对象之间的关系与监督者数据流见[逻辑设计](../conversation-supervision/logic-design.md)，本文负责对象含义及用户操作要求。

FR-G1：外圈时间轴承载事件，内部节点表示持续积累的知识实体，阶段总结解释一个时间区间。同一知识实体可连接多个时间事件，分别表示提出、补充、验证或修订。新增方案不自动意味着旧方案已失效。

| 对象 | 内容 |
| --- | --- |
| 故事线 | 围绕某个工作主题形成的事件与知识集合 |
| 时间事件 | 发生时间、所属故事、来源及影响的知识实体 |
| 知识实体 | 当前描述、关联来源、演变记录与确认状态 |
| 阶段总结 | 指定范围内的决定、变化和未解决事项 |
| 关系 | 两端对象、关系类型、依据与确认状态 |

## 环绕时间轴

FR-G2：默认平铺视图将时间轴放在外围，逆时针围绕内部知识实体。起点、终点、方向和当前时间范围持续可见，外圈保留缺口，避免暗示时间循环。日期密集时聚合事件数量，展开后选择具体事件；时间位置采用真实比例还是等距事件布局需在下一轮原型中确定并明确标注。

选择事件后，高亮其影响的知识实体，右侧显示事件摘要和原始记录入口。外围时间点与内部实体使用实际连线；未选中的关系降低显著度。支持缩放、平移和聚焦，新增内容与回放尽量保留实体位置。

FR-G3：选择知识实体时，高亮对应的多个时间点与连线，标明提出、补充、验证或修订。右侧优先显示当前理解，再列演变和来源。历史回放下显示截至所选时刻的理解。

FR-G4：选择关系后，展示类型、关联理由及两端依据。跨故事关系与时间到实体的关系分别说明。用户可以确认、修改类型或移除关系；自动发现的关联标注待核对。

FR-G5：支持选择时间区间查看阶段总结，通过底部控制回放已发生事件及当时已知内容。圆形视图保留，用于观察独立故事聚合；视图切换保留范围、选择与回放时刻。集中度只描述关联分布，不等同于效率或产出，具体计算方式尚待设计。

FR-G6：默认展示主要实体及阶段事件，选中后展开一层关联，进一步展开由用户触发。提供文字列表完成与图形等价的对象选择、关系查看和来源跳转，遵循[监督者 UI 设计](../conversation-supervision/ui-design.md)的键盘与窄屏要求。

## 原型边界与下一轮验证

当前 Demo 使用阶段节点、固定坐标和预置关联，支持环绕时间轴、视图切换、回放、来源展开及模拟聚合；未实现真实实体合并、生成、历史版本、知识库接入或继续讨论。

下一轮场景：用户查看近期总结，选择“故事图谱布局”实体，看到三次讨论分别提出圆形、增加平铺、改为外圈逆时针时间轴，再查看来源并预览继续讨论的上下文。该场景应验证同一实体的多时点连接、事件和关系详情、阶段选择及上下文预览。验收映射见[User Stories](../conversation-supervision/user-stories.md) US-S04 至 US-S13。
