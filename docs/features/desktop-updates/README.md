# 桌面应用更新

设置中的更新入口负责检查版本、下载适合当前安装方式的发布包，并交接安装。更新沿用 GitHub 与镜像发布源，用户选择重启时才应用更新。

本文档组包含完整目标方案。当前已接通下载、校验、取消、重试与安装包打开，并在 Windows NSIS 安装版提供“重启并更新”。自动下载设置、其他格式自动安装和发布侧更新支持仍待实施；Windows 完整载荷与提权场景仍需验收。具体证据以[实施记录](./progress.md)为准。

更新缓存支持失败/取消清理、已安装版本与遗留半包回收、候选重新校验复用和手动清理。文件占用会显示原因并有限重试，范围限于所属更新缓存文件。
