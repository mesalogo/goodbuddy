# 桌面更新界面

遵循根目录 [UI-DESIGN.md](../../../UI-DESIGN.md)，实现 [FR-1 至 FR-7](./prd.md) 和[状态规则](./logic-design.md)。

设置的关于区域保留当前版本、启动检查、更新源和检查按钮。新增“自动下载更新”共享 Switch，说明为“发现新版本后后台下载，安装前由你选择重启”。

新版本卡片左侧显示版本与更新说明入口，右侧放“下载更新”主按钮。正在下载显示大小、进度与取消；校验阶段显示“正在校验”；ready 状态按安装适配显示“重启并更新”或“打开安装包”。系统安装交接旁明确说明仍需在系统窗口完成安装。

包文件名与校验信息放在详情中，默认只显示适用安装方式与大小。无法检测 Linux 包类型时使用带标签的原生选择控件。切换设置页后从领域快照恢复状态，不能重置下载。

失败原因与重试按钮位于下载卡片内；不再重复弹出同一错误通知。自动下载就绪提示通过全局通知呈现。进度使用带标签的 progress 元素，状态文字使用 polite live region；按钮保持键盘可操作。窄窗口主操作换行，避免撑宽设置面板。

当前 Windows NSIS 安装版在包准备完成后显示“重启并更新”，点击后显示“正在准备重启…”。有活动任务、输入草稿或未保存编辑时，卡片显示需要处理的原因，并保留重启按钮供再次尝试。保存确认期间暂时禁用窗口输入；失败恢复交互。进入关闭清理后发生的错误通过原生提示展示，因为此时界面及 IPC 已开始关闭。

检查按钮旁提供“清理更新缓存”。正在清理时显示进度文案；下载、校验、重启或已移交外部程序时禁用。清理失败在该区域显示原因，成功反馈使用全局通知。清理入口不依赖是否发现新版本，便于处理启动时发现的遗留文件。打开更新文件后说明本次进程将保留该文件，完成安装并重新打开应用后才能再次清理或下载。
