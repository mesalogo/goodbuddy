# 监督者与会话监督

监督者统一工作回顾、会话监督与故事线图谱，以智能心跳作为定时唤醒机制。现有智能心跳页面承载监督者工作回顾入口，手动回顾、定时结果投影、来源原文、实体/关系确认、继续讨论、知识库预览提交和侧栏反馈已经接入。历史回顾定位到对应结果图谱；侧栏按会话或任务查询，并支持固定目标。同 scope 的跨 run 实体复用依赖模型显式选择 Main 提供的候选引用，Main 处理 UUID 和旧文本主键的精确映射，具体规则和验证边界见[实施进度](./progress.md)。

## 文档导航

主页面包含工作回顾、故事线图谱、自动监督、活动记录和设置。工作回顾阅读统一监督结果并选择历史，图谱定位同一结果；自动监督管理计划、监督建议和只读的旧报告。活动记录展示统一执行、进度、建议阶段及详情，可按计划 ID 筛选；设置只保留算法参数。当前布局以 [UI 设计](./ui-design.md#应用入口)为准。活动读取实际手动回顾及心跳执行，合并展示同一次心跳触发的监督回顾与建议阶段；状态规则、历史缺失和保留期限见[活动记录](./logic-design.md#活动记录)。

心跳的职责为“定时触发增量回顾＋按配置介入（建议）”，不再先生成独立报告；手动“回顾”默认增量，历史重看改为显式“重新整理”。规则见[心跳职责与介入](./logic-design.md#心跳职责与介入目标设计)，需求 FR-S12，验收 US-S32、US-S33，2026-09-30 已实现（主动介入除外），验证见[实施进度](./progress.md#2026-09-30-心跳职责收敛与监督建议)。

监督回顾按来源版本及正文位置增量处理，手动回顾与心跳共享进度，无变化时跳过模型；“重新整理”才重读所选区间。旧的进度、失败重试和删除边界见[自动增量与手动重看](./logic-design.md#自动增量与手动重看)。
