# 监督者与会话监督

监督者的目标设计统一工作回顾、会话监督与故事线图谱，以智能心跳作为定时唤醒机制。计划将已有智能心跳入口升级为监督者，避免新增重复应用。当前会话监督尚在设计中，图谱仅有模拟原型，统一应用尚未接入产品。
