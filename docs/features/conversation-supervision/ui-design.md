# 监督者 UI 设计

日期：2026-09-16。状态：目标设计，遵循根目录 [UI-DESIGN.md](../../../UI-DESIGN.md)。需求对应[监督者应用产品设计](./supervisor-prd.md) FR-S1 至 FR-S9。

## 应用入口

应用中心中的智能心跳入口升级为“监督者”，沿用既有启用、常驻与排序能力。未来应用市场使用同一应用身份。用户停用自动心跳时仍可手动回顾；停用应用时明确说明关联自动计划的处理，既有结果仍保留。停用与运行中任务的具体行为需在逻辑设计中确定。

应用页使用共享 PageTabs 展示“工作回顾 / 故事线图谱”，右上角提供设置。设置包含关注范围、心跳计划和反馈方式，已有运行记录可从工作回顾进入，保留失败详情与手动运行入口。

## 工作回顾

页面顶部持续显示项目或 Global 范围、来源选择与时间区间。首次使用引导用户选择来源并生成回顾。默认查看最近一次成功结果，包含阶段决定、变化与未解决事项；每项附来源和图谱定位入口。

手动“回顾当前进展”是主要操作。生成中显示进度与取消；空范围提供选择来源入口；有来源但没有有效变化时显示检查时间和“暂无新进展”。失败保留上次结果并标明时间，提供重试。部分来源不可用时列出遗漏范围。

## 会话侧栏

右侧通用助手工作栏中的监督面板展示“监督反馈”，沿用现有[工作栏设计](../assistant-workbar/prd.md)的布局和执行边界。跟随模式对应当前会话；固定模式持续显示所选 Conversation、Task 或 Experiment，切换聊天不改变目标。反馈卡片显示所属目标、阶段、结论、未解决事项及来源。

“在图谱中查看”定位到对应阶段或节点；“继续讨论”先预览节点摘要和来源引用，允许用户移除不需要的内容，再进入会话。“发到当前会话”由用户主动触发。跨会话内容需显式显示范围，不能伪装成当前会话的观察。

## 故事线图谱

使用 master-detail 页面壳层，左侧选择故事线，中间浏览图谱，右侧按选中对象切换详情。平铺和圆形视图使用共享 SegmentedControl；同级页面导航仍使用 PageTabs。布局、连线与回放行为见[图谱设计](../story-graph/prd.md)。

窄屏时故事列表收为选择入口，详情进入可返回的独立区域；保留文字事件列表作为图谱的替代入口。节点、连线与时间事件都可从列表选择，键盘焦点可见。颜色只辅助区分故事线，关系类型还需文字说明。缩放与平移不改变右侧当前选择。
