# 监督者 UI 设计

日期：2026-09-16。状态：目标设计，遵循根目录 [UI-DESIGN.md](../../../UI-DESIGN.md)。需求对应[监督者应用产品设计](./supervisor-prd.md) FR-S1 至 FR-S9。

## 应用入口

“设置 → 模型”还提供“监督者模型”单选框：默认“跟随应用默认”，其余选项为已保存的文本模型连接，以连接名称和模型名区分，不列图片模型。失效的已选连接保留“所选模型已不可用”，用户可改选；加载或保存期间禁用选择。沿用该分类的保存按钮、未保存草稿保护和失败重试，常显说明覆盖的阶段及[生效时点](./logic-design.md#监督者模型选择)，不增加凭据输入。

应用中心中的智能心跳入口升级为“监督者”，沿用既有启用、常驻与排序能力。未来应用市场使用同一应用身份。应用已启用时，停用单条自动心跳计划仍可手动回顾；关闭应用后，已打开页面显示关闭状态并禁用工作区操作。默认值及运行边界见[应用启停与执行](./logic-design.md#应用启停与执行)。

当前应用页的顶层导航只使用一套共享 PageTabs：“工作回顾 / 故事线图谱 / 智能心跳 / 活动记录 / 设置”（英文活动标签为 Activity records）。智能心跳独立管理心跳计划；设置不含计划、报告或审计，也不显示整页全局徽标或独立刷新行。设置内用一排分段页签按用途分为“模型 / 回顾整理 / 故事与经验 / 建议”，每次只显示一个表单：模型含整理超时与并发；回顾整理含读取条数、每批文本量与消息数、单次响应容量；故事与经验含子线索与经验阈值及跨项目关联开关；建议含暂无进展天数。各分类单独保存，只提交本分类字段并沿用其他字段的已存值；切换分类保留未保存的草稿。故事线图谱没有数据时，空状态占满剩余可见高度，标题、说明与“工作回顾”按钮居中，刷新保留在共用回顾栏。计划范围仍在表单和每条计划内显示。整个页面只有一个一级标题；监督者 bridge 不可用时显示明确错误，设置仍可访问，不回退到旧心跳概览。共享页签保留方向键、Home/End、游标焦点和单一激活面板，窄窗口横向滚动。故事线图谱面板内另有分类页签，见[故事线图谱](#故事线图谱)。

工作回顾与故事线图谱在主页签下方共用回顾上下文栏。历史选择器最多占 280px，收起时只显示生成日期时间，随后是“刷新”和“新回顾”，不在右侧重复范围和覆盖区间。展开复用共享锚定单选菜单，每项显示生成时间及该结果自身的真实范围、覆盖起止时间，长说明换行；当前项带选中标记，触发按钮的无障碍描述保留所选结果的完整上下文。即使只有一条结果也显示选择器。切换页签和图谱模式时，这一栏的位置、内容和选择保持一致，空态及读取失败时仍可访问。

点击“新回顾”才展开范围、时间、发起按钮和重新整理菜单。表单位于上下文栏下方，以次级表面区分新请求与已选结果；再次点击收起并保留输入。工作回顾正文铺满页面壳层，不另设阅读宽度上限。容器宽于 860px 且有辅助内容时，左侧约占三分之二，显示工作总结和本次变化；右侧显示未解决事项、故事进展和经验，以弱分隔线分区。没有辅助内容时只保留全宽正文。窄屏按正文、辅助内容顺序排列为单列。摘要保留原有段落和换行，故事摘要保留“显示更多”及进入图谱的选择。

新回顾运行中保留已显示结果及其日期、范围，范围、时间、发起和刷新控件保持可用。手动发起、完成、暂停、取消、无变化和失败统一使用应用 Toast；重复点击发起提示已有运行，不新建或排队。同一回顾操作的通知互相替换，关闭通知不暂停或取消执行。成功和信息沿用共享自动消失时间，错误由用户关闭。页面不保留操作状态条或错误横幅，加载历史结果、切换页签和重新进入页面不触发回顾通知。

通知使用中英文可理解的状态及下一步说明，失败时引导到活动记录查看原因、继续已保存进度或重新发起。原始技术错误仍保留在活动详情。共享通知当前只提供关闭按钮，查看进度使用既有“活动记录”页签。内容加载失败继续在页面内显示本地化说明和重试，操作反馈不会清空范围、时间或已有结果；运行中刷新不丢弃随后到达的结束通知。

范围、时间和活动计划筛选保留可访问名称，不再重复显示字段标题。工作回顾不读取历史心跳报告，也不显示自动报告空态、记忆与行动建议或第二行全局范围与刷新。无监督结果时，空态独占工具栏下方整行，标题与手动回顾入口水平居中；自动报告是否为空不影响此判断。

## 会话故事图谱开关

对应 FR-S11、US-S30。输入区“选项 → 对话设置”在知识库之前显示“使用故事图谱”（英文 `Use story graph`），复用共享 `toggle-row` 滑动 Switch，标签在左、开关在右，支持 Tab 和 Space。仅当监督者应用 `heartbeatEnabled` 为 true 时渲染；应用关闭或设置尚未加载时完全隐藏，不保留禁用控件或占位。

每个会话默认开启。保存期间保留已确认状态并禁用重复提交，成功后显示新值，失败时保留原值并通过应用通知说明错误。切换会话、重新打开或重启后恢复各自设置。开关的执行规则和持久化见 [MCP 接入合同](./story-graph-mcp-design.md#6-内置-mcp-与-runtime-接入)。

## 活动

文案遵循根目录 [监督者文案规则](../../../UI-DESIGN.md#134-智能心跳)：不把内部路线图、交付状态或实现缺项展示给用户。活动页不常显重复说明；真实错误、失败和暂停状态仍展示，并保留恢复操作。事实详情提示展开批次并对照原文核对模型内容，不承诺完整语义识别；图谱说明实体状态以所选回顾结果为准。

对应 FR-S10、US-S26。活动按开始时间倒序，每页 50 条，提供较新/更早记录和刷新。列表保留触发方式、执行范围、开始/结束时间、实际状态、阶段状态、错误及已保存摘要。没有结果时不显示结果按钮；有监督结果时可分别进入该结果的工作回顾和故事线图谱，焦点移到目标页签。超过最近 20 条的结果仍按 ID 读取，不能回退最新结果。

活动页只展示统一监督活动、进度、详情及结果入口，不在列表下方重复显示心跳概览或心跳审计。计划“执行记录”打开此页并按精确 ID 筛选，筛选器显示所选计划并提供清除；监督查询在分页前过滤。同名计划仍按 ID 区分；没有匹配记录时显示筛选无结果，不回退全部数据。监督建议和历史心跳报告位于智能心跳。

“智能心跳”页依次展示范围与“刷新智能心跳”、“心跳计划”卡片、监督建议，以及只读的历史心跳报告。心跳计划卡片内不再嵌套第二层边框：标题行右侧显示运行状态点，下方一行说明文字与“创建心跳计划”按钮同行，其后直接是计划列表。说明文字按状态三选一：无计划显示“尚未配置心跳计划，目前仅支持手动回顾”，全部暂停显示暂停说明，否则显示频率帮助；不叠加第二个空态或创建入口，点击按钮打开现有 Modal。

加载、空记录和读取失败分开显示；读取失败保留已显示记录并提供就地重试。活动页面激活时，同轮读取活动和实时执行状态；有活动执行（包括停止清理）或运行中记录则在上次读取结束 2 秒后刷新，否则 10 秒后刷新，不重叠轮询。切换顶层页签、离开监督者或关闭应用后停止活动定时器，迟到响应不更新界面。错误后等待用户重试，不持续重发失败查询。

活动列表与工具栏铺满监督者页面壳层的可用内容宽度，与页签左右对齐，不另设仪表盘宽度上限。范围、计划筛选、清除筛选和刷新紧邻排列，空间不足时换行。列表使用共享表面、边框、状态颜色和按钮。每条运行首先显示类型、状态、开始时间和范围；恢复与事实操作紧随其后，再展示“收集来源 / 整理批次 / 合并摘要 / 发布回顾”。阶段使用编号圆点和连接线，宽窗口四项等宽，窄于 720px 时两列；当前及已完成阶段突出显示，不为每个阶段铺设独立色块卡片。阶段读取已保存位置和真实运行状态，剩余来源为零不表示发布成功。旧运行没有阶段字段时显示“未记录”，不猜测失败位置；已提交来源清单可确认收集结束。无变化运行不显示新结果跳转，后续无需执行的阶段单独标注。

阶段下突出显示已保存批数和剩余来源，运行中另显示合计的排队或在途数，不拆分未经接口提供的数量。已读字符数和已保存导航合并数放入默认折叠的“运行详情与配置”。字符进度按码点统计，界面不展示 Unicode 术语。恢复操作先于详情：运行中可暂停，失败或暂停后沿用同一运行继续；已记录合并、发布阶段时分别显示“继续合并摘要”“重试发布”。成功叶子保留。来源失效时显示新建回顾提示，不提供无效继续。原始错误默认折叠，展开后的完整文本最多占 240px 高度，可滚动、选择复制和键盘聚焦；错误与恢复操作位于批次树之前。结束时间、覆盖区间、报告状态和已有摘要收进“运行详情与配置”，已保存配置在其中再次折叠。

“已保留事实与来源”展开后才查询既有批次接口，每页 10 批，按本页持久记录组成项目、会话、批次层级。项目使用可用名称，会话优先使用保存来源的标题；只有已保存批次标记“已保存”，不创建未落库的待执行、在途或失败叶子，也不把本页数量当作项目总量。批次摘要收起时最多两行，展开后保留完整摘要、事件、实体、变化、关系及原文片段。来源显示消息 ID、码点范围及版本；长原文局部滚动。原生 details/summary 保留键盘展开和可见焦点，轮询不主动展开用户收起的会话。加载、空批次和读取失败分开显示，失败可重试；换页失败不显示上一页批次，切换 run 后旧响应失效。暂停状态为“未完成，可继续”，手动回顾主动暂停后在工作回顾页提示去活动继续，不显示完成通知。

活动页运行中同时提供“暂停回顾”和“取消回顾”，继续后的运行也可操作。停止期间禁用两项操作，并在运行标题和当前阶段显示“正在暂停”或“正在取消”；即使持久记录已经为已取消，只要执行尚未停止就继续显示“正在取消”。重新进入活动页通过实时执行状态恢复该提示。停止后显示“已取消”，保留事实详情，不显示继续按钮或失败恢复提示；任一回顾执行或停止清理期间，其他记录的继续按钮禁用。

## 智能心跳设置

没有自动运行、报告或关联建议时，只展示计划配置和已有计划，不显示零值统计、空趋势、建议、报告或审计区。手动回顾不计入心跳统计；产生自动运行或报告后展示对应结果区。

设置的四个分类共用一个设置面板，使用共享表面、边框和卡片圆角。面板内边距为 `--space-4`（16px），分段页签按内容宽度靠左，与下方表单间隔 `--space-6`（24px）；页签和表单标题左对齐。表单不再另设边框、底色或内边距，说明段落不叠加浏览器默认外边距。页签及设置面板不参与 Flex 高度压缩，窄窗口页签在自身内部横向滚动，长表单随页面纵向滚动。

模型分类的标题为“模型与运行限制 / Model and execution limits”，包含监督者模型选择、整理超时与并发。整理超时为 30 至 600 的整数秒，默认 240；监督模型并发数为 1 至 4 的整数，默认 1。保存字段为 `supervisorModelProfileId`、`supervisorOrganizeTimeoutSeconds`、`supervisorModelConcurrency`；心跳不再单独调用报告模型，此处不显示报告超时。无效输入不能提交，设置加载/保存中或锁定时禁用，失败保留草稿并提供重试。超时以阶段读取设置的时点为准，不改变已冻结的值；并发数影响后续派发，降低上限不打断在途请求。

并发说明明确监督模型调用共用上限，排队不计入模型超时；普通聊天不受此设置限制，但仍与监督竞争上游额度。表单不宣称提供商全局并发、RPM、TPM 或 Retry-After 限流已实现。

模型超时不包含数据收集与保存，直连模型另有独立 600 秒传输超时。“回顾算法”表单提供“每次读取来源条数”“每批文本量”“每批消息数”和“单次响应容量”，显示默认值及合法范围，使用“保存回顾算法”独立提交。文本量内部仍按 UTF-16 单元计算，界面不要求用户理解编码单位。保存经 App 的现有设置回调进入共享设置存储，加载/保存/锁定时禁用，失败保留草稿。取值以[当前设置合同](./review-scheduling-design.md#当前设置合同)为准。帮助说明回顾持续处理至完成，每批保存进度，可从活动记录主动暂停并继续；已保存配置用“同时处理任务数”解释并发，说明实际并发还受当前监督设置限制。

对应 US-S22 至 US-S24。“智能心跳”先显示心跳计划列表，点击创建或编辑才打开 Modal；复用原表单，不保留页面内副本。表单展示名称、项目范围、每日或每周频率、指定时间、回顾窗口（1 至 720 小时）和历史保留（1 至 365 天）；每周显示星期选择。时区常显，新建使用本机时区，编辑保留计划原时区。列表上方帮助说明选择每日或每周时间、保存并启用后自动运行。

无计划时显示“尚未配置心跳计划，目前仅支持手动回顾”；全部暂停时另行说明。加载或首次读取失败不显示未配置状态。打开页面、Modal 或填写字段均不创建计划，只有点击“保存并启用计划”才提交创建。已有计划显示范围、周期、时区、回顾窗口、保留期限和启停状态，保留编辑、暂停、恢复、立即运行、执行记录和确认删除；暂停时不显示待执行的下次时间，编辑保存不改变暂停状态。

Modal 按[共享表单 Modal 规则](../../../UI-DESIGN.md#615-表单-modal)复用 header、body、footer：标题左侧、带本地化名称和工具提示的 X 右侧；底部取消次按钮、保存主按钮整体右对齐。标题和操作区保持可见，仅表单内容滚动。表单使用独立字段容器，不嵌套设置表单；窄窗口表单单列，保留共享窗口安全边距。

沿用整窗 Portal、共享遮罩、背景 inert、焦点循环与关闭后焦点恢复；初始焦点进入名称。X、Escape、取消或点击遮罩关闭时，有未保存修改先确认；确认初始焦点为继续编辑，Escape 或 X 只返回编辑，点击遮罩不放弃修改。保存期间禁止关闭和重复提交，失败在表单内显示并保留草稿。

界面及可访问名称统一使用“智能心跳 / 心跳计划 / 回顾”；心跳负责定时触发回顾和按计划介入，回顾本身由监督者完成，保留内部 heartbeat 标识及已有计划名称、报告正文。表单继续使用共享控件和容器响应式布局，建议及审计无需先进入即可配置计划。

### 算法配置设置目标

以下高级分组为目标交互；已接通的四项算法控件以上节为准。其余参数引用[设置配置清单](./review-scheduling-design.md#4-设置配置清单)，不在 UI 文档另设数值，不增加一级页面。

普通配置常显消息每页条数、监督并发、报告/整理模型超时和单次响应容量。高级配置按“来源与分块”“上下文与输出”“汇总与内存”“超时与续跑”“上游额度”分组。消息页字段的常显帮助为：“每次从数据库读取的消息数；会持续读完所选范围，不限制回顾总消息数，也不决定每次发给模型的消息数。”模型批次消息数、片段数和新增字符数分别标注，避免统称“批量大小”。

字段显示单位、已确定的默认值和合法范围；补充帮助说明调大后的内存、等待或模型用量影响。允许继承的节点超时显示“继承监督整理值”及解析后的秒数；依赖模型容量的输入/输出预算显示所用模型、容量及 token 是否为估算。跨字段校验覆盖输入与输出预留之和、扇入可容纳性、退避起始与上限；错误附在字段并关联可访问说明，提交时聚焦首个错误，Main 仍作权威校验。

规划中的“保存配置”持久化后只用于新建运行，常显“已开始和待继续的回顾沿用启动时配置”。“恢复本组默认值”只修改该组草稿，经保存才生效，不开始回顾、不修改已有计划；取消编辑恢复已保存值。运行详情展示本次实际配置，继续操作沿用它；想采用新算法配置时使用“重新回顾”，说明会重新计算。当前已实现字段仍按上文的阶段读取和共享池生效方式工作，整次 run 冻结接线完成后再统一调整提示。

初次加载、读取失败、编辑、保存中、保存失败和已保存分别呈现；读取失败不填假默认值，保存失败保留草稿并允许重试。保存成功使用应用通知，字段错误就地显示，不重复通知。窄窗口按单列排列，折叠标题可键盘操作，单位和关键生效说明不藏进悬浮帮助。

只在真实 Main/存储/运行路径接通后显示相应可编辑字段；尚未实现的配置留在设计文档，不放置永久禁用的假控件。已接通但因加载、保存或依赖缺失而临时不可编辑时说明实际原因。上游额度明确显示适用连接/模型和是否包含普通聊天；未实现跨路径共享时不得标为提供商全局限制。覆盖完整性、来源校验及事实保留不提供开关。

## 工作回顾

2026-09-30 已实现（规则见[心跳职责与介入](./logic-design.md#心跳职责与介入目标设计)）：主按钮“回顾”执行增量整理，文案不再称“重新分析”；旁边“更多”菜单提供“重新整理…”，确认对话说明将重新分析所选区间并可能产生模型费用。计划 Modal 增加“介入方式”单选：“生成建议”“仅更新记忆”；主动介入上线前不显示。最近建议替代，每条建议显示依据、打开来源及转任务／确认／忽略。“最近建议”替代，每条建议显示依据、打开来源及转任务／确认／忽略。

当前页面提供全局或单项目范围。时间选择保留 1、7、30 天快捷项，默认 7 天，并提供“自定义天数”和“指定日期”。快捷项与自定义天数均从提交时刻向前计算，每天按 24 小时计；自定义值必须为正整数，且起始时间不得早于公元 1 年。

指定日期使用带可见标签的原生日期输入，按本地时区解释。起始时间为开始日期的零点，结束时间包含结束日期全天：取下一个本地日期的零点减 1 毫秒，跨夏令时不按固定 24 小时推算；结束日期为今天时截到提交时刻。允许同一天，拒绝缺失、无效、未来日期及开始晚于结束。天数和日期输入复用共享字段样式，窄窗口换行；错误就地显示，通过 `aria-invalid` 和 `aria-describedby` 关联输入，无效时禁用回顾和重新整理，提交入口再次校验。

重新整理确认显示当前范围及最近天数或明确起止日期，日期文案说明本地日期和今天截至当前的规则。修改范围或时间输入后关闭旧确认，重新整理仍需再次确认。新选择只改变请求时间范围，普通回顾继续跳过已处理且未变化的来源，重新整理仍使用既有显式标记，不改变增量处理规则。

没有自动计划也能手动回顾；成功结果显示自身冻结的范围、时间和未解决事项，可选择历史结果或进入图谱。来源筛选由本次回顾范围和时间限制；图谱详情只列出所选事件的关联来源，实体或关系列出相关事件的来源。独立的来源类型选择器尚未实现。

选择历史结果后，图谱读取该结果的成员和内容，历史菜单显示其回顾区间和生成时间。切换时清空旧图谱和详情并显示加载状态，迟到请求不得替换新选择。确认、修订和移除反馈更新当前所选结果，后续自动回顾不改写旧结果。

手动“回顾当前进展”新建回顾，活动页“继续”恢复原 run；运行中再次发起按上文显示提示，停止清理结束后才能开始新回顾。失败保留上次结果、本次范围和成功批次；已取消回顾不能继续。手动操作不推进自动位置，删除报告也不重置自动位置。

## 会话侧栏

监督反馈标题右侧使用共享紧凑图标按钮固定/取消固定目标与刷新回顾；固定状态通过
`aria-pressed` 和按钮高亮表达。目标正文显示会话或任务名称，名称缺失时使用“未命名会话”
或“未命名任务”，原始 ID 仅作为悬停补充。无目标时禁用固定和刷新，读取中禁用刷新；
窄侧栏中的长标题换行，按钮保留可见键盘焦点。

仅在应用已启用时挂载监督面板及固定目标控件；关闭或设置尚未加载时不挂载，也不发起面板查询。任务列表仍按原规则显示。

任务中心从上到下依次显示项目概览（含当前会话统计）、监督反馈、项目任务。

右侧通用助手工作栏中的监督卡片展示“监督反馈”，沿用现有[工作栏设计](../assistant-workbar/prd.md)的布局和执行边界。当前支持 Conversation/Task：有选中任务时跟随任务，否则跟随会话；“固定监督目标”保存当前目标，切换聊天后保持，取消固定恢复跟随。卡片显示目标、结果真实范围、回顾区间和摘要，可刷新并查看匹配来源；无目标或无匹配结果显示空态。Experiment 尚未接入。

有匹配结果时提供“在图谱中查看”，打开现有监督者页面的图谱页签并读取该结果；无匹配结果不显示入口。按钮保留原生键盘操作，进入后焦点落在图谱页签，继续使用共享 PageTabs 的方向键导航。固定目标不因跳转改变；再次点击相同或不同结果均重新定位，包括页面缓存后再次进入。结果不可用时显示错误并重试原 ID，不展示默认最新结果。

“继续讨论”直接准备上下文，不要求先查看来源。预览顶部单独显示目标会话，下方“发送内容”文本域直接填入实际回顾与来源正文，用户可编辑或删除其中任意内容。发送仅提交当前文本域内容，不再暗中拼接上下文，也不提供额外的展开区。只有点击“发送”才提交，取消不发送，失败保留整份草稿。固定任务使用其关联会话，无法确定发送会话时禁用。上下文仅包含所选来源关联的事件、实体、关系及原文快照，不带入整份全局回顾摘要；没有关联事件时只使用来源。切换目标使旧来源请求和预览失效。查看来源不自动跳转，用户点击“打开会话”才导航。侧栏不再显示实体写入或知识库选择器，现有知识库数据不受影响。

侧栏与图谱来源详情共用编辑区样式：目标区底部使用弱分隔线，区块间距为 `--space-4`，标签与文本域间距为 `--space-2`。文本域默认十行，可纵向调整大小；长内容在文本域内滚动。底部复用 `custom-task-dialog__actions`，取消在前、发送在后，整体右对齐。

## 故事线图谱

历史选择统一由上述回顾上下文栏承载，不占用画布面包屑。首次进入默认最新结果；两页之间切换保留所选结果，从侧栏或建议显式打开的结果、故事、经验优先于默认值。切换结果时清除旧来源详情，迟到请求不得覆盖新选择。平铺与时间螺旋均为上方标题工具栏、下方画布两层。标题工具栏使用相同的正文大小、内边距和淡分隔线；螺旋的“全部 / 项目 / 功能”面包屑旁放层级下拉菜单、图例 i 图标，右侧保留共享 SegmentedControl 的“平铺 / 时间螺旋”切换。窄窗口允许标题区控件换行，画布内不另设工具栏。

时间螺旋使用所选回顾的时间区间与完整事件集合，半径和区间着色规则见 [3D 密度规则](../story-graph/3d-concept.md)。当前故事成员按精确事件 ID 与结果求交；其余事件按来源确定的项目进入“当前无故事归属”分组，项目未知时显示“项目范围不可用”。图例说明“本次回顾事件按当前故事归属分组；未保存当时的故事归属”。故事与经验列表仍提供该范围的当前完整记录，供查看和调整。

根视图直接显示事件点，同一主故事的邻近事件按画布密度聚合并显示数量，未归属点使用中性色。事件和经验从左侧列表选择，画布不重复提供这两种选择器。保留一个层级菜单：左侧列表选择记录并打开详情，标题区层级菜单改变画布中的项目、功能或子线索层级。菜单与面包屑均可用键盘操作。默认斜俯视，不显示视角按钮、菜单或页签；自由拖动、平移、滚轮、方向键、数字键和 Escape 返回上层操作保留。

关联来源详情属于会话时，显示“打开会话”按钮，使用来源保存的会话 ID 跳转并切换到所属项目；不发送消息或启动回顾。另提供“继续讨论”，使用上述可编辑正文预览，点击发送后提交到来源会话并打开它。详情继续展示整理时保存的原文快照。会话已删除或读取失败时，沿用应用会话导航的提示；其他来源类型不显示此按钮。

左侧使用共享 PageTabs 切换“事件 / 实体 / 关系”，显示各类数量，一次只展示一类列表，无记录时显示本次回顾的分类空态。页签固定在顶部，列表占满剩余高度并独立滚动。切换页签不清除当前图谱选择；从画布、事件浏览或详情选择对象时同步切到对应页签。支持方向键、Home/End 和面板键盘聚焦。

使用 `supervisor` 页面壳层，最大内容宽度为 `1440px`。当前生产图谱左侧为紧凑的事件、实体和关系列表，中间为 SVG 画布，右侧为详情与来源。桌面列宽为 `216px minmax(0, 1fr) 280px`，画布获得主要空间。外圈事件按发生时间排序后等距逆时针排列，不表示实际时间间隔；起止之间保留缺口和方向箭头。内部显示真实实体名称，实线仅连接实际事件与实体，虚线仅连接实际实体关系。

高度按窗口剩余可见空间计算，底部保留约 24px 边距（不小于页面底部内边距）。平铺图最低 660px，时间螺旋最低 320px；低于最小高度时页面允许纵向滚动。中间画布不内部滚动，工具栏与事件浏览栏之外的空间给图；左侧列表和右侧详情各自滚动。两种视图的图例均使用共享 InlineHelp 的纯 i 图标，保留可访问名称和 title；点击或 Enter/Space 固定展开，再次点击、Escape、点击或聚焦外部关闭。平铺可见数量仍在画布角落；螺旋左下角不显示圈长及圈数，这些信息收进图例。窗口尺寸及上方表单展开、收起后重新计算可用高度。

实体及其影响连线复用现有 `--graph-node-*-border` 令牌；颜色用于辅助辨认实体，不代表故事分类或确认状态。选中项加粗并突出连线，其余节点降低图形强调度但保留可读文字。详情分为名称与说明、图谱关联、确认操作和来源，来源正文按需读取。图例及读图说明按需展开。

画布每批最多显示 8 个事件、6 个实体；同时间事件分开排布。列表保留全部返回记录和完整名称，选择实体会定位到真实关联事件所在批次，选择关系会优先显示两端实体。滑块明确命名“事件浏览”，只切换当前事件，不还原实体历史状态，也不宣称完整历史回放。当前接口返回单条故事线，不复制 Demo 中的三条模拟故事。后续视图规划见[图谱设计](../story-graph/prd.md)。

按实际工作区容器宽度响应：宽于 `1190px` 保留三栏和左侧分类页签；`861～1190px` 为 `184px` 列表加画布，分类改用紧凑选择框。详情通过工具栏按钮或选择记录打开，作为图谱右侧的非模态面板，不在画布下方增加长区块；关闭按钮和 Escape 返回详情触发按钮。`860px` 以下画布优先，列表在下方、最高 320px，详情面板不超过画布高度。SVG 随画布缩放，390px 下页面和画布均不横向滚动；缩小后的完整名称可从列表读取。范围、时间和操作按需换行。节点、关系与事件均可从列表选择，画布节点支持 Enter、Space 和可见焦点。加载、无数据、读取失败和服务不可用各自呈现，错误提供重试入口。

隔离视觉验证使用 `tests/support/supervisor-layout-regression.tsx` 渲染生产 React 组件；所有输入标为模拟 fixture，不读取用户数据库或调用模型。`tests/supervisor-layout.electron.test.ts` 启动 Vite 与 Electron，通过 `executeJavaScript` 测量布局、`capturePage` 截图，覆盖 1440、1024、390px、浅深主题、长名称、密集事件和异常状态。可通过 `GOODBUDDY_SUPERVISOR_ARTIFACTS` 保留截图；交互预览入口为 `node tests/support/supervisor-preview.mjs`。

设置 `GOODBUDDY_SUPERVISOR_CONTENT_LAYOUT=1` 验证工作回顾、空态、活动、待处理及失败场景，在 2000、1440、1024、390px 和浅深主题下共 40 个组合，检查全宽、空态居中及位于工具栏下方、阶段连接线和长内容溢出。

设置 `GOODBUDDY_SUPERVISOR_SETTINGS=1` 只验证设置布局：四个分类分别覆盖浅深主题及 1440×1100、1024×768、390×480，共 24 个组合。检查五个主页签、四个设置页签、单一可见面板、16px 内边距、24px 内容间距、无嵌套表单边框及横向溢出，并保存截图与几何测量；使用生产组件和模拟设置，不调用模型。

设置 `GOODBUDDY_SUPERVISOR_PLAN_MODAL=1` 可只验证五页签 fixture 中的计划 Modal：创建和编辑各覆盖浅深主题、1440×1100、390×1100、390×480，检查关闭按钮、底部按钮对齐、正文滚动、鼠标命中和原生键盘操作。截图及测量写入同一产物目录。

设置 `GOODBUDDY_SUPERVISOR_RECAP=1` 可验证本次工作回顾分区：1440×1100 和 390×1100 下覆盖监督结果与自动报告均有内容、仅有监督结果、两者均空，另检查历史结果运行中仍可阅读以及活动入口。该分支检查每页一处刷新、自动报告和建议的归属、正文段落与宽度，并截取自动页建议、展开报告和审计区块。
