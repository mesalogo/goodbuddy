# 监督者 User Stories

日期：2026-09-16。以下为目标验收场景，尚未接入生产验证。需求编号引用[监督者产品设计](./supervisor-prd.md)与[故事线图谱设计](../story-graph/prd.md)。

| 编号 | 用户故事 | Given / When / Then | 需求 |
| --- | --- | --- | --- |
| US-S01 | 启用后知道监督者关注哪些工作 | 给定未配置的新用户；当从应用中心启用并选择项目、来源和时间；则生成前显示范围，未选来源不被自动纳入 | FR-S1、S3 |
| US-S02 | 隔几天回来能继续上次工作 | 给定已有阶段记录；当打开工作回顾；则看到已有决定、未解决事项和来源，并可定位图谱 | FR-S2、S5 |
| US-S03 | 自动检查不过度打扰 | 给定已启用心跳计划；当一次检查没有有效新变化；则记录检查结果，不重复推送旧反馈 | FR-S4、S5 |
| US-S04 | 查看某个事件影响了哪些认识 | 给定时间点含多个事件；当展开并选择一个事件；则相关实体与连线高亮，详情提供事件原文位置 | FR-G2 |
| US-S05 | 追溯同一个知识实体的多次变化 | 给定实体先后被提出、补充和修订；当选择该实体；则同时看到多个时间点及其关系，不复制为多个同名实体 | FR-G1、G3 |
| US-S06 | 知道不同故事为什么有关 | 给定跨故事关联；当选择连接线；则展示关联类型、理由和两端依据，可确认、纠正或移除 | FR-S9、FR-G4 |
| US-S07 | 复盘一段时间 | 给定已有过程记录；当选择时间区间；则总结只覆盖该范围，展示决定、变化和未解决事项；回放不使用未来结论 | FR-S9、FR-G5 |
| US-S08 | 回到知识库核对依据 | 给定知识实体引用已有资料；当点击相关资料；则本地资料打开原条目及位置，且支持返回图谱；外部引用打开已保存片段与可用定位信息，缺少位置时提示 | FR-S7、S8 |
| US-S09 | 补充知识而不重复保存 | 给定候选归纳与已有本地条目；当选择补充并确认预览；则修改原条目并保留引用；外部只读资料不提供写回操作 | FR-S8 |
| US-S10 | 纠正错误关系 | 给定自动归纳有误；当修改或移除关系；则原文保留，可撤销，后续自动整理不静默覆盖用户修改 | FR-S6、S9 |
| US-S11 | 带着已有认识继续讨论 | 给定选中的知识实体；当预览并确认摘要与来源；则会话携带所选上下文，后续内容可纳入下一次整理 | FR-S3、S5 |
| US-S12 | 生成失败后仍能使用旧结果 | 给定已有成功回顾；当新一次整理失败或取消；则旧结果仍可访问，失败或部分完成状态明确，可重试 | FR-S6 |
| US-S13 | 来源变化后不会误读历史 | 给定来源已更新或失效；当回放旧阶段并打开引用；则显示可用的历史依据，缺失旧版本时提示，不能将最新版称作当时原文 | FR-S9 |
| US-S14 | 升级入口后原计划仍可管理 | 给定已有心跳计划和启用偏好；当应用升级为监督者；则保持计划、运行记录与偏好，不出现第二个重复应用入口 | FR-S1、S2 |
| US-S15 | 在窄屏或仅用键盘时查看图谱 | 给定无法方便点击图形的用户；当使用事件与节点列表选择对象；则能查看相同详情、关系与来源，并返回原选择位置 | FR-G6 |
