# 从图谱读取会话上下文

`story_graph_read_source` 默认使用 `content_kind: current`，读取来源对应的当前完整消息；不再默认返回整理时保存的片段。

```json
{
  "source_reference_id": "从事件 source_ids 获取的引用",
  "before": 5,
  "after": 5
}
```

`before`、`after` 默认均为 0，可分别设置 0–50。指定后返回同一会话内、按消息顺序排列的已完成或出错的用户／助手消息，并标出依据消息（`anchor`）。到达会话边界时只返回实际存在的消息。返回内容包含会话名称、项目、消息角色、时间及正文。

`page_size` 是本次返回的正文码点总预算，不是消息数量。长消息和剩余消息通过 `next_cursor` 继续读取；翻页时保持参数不变。消息正文的 `position` 标明本页区间，不静默丢弃后续内容。上下文发生变化时要求重新开始读取。

前后消息只支持 `current` 和会话来源。显式指定 `snapshot` 仍可读取回顾时保存的片段。当前消息不可用时返回 `current_source_unavailable` 及可用模式，不把历史片段冒充当前消息。项目权限与会话图谱开关沿用既有工具执行检查。
