# 魔法笔记与会话联动

状态：会话联动前后端已实现，真实 Electron 验收通过；全仓验证未全绿。聚焦结果、fixture 修复后复跑及执行时的全仓失败见 [progress.md](./progress.md)。

## 目标与范围

用户在阅读回答时，可将内容保存到已有笔记或新笔记，并从笔记返回原会话。会话界面提供文字预览和保存位置选择，与已有 Agent 笔记工具共用存储。

独立工作区继续承载完整编辑、画布、待办和 AI 评论；右侧笔记面板提供浏览和快速追加。笔记仍属于全局，不因入口所在项目改变归属。

## 功能要求

| 编号 | 要求 |
| --- | --- |
| FR-1 | 右侧助手工作栏增加“笔记”应用，支持搜索、打开已有笔记、新建笔记、查看记录摘要、快速追加文字，以及打开对应完整工作区。 |
| FR-2 | 助手消息操作栏提供“加入笔记”，打开可编辑预览，用户选择已有笔记或新建后明确提交。 |
| FR-3 | 会话标题的更多菜单提供“保存当前对话到笔记”，按触发时的会话内容生成预览，保存为目标笔记中的一条记录。 |
| FR-4 | 通过右侧工作栏“+ → 笔记”打开面板并恢复当前应用会话中最近选择的笔记，首次使用显示列表，不隐式保存当前对话。左侧底部和聊天页头不再提供重复的“快速笔记”入口。 |
| FR-5 | 从会话保存的记录保留结构化来源，显示会话名称、所属项目（如有）和采集时间，支持返回原会话及单条来源消息。源会话删除后保留笔记内容。 |
| FR-6 | 面板、完整工作区和 Agent 写入使用同一份笔记数据，成功写入后更新已打开视图，同时保护未保存草稿。 |
| FR-7 | 笔记支持手动标签。每篇最多 10 个，单个标签最长 24 字，不区分大小写，同名只保留首次写法。在笔记标题下添加或移除标签；添加时提示已有标签，也可以直接新建。 |
| FR-8 | 总览可按标签筛选，多选时只显示同时带有全部所选标签的笔记；搜索框也能匹配标签名。打开笔记后，左侧列表沿用当前筛选，并提供清除入口。 |
| FR-9 | 提供“管理标签”入口，列出全部标签及使用篇数。可以重命名标签；新名称与已有标签相同时，两个标签合并。删除标签时，它会从所有笔记中移除，笔记本身保留。 |
| FR-10 | Agent 笔记工具可在创建、修改笔记时设置标签，并可按标签列出笔记。只在用户要求时修改标签，不自动打标签。 |

标签第一版不提供颜色和层级（如“工作/项目A”），“/”只作为普通字符保存。没有笔记使用的标签会自动删除。

首版不包含自动总结、自动分类、自动选择保存目标、选中文本采集、多条消息勾选、附件文件复制或跨设备同步。“总结后加入”和选区采集作为后续扩展，不预留不可用按钮。

## 产品验收

- 首次使用且没有笔记时，可从一条助手回答创建笔记并保存首条记录；已有笔记时可搜索并追加，原记录保持不变。
- 保存当前对话包含未在屏幕上渲染的历史正文；预览范围明确，超出容量时提示缩减内容，不静默截断。
- 保存成功后显示目标笔记并定位新增记录；取消不写入，失败保留内容和目标供重试。
- 从来源条可返回对应会话；会话已删除时显示“原会话已不存在”，已保存正文仍可阅读和编辑。
- 面板追加后完整工作区可见，Agent 修改后面板可见；后台刷新和切换会话不覆盖未保存文字。
- 给两篇笔记加上“Work”和“work”，只会得到一个标签，计数为 2。选中两个标签后，只显示同时带有这两个标签的笔记。把“Work”重命名为已有的“发布”后，两个标签合并，两篇笔记都不会丢失。删除标签不会删除任何笔记。
