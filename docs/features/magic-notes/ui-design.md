## 入口

| 位置 | 文案与动作 |
| --- | --- |
| 助手工作栏“+”菜单 | 增加“笔记”，打开或激活单个笔记 Tab。 |
| 助手消息底部，复制旁 | 图标按钮“加入笔记”，进入该消息的采集预览。 |
| 左侧会话列表操作菜单 | “复制完整会话”下方提供同级的“保存完整会话到笔记”，加载所选会话的完整历史后进入整段采集预览；该会话运行中（含排队、工具执行、等待问答或审批）、采集加载或保存期间置灰，结束后恢复可用。运行时悬停提示等待回答完成或停止生成。魔法笔记禁用时隐藏此项。聊天标题旁不再保留独立的保存菜单。 |
| 面板笔记标题旁 | “在完整工作区打开”，进入当前笔记；有待保存文字时先处理草稿。 |

左侧主导航中的“魔法笔记”继续打开独立工作区。紧凑面板通过工作栏“+ → 笔记”打开，左侧底部和聊天页头不再提供重复的“快速笔记”入口。

## 紧凑面板

面板按单列显示列表或笔记详情，不嵌入完整工作区的多栏布局。搜索位于列表顶部，“新建笔记”在列表之后；笔记行显示标题、置顶状态、两行摘要和更新时间。无笔记时提供新建动作；搜索无结果时保留搜索词并允许创建。

详情顶部提供返回列表、笔记标题和打开完整工作区，不显示“全局”标识。中间以可滚动记录摘要供浏览，每条文字摘要最多显示前 600 个字符，画布显示首页缩略图及页数；记录按钮可在完整工作区定位该记录。底部提供快速追加文字输入区与“加入笔记”按钮，画布编辑、待办管理和 AI 评论阅读仍在完整工作区。

从会话触发时，面板切到采集编辑视图：

```text
加入笔记
来自：项目 / 会话标题 · 单条回答或当前对话
来源旁帮助按钮：按需查看保存范围

[可编辑文字预览]

保存到
[搜索或选择已有笔记]
[新建笔记 → 标题输入]

                      [取消] [加入笔记]
```

范围说明随单条或整段来源调整，通过来源旁的 `InlineHelp` 按需查看；回答未完成的警告仍直接显示。预览初始包含完整待保存文字，可滚动编辑。新建目标标题默认取会话标题前 100 个字符，可修改；已有目标与新建目标使用共享 `SegmentedControl` 切换。采集内容为空或超限、缺少目标、新建标题为空或超限时禁用保存；初始不显示通用校验说明，正文和标题超限时在对应字段旁提示。普通新建允许创建空笔记。

底栏默认仅显示右对齐的操作按钮。保存失败时保留草稿，错误与按钮在宽面板中同行，窄面板中错误换行、按钮仍靠右。完整工作区的文字保存按钮在窄窗口中也保持内容宽度并右对齐。

预览和快速追加输入框通过无障碍名称“待加入内容”标识，不再显示重复标签。提交区仅显示校验或保存错误，不显示“全局”。提交与来源跳转按钮组均居右，可在窄面板换行；来源没有项目名时省略项目及分隔符，不补写“全局”。

读取失败显示就地重试按钮；保存失败保留输入并在提交区显示错误，用户可再次点击“加入笔记”。成功通过应用通知反馈，切回目标笔记详情，滚动定位、聚焦并高亮新增记录约 2.4 秒。仅“保存后自动评论”模式发起后续分析，分析失败另行通知，已保存内容保留。

## 来源与可访问性

记录摘要和完整工作区的已保存记录均显示“来自会话”来源条，内容含保存时标题、项目及采集时间。单条来源提供返回会话和定位原消息按钮，整段来源提供返回会话按钮。点击后确认原会话不存在才显示对应文案并禁用跳转；其他错误提供就地重试。来源条与正文分开，编辑正文时仍可识别来源。

Tab 使用工作栏现有的共享页签、焦点和关闭模式。搜索有持久标签，列表用可键盘访问的按钮；打开采集后聚焦预览，取消返回消息操作按钮或所选会话的更多操作按钮，触发按钮已不可见时尝试返回工作栏开关。新建标题出现后聚焦输入框。面板中的 Escape 取消当前草稿，或从详情返回列表；需要放弃输入时先显示草稿确认。确认框初始聚焦“继续编辑”，限制 Tab 焦点范围，Escape 保留草稿并关闭确认。

## 笔记问答

FR-12～FR-14：AI 面板底部放置上下文选择、自由问答输入框和“提问”按钮。上下文选项为“当前页／指定页码／全部文档”，当前记录编号持续可见。指定页码显示起止页输入，反向或越界范围直接报错。问答历史在独立滚动区显示，右上角为无边框垃圾桶图标按钮（名称和提示文字均为“清空问答历史”）；请求期间禁用重复发送，失败保留问题。问答请求上限（单次 50 张图、24 MiB 图片、20 万字符）不常驻显示，只在超出时通过错误提示说明上限和处理方法。

输入框下方左侧为无边框的“框选当前页”图标按钮（裁剪图标，名称和提示文字均为“框选当前页”），右侧为“提问”。点击后在中间画布的当前页上叠加框选遮罩，并获得焦点，顶部和按钮旁显示“在页面上拖动框选；Enter 选整页，Esc 取消”。松开鼠标即生成区域截图，不需要二次确认；单击未拖动不算选区。键盘用户按 Enter 选整页，方向键移动选区，Shift+方向键调整大小。框选期间按钮切换为“取消框选”，再次点击或 Esc 退出，不截图、不发送，焦点返回按钮。

截图后，输入框上方立即显示缩略图，上下文切为“所选区域”。缩略图右上角为无边框 × 按钮（“移除截图”），移除后返回“当前页”。框选期间若翻页，该区域作废并提示重新截取。不提供百分比数值输入框。

仅文本问答时就地显示“未查看图片、手写和布局”。请求预算及导入保存不受影响的说明位于输入框上方。窗口变窄时沿用工作区已有的底部 AI 面板；问答区内部可滚动，保留输入框和操作的可访问性。

## 富文本表格

富文本编辑器使用共享表单 Modal 插入表格，行数限制为 1-20，列数限制为
1-12。取消、关闭、Escape 和遮罩点击不会修改内容，关闭后焦点返回“插入表格”
按钮。表格操作使用紧凑图标按钮，保留本地化的可访问名称和提示；未选中表格单元格
时，插入行、插入列和删除操作保持禁用，避免误操作或嵌套表格。每个表格操作形成
独立的撤销步骤。已保存表格在只读记录视图中继续由 Quill 以不可编辑单元格显示。

面板服从工作栏现有宽度和停靠规则，以单列切换列表、详情和采集编辑。按钮组可换行，文字摘要保留换行并折行长文本；Markdown 和代码以原始文字显示。头部与快速追加区固定，中间内容独立滚动；完整预览输入区可纵向调整大小。配色、按钮、焦点环、通知和确认使用共享组件与令牌。真实 Electron 已在实测 214px 面板验证无横向溢出，以及原生键盘返回列表、打开笔记和追加保存。
