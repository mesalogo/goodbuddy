# 会话联动逻辑设计

状态：已按当前实现核对，验证进度见 [progress.md](./progress.md)。需求编号来自 [PRD](./prd.md)。

## 内容与来源

FR-2、FR-3：单条采集读取所选助手消息的非空正文；整段采集先加载该会话完整历史，再按消息顺序收录用户和助手的非空正文，保留角色分隔。预览建立后，切换会话或收到新消息不会替换正文及来源标识。生成中的消息不可采集，停止或失败后已有正文可保存，单条预览注明回答未完成。整个会话正在生成时禁用整段采集，提示等待完成或停止生成。

首版按文字保存，保留原始 Markdown 文本、换行和代码文本，不承诺还原聊天渲染效果。推理、工具调用日志、系统提示、附件二进制和图片不进入正文；预览持续说明保存范围。用户可编辑预览，来源仍指向本次采集的会话。读取完整会话失败时不以屏幕上已有消息代替。

FR-5：来源独立于可编辑正文。单条来源包含会话和消息标识；整段来源包含会话标识、此次收录的消息标识及采集时间。预览使用采集时的会话标题和项目名称；保存时主进程校验消息归属，并以当时数据库中的会话标题和项目名称写入来源，无项目时显示全局。若预览期间源会话或消息已删除，保存失败并保留预览。保存完成后，修改或删除源消息不回写笔记正文和来源。

点击来源时读取完整会话。消息不存在但会话仍在时打开会话并提示“原消息已不存在”；确认会话不存在后保留来源文字，并在当前来源条禁用跳转。其他读取失败显示可重试错误。打开未渲染的来源消息时扩大聊天历史显示范围，再滚动定位并聚焦。编辑笔记正文不移除来源；删除笔记不影响源会话。

## 面板与草稿

FR-1、FR-4：笔记应用为可关闭、可排序的单实例工作栏 Tab，新布局默认不打开。再次触发入口激活现有 Tab；笔记选择属于应用级状态，切换项目或会话不改写它。列表按置顶优先、最近更新时间排列，搜索匹配标题与记录文字，同一笔记只显示一次。当前应用会话内保留最近选择，重启不恢复笔记选择或草稿。该笔记已删除时回到列表，清除失效保存目标并保留待保存文字。

FR-2、FR-3：面板有浏览、采集编辑、保存中三个状态。触发采集进入编辑态；选择目标只改变写入位置；明确点击“加入笔记”才写入。每次提交新增一条记录，不覆盖旧记录。新建目标时先填写标题，会话标题作为可修改默认值；提交一次创建笔记和首条记录，取消不遗留空笔记。普通“新建笔记”仍可显式创建空笔记。

保存中禁用重复提交和面板离开操作，结果返回后可再次操作。成功后清除本次草稿，显示响应返回的新增记录；失败保留预览、标题和目标。目标已删除时提示重新选择。容量校验使用现有文字记录限制，超限由用户缩减正文后重试；一次提交始终对应一条完整记录。

关闭 Tab、返回面板列表、从面板打开完整工作区、禁用应用或以另一条采集替换草稿前，显示“继续编辑 / 放弃草稿并切换”确认。普通主页面、项目和会话切换以及隐藏工作栏保留 App 持有的草稿及来源。取消采集只在正文或标题相对预览初值有修改时确认；未修改预览可直接取消。完整工作区自身的编辑草稿仍由其离开确认保护。

FR-6：成功写入触发现有通知刷新视图；面板重新挂载或工作栏重新展开时读取最新数据。面板挂载期间保留搜索词；笔记选择和草稿由 App 保留，不受搜索响应或后台刷新覆盖。既有记录编辑继续使用原修订号处理冲突。此处同步仅指本机共享存储的视图更新。

## 启用与评论

FR-1～FR-4：遵循魔法笔记应用的启用状态。禁用时隐藏会话采集、快速笔记及工作栏目录入口，并移除笔记 Tab；禁用前处理草稿。外部设置变更要求禁用时，选择继续编辑会尝试恢复启用设置，失败显示设置错误。应用未常驻不影响快速入口或工作栏可用性。设置继续由应用中心管理。

会话采集和快速追加本身不调用模型。保存后沿用现有 AI 评论模式；只有已有设置要求保存后自动评论时才触发，失败不撤销保存，也不自动重新追加。

## 完整性检查

当前实现覆盖首次创建、追加、取消、重复点击、写入失败、目标删除、来源删除、跨会话切换及刷新与草稿的关系。完整历史读取、来源定位和存储接口已接入；产品范围无待决项。真实 Electron 已验证采集、保存、定位、窄面板键盘操作和持久化，具体范围见进展记录。全仓测试和类型检查仍有执行时记录的失败，聚焦复跑通过不等于全仓通过。
