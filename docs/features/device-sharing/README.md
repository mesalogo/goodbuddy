# 设备发现与共享

设备共享在测试阶段默认关闭，先在“管理应用 → 设备共享 → 应用设置”启用，再从“应用 →
设备共享”或管理列表的“打开”进入。连接 ShareServer 后注册本机，服务器默认免验证接纳，
管理员也可要求审批；后续请求携带独立设备凭据，无需在 GB 登录管理员账号。
可浏览设备与发布目录、发布能力或知识元数据并撤销本机条目。内网填写主机 IP 与端口，
例如 `http://主机IP:8088`；默认回环地址仅用于本机开发。
管理员操作与协议见[ShareServer 设备注册与审批](../../../../goodbuddy-shareserver/docs/features/share-server/device-registration.md)。

当前实现不执行远程能力，不读取、搜索或下载知识正文；来源模式和权限均为元数据声明。
局域网发现、配对、组织网关和远程调用仍是后续设计，不是首期交付内容。

## 术语

- **附近设备**：同一局域网内主动广播 GoodBuddy 共享服务的设备。
- **已配对设备**：双方确认设备指纹后建立点对点信任的设备。
- **网关连接**：本机与某个 ShareServer 中特定组织身份的连接。
- **本机共享**：由本机作为提供者发布给 Peer 或组织的能力。
- **远端能力**：由其他设备或组织提供、本机可以查看或调用的能力。

SSH 远程项目是用户明确配置 Host 后操作远端工作区的独立功能，不自动进入设备发现与共享，
详见[远程主机与远程执行](../remote-host/README.md)。
