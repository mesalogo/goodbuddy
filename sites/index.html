产品亮点

项目、知识与编程 Agent

选择适合任务的 Agent，连接项目与知识来源，并查看工具调用和运行结果。

01

内置 OpenCode、Continue 与 DeepSeek Harness

在图形界面中选择编程 Agent、配置模型，直接向项目发起任务。DeepSeek Harness 为预览功能，也支持直连模型对话。

直连模型OpenCodeContinueDeepSeek Harness（预览）
02

本地项目与 SSH 远端项目

处理电脑上的代码，也可通过 OpenCode、Continue 连接 SSH 远端项目。远端运行配套的 GoodBuddy Agent。

03

接入已有知识服务

使用本地知识库，或配置 Dify、FastGPT、RAGFlow 连接，将已有资料用于检索与问答。

无需切换工作模式。可用工具由所选 Runtime 和已启用能力决定，操作使用当前账号权限，工具调用保留在运行记录中。

05

导入 Skills，连接 MCP 服务，为所选 Agent 配置工作中需要的工具。

06

运行记录与 Token 用量

查看工具调用、取消、超时、Token 用量和历史记录。

常见问题

安装与连接步骤见 README 入门指南。

需要注册账号或支付模型费用吗？

无需注册 GoodBuddy 账号。外部模型服务可能需要账号或 API 密钥，费用按服务商定价收取。使用本地模型时，需准备相应的运行环境。

我的资料会发送到哪里？

对话记录与笔记保存在本机。使用模型、知识服务、MCP 工具或消息渠道时，相关内容会发送到你配置的服务。模型请求可能包含检索到的资料片段和附件。

第一次使用编程 Agent，需要配置什么？

选择 Agent，配置模型连接并打开项目；根据所选 Agent 和系统准备或下载运行组件。DeepSeek Harness 为预览功能，安装步骤见入门指南。

支持哪些平台和信创环境？

Windows、macOS、Linux 提供 x64 与 ARM64 版本，国产环境覆盖相应架构；龙芯 LoongArch 提供独立实验预览版。统信 UOS、银河麒麟等环境需按系统、架构和安装包选择，兼容性说明不等同于整机或厂商认证。

使用 SSH 远端项目需要准备什么？

OpenCode、Continue 的远端项目需要可用的 SSH 连接，并在远端准备与桌面版本配套的 gbagent 及所需运行环境。操作使用远端登录账号权限；具体配置见 README 入门指南。
