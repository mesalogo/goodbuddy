主要功能

GoodBuddy 可以做什么

管理对话和知识，运行任务，并在需要时调用经过确认的工具。

01

Agent 运行模式

问答和计划模式不执行工具。执行模式通过审批控制调用工具，并支持取消、超时和输出限制。

问答 只读 计划 只读 执行 需审批
02

知识库按范围管理

全局知识和项目知识分开保存。搜索结果和引用会显示来源。

03

定时任务和运行记录

可以创建周期计划，查看每次运行的状态、结果和活动记录。

04

文档和图片

单次最多添加 8 个附件，支持同时传入 5 张图片。

05

生成图片

支持 auto、low、medium、high 四档质量。生成结果会保存到本地。

06

模型、MCP 与运行时

模型连接、MCP 工具和运行时都在桌面端配置。API 密钥只保存在主进程。

模型提供商MCPOpenCodeContinue

安全设计

主要安全边界

渲染界面不能直接读取密钥或调用 Node。工具和子运行时通过主进程受控访问系统能力。

在 GitHub 查看项目 ↗ （在新窗口打开）
01

密钥仅存主进程

API 密钥写入加密设置存储，不会暴露给渲染界面。

02

IPC 输入经过校验

预加载层只暴露明确的方法。IPC 输入使用共享模式校验，并检查发送方。

03

子运行时受限

OpenCode 与 Continue 使用环境白名单、沙箱检查和工具审批。

04

工具执行可追踪

工具名称、状态、取消、超时和输出限制都会记录在活动中。
