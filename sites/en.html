Before you start

Frequently asked questions

See the README getting-started guide for installation and connection steps.

Do I need an account or a paid model subscription?

No GoodBuddy account is required. External model services may need an account or API key and charge at their own rates. Local models need a suitable runtime on your machine.

Where does my data go?

Conversation history and notes are stored on your machine. Using models, knowledge services, MCP tools, or messaging channels sends relevant content to the services you configure. Model requests may include retrieved passages and attachments.

How do I set up a coding agent?

Select an agent, configure its model connection, and open a project. Prepare or download the runtime components required by your agent and operating system. DeepSeek Harness is in preview. See the getting-started guide for installation steps.

Which platforms and Chinese domestic systems are supported?

Windows, macOS, and Linux releases cover x64 and ARM64, including corresponding Chinese domestic hardware. LoongArch has a separate experimental preview. For systems such as UOS and Kylin, choose the matching architecture and package; compatibility information does not imply vendor or whole-system certification.

What do SSH projects require on the remote host?

Remote projects with OpenCode and Continue require a working SSH connection, a companion gbagent matching your desktop version, and the required runtime environment on the host. Operations use the remote login account's permissions. See the README for setup.
