# GoodBuddy Agent 0.15.12 更新内容

## 问题修复

- **补充 Runtime 启动失败原因**：远端 Runtime 无法启动时，Agent 返回有界的错误详情，帮助 Desktop 定位原因。配套 Desktop 0.16.13 显示，不改变任务执行和恢复规则。

OpenCode `1.19.3`、Continue `1.5.47` 和协议版本不变。

# What's New in GoodBuddy Agent 0.15.12

## Bug Fixes

- **Include the cause of Runtime launch failures**: When a remote Runtime cannot start, Agent returns bounded error details to help Desktop identify the cause. Desktop 0.16.13 displays these details without changing task execution or recovery rules.

OpenCode `1.19.3`, Continue `1.5.47`, and protocol versions are unchanged.
