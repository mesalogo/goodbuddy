# GoodBuddy Agent 0.15.7 更新内容

## 功能更新

- **支持远程项目图片读取**：配合 Desktop `0.16.5`，Agent 可分段返回用于图片预览的二进制内容。保留分段大小、摘要和取消检查，图片整体仍受客户端内存与解码能力限制。

## 问题修复

- **改善模型大请求提示**：远程模型桥接遇到 HTTP 413 时增加压缩上下文后重试的建议。此提示不会自动压缩、重发或改变模型请求限制。

本版面向 Linux x64、Linux arm64 和 macOS arm64 发布，Agent 发布与 Desktop 的 Latest 状态保持独立。

# What's New in GoodBuddy Agent 0.15.7

## Features

- **Read images from remote projects**: With Desktop `0.16.5`, the Agent can return binary content in pages for image previews. Page-size, digest, and cancellation checks remain in place, while complete images remain subject to client memory and decoding limits.

## Bug Fixes

- **Clarify oversized model request errors**: The remote model bridge adds a suggestion to compress context before retrying an HTTP 413 error. It does not automatically compress, resend, or change model request limits.

This release targets Linux x64, Linux arm64, and macOS arm64. Agent publication remains separate from the Desktop release's Latest status.
