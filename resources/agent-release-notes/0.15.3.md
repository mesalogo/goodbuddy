# GoodBuddy Agent 0.15.3 更新内容

## 功能更新

- **查询故事与经验**：配套 Desktop 0.15.9，远程 Story Graph 工具现在接受故事和经验对象，可读取故事事件以及经验的形成和应用依据。工具说明引导 Agent 在继续既有工作时按需查询，是否调用仍由模型决定，经验应作为参考而不是指令。

## 使用说明

- 先升级 Desktop **0.15.9**，再下载并更新 Host；已有 Agent 进程不热更新。
- 读取仍受监督者开关、Runtime 分配和项目范围约束；没有新增写入权限或自动全量上下文注入。
- Linux x64、Linux arm64、macOS arm64 三平台；Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47** 不变。
- Agent 独立发布，签名和完整性验证保留，不替代 Desktop Latest。

# What's New in GoodBuddy Agent 0.15.3

## Features

- **Query stories and experiences**: With Desktop 0.15.9, remote Story Graph tools accept story and experience objects to read story events and the evidence behind an experience's formation and applications. Tool descriptions guide Agents to query when continuing earlier work, but actual tool use remains model-dependent, and experiences are advice rather than instructions.

## Usage Notes

- Upgrade to Desktop **0.15.9** before downloading and updating the Host; existing Agent processes are not hot-updated.
- Reads remain subject to Supervisor enablement, Runtime assignments, and project scope, without new write permissions or automatic full-graph context injection.
- Targets are Linux x64, Linux arm64, and macOS arm64; Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47** are unchanged.
- Agent is released separately with signature and integrity checks, without replacing Desktop Latest.
