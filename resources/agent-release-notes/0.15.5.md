# GoodBuddy Agent 0.15.5 更新内容

## 问题修复

- **原生启动期间仍可取消和查询**：OpenCode 或 Continue 初始化等待不再占住全局控制队列，其他绑定、取消和看门狗可以继续处理。同一启动保持合并与冲突校验，取消后的迟到 Session 单独关闭，不重发原 Prompt。
- **模型路由清理不阻塞其他任务**：取消时的路由清理等待不再阻塞全局控制操作，迟到安装按所属 Session 和 operation 清除，不影响仍在运行的其他会话。真实 Linux x64 Host 已验证两个 Runtime 的工具、取消、断开恢复及回放去重，不代表所有平台和恢复场景均已覆盖。

## 升级须知

先升级至 **Desktop 0.15.12**，再下载此包并更新 Host。已有进程不会热更新，请先妥善处理活动任务；runtime/acp 6、wire 2.0、Node 24.19.0、OpenCode 1.18.29 和 Continue 1.5.47 保持不变。

# What's New in GoodBuddy Agent 0.15.5

## Bug Fixes

- **Keep cancellation and queries responsive during native startup**: Waiting for OpenCode or Continue initialization no longer holds the global control queue, so other bindings, cancellation, and watchdogs can progress. Duplicate startup coalescing and conflict checks remain, and late sessions after cancellation are closed separately without replaying the original prompt.
- **Avoid blocking other tasks during model-route cleanup**: Cancellation no longer holds global control operations while waiting for route cleanup, and late installations are removed for their owning session and operation without affecting active peers. Real Linux x64 Host checks covered both Runtimes' tools, cancellation, reconnection, and replay deduplication, not every platform or recovery scenario.

## Upgrade Notes

Upgrade to **Desktop 0.15.12** before downloading this package and updating the Host. Running processes are not hot-updated, so handle active tasks first; runtime/acp 6, wire 2.0, Node 24.19.0, OpenCode 1.18.29, and Continue 1.5.47 remain unchanged.
