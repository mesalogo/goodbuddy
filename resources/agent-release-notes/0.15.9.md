# GoodBuddy Agent 0.15.9 更新内容

## 功能更新

本版本未新增独立功能，配套 Desktop 0.16.10 使用。

## 问题修复

- **对齐故事图谱工具说明与读取方式**：远程 Runtime 的工具说明同步适配 Desktop 的分组搜索、结构化上下文和来源原文读取。Agent 可按事件提供的来源 ID 继续核对历史；自动回顾仍可能不完整，经验仅供参考，不代表任务已完成或旧决定已被替代。

OpenCode `1.19.3`、Continue `1.5.47` 和协议版本保持不变。需要同时更新 Desktop；此说明不代表完整已安装 Host 验收已完成。

# What's New in GoodBuddy Agent 0.15.9

## Features

This release adds no standalone capability and accompanies Desktop 0.16.10.

## Bug Fixes

- **Align story graph tool descriptions with history reading**: Remote Runtime tool descriptions now match Desktop's grouped search, structured context, and original-source reading. Agents can follow source IDs on events to verify history; automatic reviews may be incomplete, and experiences are advice, not proof of task completion or superseded decisions.

OpenCode `1.19.3`, Continue `1.5.47`, and protocol versions are unchanged. Update Desktop as well; these notes do not claim complete installed-Host acceptance.
