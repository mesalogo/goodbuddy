# GoodBuddy Agent 0.13.1 更新内容

## 功能更新

- **远程环境同时提供 OpenCode 和 Continue**：一个 `.gbagent` 包包含两个 Runtime，配合新版桌面端可为远程项目选择 Continue。Continue 支持模型请求、Execute 会话 MCP 工具、取消、断线恢复与重启后续聊，Ask 保持只读。
- **传递原生执行清单**：远程 OpenCode 和 Continue 的清单更新可显示在桌面对话顶部，并随会话保存。保留原任务归属、显式清空及断线重放，不把取消后的未完成项改为已完成。

## 使用说明

- 请先升级至 **GoodBuddy 0.13.7**，再更新 Host 环境。新行为在更新后的 Agent 和 Runtime 中生效，旧进程不会热更新。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，内含 Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47**。
- 远程项目仍为技术预览，Execute 使用所选 SSH 账号的权限。Agent 独立发布，不替代桌面端的 Latest 版本。

# What's New in GoodBuddy Agent 0.13.1

## Features

- **OpenCode and Continue in one remote environment**: A single `.gbagent` package contains both runtimes, allowing remote projects to select Continue with the updated Desktop. Continue supports model requests, conversation MCP tools in Execute, cancellation, reconnection, and conversation continuation after restart; Ask remains read-only.
- **Deliver native execution checklists**: Remote OpenCode and Continue checklist updates appear above the Desktop conversation and persist with its history. Task ownership, explicit clearing, and reconnection replay are preserved without marking cancelled, unfinished items complete.

## Usage Notes

- Upgrade to **GoodBuddy 0.13.7** before updating the Host environment. Changes take effect in the updated Agent and Runtime; older processes are not hot-updated.
- Packages cover Linux x64, Linux arm64, and macOS arm64, with Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**.
- Remote projects remain a technical preview, and Execute uses the selected SSH account’s permissions. Agent releases remain separate and do not replace the Desktop release marked Latest.
