# GoodBuddy Agent 0.15.10 更新内容

## 功能更新

- **支持远端直连模型工具**：随包提供搜索工具，让 Desktop 直连模型在 Host 执行文件读取、搜索、补丁和命令，并传回可续读的长输出。需要配套 Desktop 0.16.11，模型循环仍在 Desktop。

## 问题修复

- **减少 Continue 重复启动的磁盘写入**：复用已校验的运行缓存，不再每次启动都重新准备并删除。任务专属文件仍在子进程结束后清理，缓存不会替代任务取消和进程回收。

- **保留恢复会话与工具结果**：避免迟到的断线事件解绑已恢复会话；旧 Agent 退出前等待直连工具和保留输出，取消输出传输时及时停止。临时清理失败保留已知命令结果，不据此重复执行。

内置 OpenCode `1.19.3`、Continue `1.5.47` 不变。Linux x64 当前源码已实测，其他架构原生构建由 CI 验证，不等同于所有平台的已安装包端到端验收。

# What's New in GoodBuddy Agent 0.15.10

## Features

- **Support remote direct-model tools**: Bundled search tooling lets Desktop direct models read, search, patch, and run commands on the Host, returning long output for paged reading. Requires Desktop 0.16.11; the model loop remains on Desktop.

## Bug Fixes

- **Reduce disk writes on repeated Continue starts**: Reuse the validated runtime cache instead of rebuilding and deleting it on every launch. Request-specific files are still cleaned after child processes terminate; caching does not replace task cancellation or process cleanup.

- **Preserve resumed sessions and tool results**: Late disconnect events no longer detach resumed sessions; retiring Agents wait for direct tools and retained output, and cancelled output transfers stop promptly. Cleanup failures preserve known command results without replaying execution.

Bundled OpenCode `1.19.3` and Continue `1.5.47` are unchanged. Current-source Linux x64 validation is recorded; native CI builds for other architectures do not establish installed-package end-to-end acceptance on every platform.
