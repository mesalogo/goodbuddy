# GoodBuddy Agent 0.15.8 更新内容

## 功能更新

- **更新远程 OpenCode**：内置 OpenCode 升级至 `1.19.3`，与 Desktop `0.16.9` 配套使用。Continue 保持 `1.5.47`。

## 问题修复

- **清理 Continue 命令后代**：取消远程 Continue 请求时，通过独立进程组清理所属命令和后代，避免先退出请求 Host 而遗留子进程。不通过停止共享服务取消单个请求。
- **传递 OpenCode 子任务中止状态**：远程插件转发所属子会话的中止错误，让 Desktop 将对应任务显示为取消。其他错误仍按失败处理。

# What's New in GoodBuddy Agent 0.15.8

## Features

- **Update remote OpenCode**: Bundled OpenCode is updated to `1.19.3` for use with Desktop `0.16.9`. Continue remains at `1.5.47`.

## Bug Fixes

- **Clean up Continue command descendants**: Cancelling a remote Continue request uses its dedicated process group to terminate owned commands and descendants, rather than exiting the request Host first and leaving child processes behind. A shared service is not stopped to cancel an individual request.
- **Forward aborted OpenCode subtask states**: The remote plugin forwards abort errors from owned child sessions so Desktop can display the corresponding task as cancelled. Other errors remain failures.
