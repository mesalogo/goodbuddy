# GoodBuddy Agent 0.13.0 更新内容

## 功能更新

- **远程聊天也能直接生图**：使用托管远程 OpenCode 时，可在当前对话中调用桌面端配置的图片模型，生成图片、修改上传图片或继续调整历史成果。无需另开会话或切换聊天模型，图片结果保存到原会话。

## 问题修复

- **多个远程项目更省资源**：同一 Host 上兼容的项目和会话可共享 OpenCode 底层进程，减少重复启动。各会话继续独立工作，取消其中一个不会结束其他会话使用的共享进程。
- **断线后继续处理原对话**：配合新版桌面端，重新连接或重启桌面后可恢复原操作的待答问题与任务状态。重连不会重新发送已经接受的请求。

## 使用说明

- 请先升级至 **GoodBuddy 0.13.5 或更高版本**，再更新远程环境。聊天生图需开启图片模型的会话调用，并使用 Execute 模式。
- 提供 Linux x64、Linux arm64 和 macOS arm64 安装包，内含 Node `24.19.0` 和 OpenCode `1.18.29`。新行为在更新后的 Agent 和 Runtime 中生效，正在运行的旧进程不会热更新。
- 远程项目仍为技术预览；Ask 保持只读，Execute 使用所选 SSH 账号的权限。

# What's New in GoodBuddy Agent 0.13.0

## Features

- **Create images in remote chats**: Managed remote OpenCode can use Desktop-configured image models to generate images, edit uploads, or refine earlier results in the current conversation. No separate conversation or chat-model switch is needed, and results stay in the original conversation.

## Bug Fixes

- **Use fewer resources across remote projects**: Compatible projects and conversations on the same Host share underlying OpenCode processes, reducing duplicate startup. Conversations remain independent, and cancelling one does not terminate the shared process used by others.
- **Continue the original conversation after disconnection**: Together with the updated Desktop, pending questions and task status recover after reconnection or Desktop restart. Reconnection does not resend accepted requests.

## Usage Notes

- Upgrade to **GoodBuddy 0.13.5 or later** before updating the remote environment. In-chat image tools require conversation access to be enabled for an image model and Execute mode.
- Packages cover Linux x64, Linux arm64, and macOS arm64, with Node `24.19.0` and OpenCode `1.18.29`. Changes take effect in the updated Agent and Runtime; running older processes are not hot-updated.
- Remote projects remain a technical preview. Ask stays read-only, and Execute uses the selected SSH account’s permissions.
