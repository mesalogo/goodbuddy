# GoodBuddy Agent 0.11.25 更新内容

## 维护更新

- **配套 Desktop 0.13.2 的维护版本**：本次重新发布受支持平台的 Agent 复合包，不新增独立远端功能，也不改变 Agent 协议。桌面端的工具记录和执行历史存储补修由 Desktop 0.13.2 提供，更新 Agent 不能代替桌面升级。

## 升级说明

- 需要 **Desktop 0.13.2 或更高版本**，请先升级 Desktop，再按需更新 Host 环境。提供 Linux x64、Linux arm64 和 macOS arm64 复合包，Node 保持 `24.19.0`，OpenCode 保持 `1.18.29`。
- Ask 保持只读，Execute 继续使用所选 SSH 账号权限。更新不会热替换运行中的旧进程，请在当前任务结束后更新并使用新 Runtime。

# What's New in GoodBuddy Agent 0.11.25

## Maintenance

- **Maintenance release alongside Desktop 0.13.2**: Agent compound packages are republished for the supported platforms without adding standalone remote features or changing the Agent protocol. Desktop 0.13.2 provides the tool-record and execution-history storage repairs; updating Agent does not replace the Desktop upgrade.

## Upgrade Notes

- Requires **Desktop 0.13.2 or later**; upgrade Desktop before updating Host environments as needed. Compound packages target Linux x64, Linux arm64, and macOS arm64, retaining Node `24.19.0` and OpenCode `1.18.29`.
- Ask remains read-only, and Execute retains the selected SSH account's permissions. Updates do not hot-replace running processes; finish active tasks before updating and using a new Runtime.
