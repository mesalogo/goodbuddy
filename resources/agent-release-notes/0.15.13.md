# GoodBuddy Agent 0.15.13 更新内容

## 问题修复

- **修复断线后的任务记录读取**：配套 Desktop `0.17.4`，即使原执行连接已清理，也能读取已保存的任务完成状态和结果。仍在运行的任务重新接管后保留取消能力，不重复启动原任务，也不重建已经丢失的 Runtime 进程。

OpenCode `1.19.3`、Continue `1.5.47` 和协议版本不变。

# What's New in GoodBuddy Agent 0.15.13

## Bug Fixes

- **Fix task record access after disconnection**: With Desktop `0.17.4`, persisted task completion and results remain readable even after the original execution connection has been cleaned up. Reattaching a running task preserves cancellation without restarting the task or recreating a lost Runtime process.

OpenCode `1.19.3`, Continue `1.5.47`, and protocol versions are unchanged.
