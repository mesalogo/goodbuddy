# GoodBuddy Agent 0.15.15 更新内容

## 问题修复

- **放宽远端 Continue 配置数量限制**：移除 GoodBuddy 适配层对 Continue MCP Server、Rules 和 Prompts 数量的固定限制，避免较多配置被拒绝。配置格式校验、取消、超时和传输大小限制继续生效。
- **对齐图片工具的来源列表**：远端图片工具不再仅因来源图片引用超过八项而拒绝请求。图片内容、传输和模型服务自身的限制仍然适用。

需配套 Desktop `0.18.0` 或更高版本。内置 OpenCode、Continue 和协议版本不变。

# What's New in GoodBuddy Agent 0.15.15

## Bug Fixes

- **Relax remote Continue configuration counts**: Remove fixed GoodBuddy adapter limits on the number of Continue MCP servers, rules, and prompts so larger configurations are not rejected solely by count. Configuration validation, cancellation, timeouts, and transport-size limits remain in effect.
- **Align image-tool source lists**: Remote image tools no longer reject requests solely because they reference more than eight source images. Image-content, transport, and model-service limits still apply.

Requires Desktop `0.18.0` or later. Bundled OpenCode, Continue, and protocol versions are unchanged.
