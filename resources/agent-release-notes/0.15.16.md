# GoodBuddy Agent 0.15.16 更新内容

## 问题修复

- **重试响应头到达前的连接重置**：向模型服务发送请求时，如果在收到响应头前遇到 `ECONNRESET`，Agent 最多重试两次，各次尝试共用原请求的取消信号和超时设置。服务商可能已处理先前的请求，重试可能造成重复处理或计费。已收到响应头后若读取中断，Agent 不会重发请求。

需配套 Desktop `0.18.3` 或更高版本。内置 OpenCode `1.19.3`、Continue `1.5.47`、Node `24.19.0` 和协议 `2.0` 均不变。

# What's New in GoodBuddy Agent 0.15.16

## Bug Fixes

- **Retry connection resets before response headers arrive**: If a model request encounters `ECONNRESET` before receiving response headers, the Agent retries up to twice under the original cancellation signal and timeout settings. The provider may already have processed an earlier attempt, so retries can result in duplicate processing or charges. If reading the response fails after headers arrive, the Agent does not resend the request.

Requires Desktop `0.18.3` or later. Bundled OpenCode `1.19.3`, Continue `1.5.47`, Node `24.19.0`, and protocol `2.0` are unchanged.
