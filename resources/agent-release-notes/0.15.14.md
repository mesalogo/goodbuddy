# GoodBuddy Agent 0.15.14 更新内容

## 问题修复

- **保留模型请求的具体失败原因**：远端模型请求失败后，任务结果保留原有网关错误，不再被笼统的运行停止错误覆盖。诊断记录包含可用的失败阶段及安全筛选后的网络错误码，不包含请求正文或凭据。
- **重试确认未连接的模型请求**：对确认尚未连接成功的网络错误最多重试两次，沿用同一次调用的取消和总超时设置。响应中断或请求是否送达不明时不自动重试；失败后可明确发送下一条消息，不自动重放旧任务。

需配套 Desktop `0.17.5` 或更高版本。OpenCode `1.19.3`、Continue `1.5.47` 和协议版本不变。

# What's New in GoodBuddy Agent 0.15.14

## Bug Fixes

- **Preserve specific model request errors**: Failed remote model requests retain their original gateway errors in task results instead of being replaced by a generic runtime-stopped error. Diagnostics include the available failure phase and allowlisted network error codes, without request bodies or credentials.
- **Retry confirmed pre-connection failures**: Confirmed pre-connection network failures receive up to two retries using the same call’s cancellation and total timeout settings. Interrupted responses and uncertain delivery are not automatically retried; users can explicitly send another message after failure without replaying the previous task.

Requires Desktop `0.17.5` or later. OpenCode `1.19.3`, Continue `1.5.47`, and protocol versions are unchanged.
