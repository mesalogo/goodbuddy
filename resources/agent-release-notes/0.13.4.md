# GoodBuddy Agent 0.13.4 更新内容

## 问题修复

- **远程回答完成状态更准确**：任务结束前等待模型交付确认，避免正文已经返回却因确认尚未完成而出现结果未知。空闲 Runtime 回收失败不再改变已保存的完成结果，真实交付失败仍会报告结果未知。
- **更新时清理停用安装**：配套 Desktop 0.13.14 更新 Host 环境后，由当前 Agent 清理已确认停用的旧程序及所属孤儿进程。会话历史、当前和候选安装、仍在运行或状态不明的旧安装会保留，清理未完成不撤销已成功的环境更新。

## 使用说明

- 请先升级至 **GoodBuddy 0.13.14**，再下载并更新 Host 环境。结果未知后可显式发送新消息继续对话，自动恢复不会重发原任务；已有旧进程不会热更新。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，内含 Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47**。旧程序清理依赖可确认的进程状态，无法确认时保留原安装。
- Ask 保持只读，Execute 使用所选 SSH 账号的权限。Agent 独立发布，不替代桌面端的 Latest 版本。

# What's New in GoodBuddy Agent 0.13.4

## Bug Fixes

- **More accurate remote completion status**: Tasks wait for model delivery acknowledgement before finishing, avoiding uncertain outcomes caused by an acknowledgement still pending after the answer arrives. Idle Runtime cleanup failures no longer change a saved completion result; genuine delivery failures still report an uncertain outcome.
- **Clean up inactive installations during updates**: After a Host environment update through Desktop 0.13.14, the current Agent removes verified inactive older payloads and their owned orphan processes. Conversation history, current and candidate installations, and active or uncertain older installations are retained; incomplete cleanup does not undo a successful environment update.

## Usage Notes

- Upgrade to **GoodBuddy 0.13.14** before downloading and updating the Host environment. After an uncertain outcome, explicitly send a new message to continue; automatic recovery never resends the original task, and existing older processes are not hot-updated.
- Packages cover Linux x64, Linux arm64, and macOS arm64, with Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**. Older payload cleanup requires verifiable process state and retains installations when that state cannot be confirmed.
- Ask stays read-only and Execute uses the selected SSH account's permissions. Agent releases remain separate and do not replace the Desktop release marked Latest.
