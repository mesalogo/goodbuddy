# GoodBuddy Agent 0.11.23 更新内容

## 功能更新

- **远程文件与 Git 管理**：远程项目可通过桌面工作区管理文件和目录，并操作分支、提交历史和单文件差异。操作使用所选 SSH 账号权限，删除须确认，分支冲突不会自动丢弃修改。

## 问题修复

- **修复长任务被固定限制中断**：移除随包 Runtime 的固定十分钟 Prompt 时限，并正确处理未额外设置模型超时或输出上限的请求。较大的模型请求和响应可通过更新后的桥接传输，取消、显式期限和传输边界仍然有效。
- **不限请求时长时仍可连接**：修复无限请求时长被误用为零连接超时的问题。连接建立仍有独立超时，不会因此立即失败。
- **更准确的失败分类**：模型网关区分取消、超时和响应过大等失败原因。保留原有调用记录和响应交付语义，不自动重放结果不确定的模型请求。

## 升级说明

- 需要 **Desktop 0.12.11 或更高版本**。提供 Linux x64、Linux arm64 和 macOS arm64 复合包，包含 Agent、固定 Node 和适配的 OpenCode；旧的运行中进程不会热更新。

# What's New in GoodBuddy Agent 0.11.23

## Features

- **Remote file and Git management**: Manage remote files and directories, branches, commit history, and per-file diffs from the desktop workspace. Operations use the selected SSH account’s permissions, deletion requires confirmation, and branch conflicts never automatically discard changes.

## Bug Fixes

- **Fix long tasks interrupted by fixed limits**: Removed the bundled Runtime’s fixed ten-minute Prompt deadline and corrected handling of requests without additional model timeouts or output caps. Updated bridges handle larger model requests and responses while retaining cancellation, explicit deadlines, and transport bounds.
- **Connections work with unlimited request duration**: Fixed unlimited request duration being misinterpreted as a zero connection timeout. Connection establishment retains a separate timeout instead of failing immediately.
- **More accurate failure classification**: The model gateway distinguishes cancellation, timeout, and oversized responses. Existing call records and response-delivery semantics remain intact, without automatically replaying model requests whose outcome is uncertain.

## Upgrade Notes

- Requires **Desktop 0.12.11 or later**. Compound packages target Linux x64, Linux arm64, and macOS arm64 and include the Agent, pinned Node, and adapted OpenCode; existing running processes are not hot-updated.
