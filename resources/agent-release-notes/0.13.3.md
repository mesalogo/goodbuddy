# GoodBuddy Agent 0.13.3 更新内容

## 问题修复

- **远程任务结束后释放空闲 Runtime**：任务完成后自动回收空闲运行进程，下一轮对话重新启动 Runtime 并恢复历史。共享进程仍有其他任务或待答问题时继续保留，断开 Desktop 不会取消已有工作。
- **更新后的旧 Agent 完成工作再退出**：被新安装替换的 Agent 停止接受新任务，已有工作可以继续并重连收取结果，完成后退出。当前 Agent 保持常驻，已经退出的旧安装不会因重连而重新启动。

## 使用说明

- 请先升级至 **GoodBuddy 0.13.12**，再更新 Host 环境。已有旧进程不会热更新，本次更新不能追溯改变旧版本进程的退出行为。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，内含 Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47**。
- 远程项目移除技术预览标识，仍默认关闭。Ask 保持只读，Execute 使用所选 SSH 账号的权限；Agent 独立发布，不替代桌面端的 Latest 版本。

# What's New in GoodBuddy Agent 0.13.3

## Bug Fixes

- **Release idle Runtimes after remote tasks**: Completed tasks reclaim idle Runtime processes, and the next conversation turn restarts the Runtime and restores history. Shared processes remain alive while other tasks or pending questions are active, and disconnecting Desktop does not cancel existing work.
- **Replaced Agents finish work before exiting**: An Agent displaced by a new installation stops accepting new tasks while existing work can continue and reconnect to deliver its results, then exits. The current Agent stays resident, and reconnecting does not restart an older installation that has already exited.

## Usage Notes

- Upgrade to **GoodBuddy 0.13.12** before updating the Host environment. Existing older processes are not hot-updated; this update cannot retroactively change how older Agent processes exit.
- Packages cover Linux x64, Linux arm64, and macOS arm64, with Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**.
- Remote Projects loses its technical preview label and remains disabled by default. Ask stays read-only and Execute uses the selected SSH account's permissions; Agent releases remain separate and do not replace the Desktop release marked Latest.
