# GoodBuddy Agent 0.13.2 更新内容

## 维护更新

- **配套 Desktop 0.13.8**：本版本是与 Desktop 0.13.8 配套的 Agent patch 发布，保持 OpenCode、Continue、原生执行清单和远程权限边界不变。

## 使用说明

- 请先升级至 **GoodBuddy 0.13.8**，再更新 Host 环境。旧进程不会热更新。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，内含 Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47**。
- 远程项目仍为技术预览，Execute 使用所选 SSH 账号的权限。Agent 独立发布，不替代桌面端的 Latest 版本。

# What's New in GoodBuddy Agent 0.13.2

## Maintenance

- **Paired with Desktop 0.13.8**: This is the Agent patch release paired with Desktop 0.13.8. OpenCode, Continue, native execution checklists, and remote permission boundaries remain unchanged.

## Usage Notes

- Upgrade to **GoodBuddy 0.13.8** before updating the Host environment. Older processes are not hot-updated.
- Packages cover Linux x64, Linux arm64, and macOS arm64, with Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**.
- Remote projects remain a technical preview, and Execute uses the selected SSH account’s permissions. Agent releases remain separate and do not replace the Desktop release marked Latest.
