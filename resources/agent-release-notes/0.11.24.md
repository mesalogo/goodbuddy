# GoodBuddy Agent 0.11.24 更新内容

## 问题修复

- **在桌面回答远程原生问题**：托管 SSH OpenCode 的主会话与子会话问题可以回传到前台对话，支持选项、自由文本和跳过。多个问题可分别回答，不再依赖模型正文转述问题。
- **取消待答任务后可以继续发送**：修复取消远程问题后，旧操作未正确结束导致同一会话后续消息失败的问题。取消后会核对并结束旧绑定，迟到的回答不会提交到新请求。

## 升级说明

- 需要 **Desktop 0.13.0 或更高版本**，请先升级 Desktop，再更新 Host 环境。提供 Linux x64、Linux arm64 和 macOS arm64 复合包，OpenCode 保持 `1.18.29`，运行中的旧进程不会热更新。
- 问答支持仅适用于 GoodBuddy 管理的 OpenCode 前台对话，不包括任意 ACP 服务或终端密码、OAuth 等提示。Ask 保持只读，Execute 继续使用所选 SSH 账号权限。

# What's New in GoodBuddy Agent 0.11.24

## Bug Fixes

- **Answer native remote questions from Desktop**: Questions from managed SSH OpenCode main and child sessions reach the foreground conversation, supporting choices, free text, and skipping. Multiple questions can be answered individually without relying on the model to repeat them in its response text.
- **Send again after cancelling a pending question**: Fixed unfinished operation state that could reject subsequent messages in the same conversation after cancellation. Cancellation reconciles and closes the old binding, and late answers cannot be submitted to a new request.

## Upgrade Notes

- Requires **Desktop 0.13.0 or later**; upgrade Desktop before updating the Host environment. Compound packages target Linux x64, Linux arm64, and macOS arm64, retain OpenCode `1.18.29`, and do not hot-update running processes.
- Questions are supported only in foreground conversations using GoodBuddy-managed OpenCode, not arbitrary ACP services or terminal password and OAuth prompts. Ask remains read-only, and Execute retains the selected SSH account’s permissions.
