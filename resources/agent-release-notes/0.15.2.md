# GoodBuddy Agent 0.15.2 更新内容

## 功能更新

- **把会话图片保存到 Host**：配套 Desktop 0.15.8，在 Execute 模式中使用 `save_image`，可把当前会话中已上传或生成的图片保存到 Host 的指定绝对路径。Agent 分块接收 Desktop 中的图片并在 Host 写入，默认拒绝覆盖已有文件，只有明确指定覆盖时才替换；Ask 模式不能写入。

## 使用说明

- 先升级 Desktop **0.15.8**，再下载 Agent 并更新 Host；已有进程不热更新。
- 支持 PNG、JPEG 与原格式 WebP，不支持转换为 WebP；只接受当前会话可访问的图片，不下载服务商返回的图片 URL。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包。Node **24.19.0**、OpenCode **1.18.29**、Continue **1.5.47** 不变。
- Agent 独立发布，不替代 Desktop Latest，保留签名与完整性验证。

# What's New in GoodBuddy Agent 0.15.2

## Features

- **Save conversation images on the Host**: With Desktop 0.15.8, use `save_image` in Execute mode to write an uploaded or generated image from the current conversation to an absolute path on the Host. Agent receives the image from Desktop in bounded chunks and writes it locally on the Host, refusing to replace an existing file unless overwrite is explicitly requested; Ask mode cannot write files.

## Usage Notes

- Upgrade to Desktop **0.15.8** before downloading Agent and updating the Host; existing processes are not hot-updated.
- PNG, JPEG, and unchanged WebP are supported; conversion to WebP is not. Only images accessible to the current conversation can be saved, and provider-returned image URLs are not downloaded.
- Packages cover Linux x64, Linux arm64, and macOS arm64. Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47** remain unchanged.
- Agent is published separately without replacing Desktop Latest, retaining signature and integrity verification.
