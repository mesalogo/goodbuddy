# GoodBuddy Agent 0.15.6 更新内容

## 问题修复

- **配合桌面存储 owner 迁移**：远程 Runtime、工具、图片和历史路径继续使用既有 Agent 会话、权限和回放语义；本版包含与 Desktop 0.15.13 配套的 Runtime 调整。
- **工具失败后继续请求**：直连模型在工具执行失败后可继续下一轮，分页输出和下一轮请求保持有界；取消、资源清理和错误上下文继续保留。

## 升级须知

先升级 **Desktop 0.15.13**，再下载此包并更新 Host。runtime/acp 6、wire 2.0、Node 24.19.0、OpenCode 1.18.29 和 Continue 1.5.47 保持不变。已有 Agent 进程不会热更新，请先处理活动任务。

# What's New in GoodBuddy Agent 0.15.6

## Bug Fixes

- **Support the desktop storage-owner migration**: Remote Runtime, tool, image, and history paths retain existing Agent session, permission, and replay semantics; this package contains the matching Runtime changes for Desktop 0.15.13.
- **Continue after tool failures**: Direct-model requests can continue after tool execution failures while paged output and next-turn requests remain bounded. Cancellation, resource cleanup, and error context remain intact.

## Upgrade Notes

Upgrade to **Desktop 0.15.13** before downloading this package and updating the Host. runtime/acp 6, wire 2.0, Node 24.19.0, OpenCode 1.18.29, and Continue 1.5.47 remain unchanged. Running Agent processes are not hot-updated; handle active tasks first.
