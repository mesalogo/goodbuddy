# GoodBuddy Agent 0.15.1 更新内容

## 问题修复

- **避免 Continue 重复嵌套对话历史**：远程 Continue 识别 Desktop 在新进程首次请求中携带的历史封装，将其纳入当前会话，而不是再次作为一整段用户输入封装。后续轮次复用已保存的历史，并在保存用户消息时去除本轮工作模式前缀；Ask/Execute 的执行边界不变。

## 使用说明

- 请先升级 **GoodBuddy Desktop 0.15.4**，再下载并更新 Host 环境。已有进程不会热更新，本次不新增远程原生客户端快捷入口。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，继续使用 Node **24.19.0**、OpenCode **1.18.29** 和 Continue **1.5.47**。
- Agent 独立发布，不替代桌面端 Latest；保留签名验证和原有远程工作区、模型桥及取消机制。

# What's New in GoodBuddy Agent 0.15.1

## Bug Fixes

- **Avoid nesting Continue history twice**: Remote Continue recognizes the history envelope sent by Desktop on the first request to a new process and adds it to the session rather than wrapping it again as one user input. Subsequent turns reuse the stored history, with the current work-mode prefix removed from saved user messages; Ask and Execute execution boundaries are unchanged.

## Usage Notes

- Upgrade to **GoodBuddy Desktop 0.15.4** before downloading and updating the Host environment. Existing processes are not hot-updated, and this release adds no remote native-client shortcuts.
- Packages cover Linux x64, Linux arm64, and macOS arm64, retaining Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**.
- Agent releases remain separate and do not replace Desktop Latest; signature verification and existing remote workspace, model-bridge, and cancellation mechanisms remain in place.
