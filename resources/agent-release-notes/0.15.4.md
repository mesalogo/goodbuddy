# GoodBuddy Agent 0.15.4 更新内容

## 功能更新

- **统一远程执行**：普通请求不再携带 Ask / Execute 工作模式或通用工具审批，使用已启用能力和所选 SSH 账号权限。Continue helper 使用原生 agent 路径，不再因旧模式选择进入只读 chat；用户仍需明确表达只解释、不修改等要求。
- **远程工作区导入**：配套 Desktop 可将本机文件分块上传到所选 Host 目录，支持二进制和空文件，并显示可用的修改、创建时间。同名文件不覆盖，失败项单独报告，不自动导入旧会话图片或成果。
- **保留远程图片保存位置**：远程专家沿用父请求的 OpenCode 或 Continue 路径与图片绑定，保存图片写入 Host。仅由消息引用的既有图片也可发现，关闭图片生成不阻止保存已有图片。

## 升级须知

- 最低要求 **Desktop 0.15.11**，远程能力版本为 **runtime/acp 6**，旧版客户端不兼容。先结束或妥善处理活动任务，升级 Desktop，再下载此包更新 Host；已有进程不会热更新，旧操作跨版本恢复尚未验证。
- Node 24.19.0、OpenCode 1.18.29、Continue 1.5.47 不变。提供 Linux x64、Linux arm64、macOS arm64 三个独立签名包；真实 Host 开发验证来自 Linux x64，不等于完整三平台实机验证。

# What's New in GoodBuddy Agent 0.15.4

## Features

- **Unified remote execution**: Normal requests no longer carry Ask / Execute work modes or general tool approval policies and use enabled capabilities and the selected SSH account permissions. The Continue helper uses native agent execution rather than selecting read-only chat from the retired mode; users should still state explanation-only or no-modification requirements explicitly.
- **Remote workspace imports**: The matching Desktop can upload local files in chunks to a selected Host directory, including binary and empty files, and display available modification and creation times. Existing files are not overwritten, failures are reported per item, and old conversation images or artifacts are not imported automatically.
- **Keep image saves on the remote Host**: Remote experts retain the parent's OpenCode or Continue path and image bindings so saving writes to the Host. Existing images referenced only by messages can also be discovered, and disabling generation does not prevent saving existing images.

## Upgrade Notes

- Requires **Desktop 0.15.11** and **runtime/acp 6**; older clients are incompatible. Finish or otherwise handle active tasks, upgrade Desktop, then download this package and update the Host; running processes are not hot-updated, and cross-version recovery of old operations has not been validated.
- Node 24.19.0, OpenCode 1.18.29, and Continue 1.5.47 remain unchanged. Separate signed packages cover Linux x64, Linux arm64, and macOS arm64; real-Host development evidence comes from Linux x64 rather than a complete three-platform hardware matrix.
