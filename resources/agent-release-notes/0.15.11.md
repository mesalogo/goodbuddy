# GoodBuddy Agent 0.15.11 更新内容

## 功能更新

- **改善远端会话准备与恢复**：远端连接在准备阶段短暂中断时可有限重试，启动响应丢失时继续接管已接受的请求，不重复提交原操作。配套 Desktop 0.16.12 使用。

## 问题修复

- **保留工具结果并正确结束任务**：工具失败详情继续传给后续模型；远端恢复和 Agent 生命周期处理保持已知结果，不因普通工具失败错误终止正常完成的 Runtime。

OpenCode `1.19.3`、Continue `1.5.47` 和协议版本保持不变。远端直连工具及 Continue 缓存能力沿用上一版本；当前源码验证和原生 CI 不等同于所有平台已安装包端到端验收。

# What's New in GoodBuddy Agent 0.15.11

## Features

- **Improve remote session preparation and recovery**: Temporary disconnects during remote preparation retry within bounds, and lost start responses continue accepted requests without resubmitting the original operation. Pair with Desktop 0.16.12.

## Bug Fixes

- **Preserve tool results and finish tasks correctly**: Tool failure details continue to the next model turn; remote recovery and Agent lifecycle handling retain known results instead of incorrectly terminating a normally completing Runtime after an ordinary tool failure.

OpenCode `1.19.3`, Continue `1.5.47`, and protocol versions are unchanged. Remote direct tools and the Continue cache from the previous release remain available; current-source validation and native CI do not establish installed-package end-to-end acceptance on every platform.
