# GoodBuddy Agent 0.15.0 更新内容

## 问题修复

- **远程 Runtime 遵循遥测关闭设置**：通过更新后的 Host 环境启动 OpenCode 或 Continue 时，Agent 与模型桥统一传入遥测关闭配置。保留模型、MCP 和用户主动联网能力，不把关闭遥测变成禁止正常联网。
- **Continue 不再重复检查更新**：远程 Continue 使用的共享适配器在自动更新关闭时跳过更新检查。正常模型请求和执行能力不受影响，该修改随新启动的 Runtime 生效。

## 使用说明

- 请先升级 **GoodBuddy Desktop 0.15.1**，再下载并更新 Host 环境。此版本不提供远程原生客户端快捷入口，已有进程不会热更新。
- 提供 Linux x64、Linux arm64 和 macOS arm64 包，继续使用 Node **24.19.0**、OpenCode **1.18.29** 和 Continue **1.5.47**。
- Ask 保持只读，Execute 使用所选 SSH 账号的权限。Agent 独立发布，不替代桌面端 Latest。

# What's New in GoodBuddy Agent 0.15.0

## Bug Fixes

- **Remote Runtimes respect telemetry opt-out**: OpenCode and Continue launched through the updated Host environment receive consistent telemetry opt-out settings from the Agent and model bridge. Model, MCP, and user-requested networking remain available rather than being blocked alongside telemetry.
- **Continue skips disabled update checks**: The shared adapter used by remote Continue skips update checks when automatic updates are disabled. Normal model requests and execution remain available, and the change takes effect for newly started Runtimes.

## Usage Notes

- Upgrade to **GoodBuddy Desktop 0.15.1** before downloading and updating the Host environment. This release does not provide remote native-client shortcuts, and existing processes are not hot-updated.
- Packages cover Linux x64, Linux arm64, and macOS arm64, retaining Node **24.19.0**, OpenCode **1.18.29**, and Continue **1.5.47**.
- Ask stays read-only and Execute uses the selected SSH account's permissions. Agent releases remain separate and do not replace Desktop Latest.
